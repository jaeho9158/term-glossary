    큐레이션 생애주기모형 (Curation Lifecycle Model)

    문헌정보학
    한 줄 정의: 디지털 자료의 개념화, 생성, 평가·선별, 수집, 보존작업, 저장, 접근·이용, 재이용에 이르는 전 과정을 순환적 단계로 도식화한 모형으로, 영국 디지털큐레이션센터(DCC)가 제시한 모형이 대표적이다.

    쉽게 풀면

    디지털 자료가 태어나서부터 계속 관리되고 다시 쓰이기까지의 전체 과정을 단계별로 그려 놓은 순환 모형이다.

    왜 중요한가

    DCC 큐레이션 생애주기모형은 데이터 생성부터 보존·재이용까지 각 단계에서 필요한 조치를 한눈에 보여 주어 연구데이터 관리 계획 수립과 저장소 업무 설계의 공통 언어가 되었습니다. 기관의 데이터 관리 성숙도를 점검하는 체크리스트로도 쓰입니다.

    이 모형은 특정 기술이나 저장소를 규정하지 않는 개념적 틀이어서, 다양한 기관이 자신의 실무 절차에 맞게 각 단계를 구체화해 적용한다. 이 모형을 교육 자료로 활용하면 연구자들에게 데이터 관리의 전체 그림을 간단히 설명할 수 있다는 실무적 이점이 있다.

    핵심 정리

    • DCC 큐레이션 생애주기모형은 영국 디지털큐레이션센터(Digital Curation Centre)의 히긴스(Higgins, 2008)가 제시한 모형으로, 디지털 자료를 만들 때부터 다시 쓸 때까지 필요한 큐레이션 활동을 한 장의 그림으로 정리합니다.
    • 그림의 중심에는 데이터(디지털 객체와 데이터베이스)가 있고, 바깥으로 세 겹의 활동이 둘러쌉니다.
    층활동성격
    전 생애주기 활동설명과 표현 정보, 보존 계획, 공동체 감시와 참여, 큐레이션과 보존모든 단계에 걸쳐 계속
    순차 활동구상(Conceptualise) → 생성 또는 수령 → 평가와 선별 → 수집(Ingest) → 보존 활동 → 저장 → 접근·이용·재이용 → 변환(Transform)생애주기를 따라 순서대로
    가끔 하는 활동폐기(Dispose), 재평가, 이주(Migrate)필요할 때 수행
    • 순환 구조라서 재이용 단계에서 새로 만들어진 자료가 다시 구상·생성으로 이어집니다.
    • 특정 기술이나 저장소를 규정하지 않는 개념적 틀이며, 기관은 이를 자기 업무 절차에 맞게 구체화합니다.

    예시로 보기

    연구데이터 관리에 적용하면 각 활동을 담당자·산출물과 연결해 점검표로 쓸 수 있습니다. 예를 들어 어떤 대학 도서관의 기관 리포지터리를 이 모형에 대응시키면 다음과 같이 정리됩니다(가상의 예).

    모형의 단계리포지터리에서의 업무주 담당
    구상데이터관리계획(DMP) 작성 지원연구자, 데이터사서
    생성 또는 수령연구자가 파일과 메타데이터 기탁연구자
    평가와 선별보존 가치와 보존 기간 결정데이터사서
    수집(Ingest)포맷·무결성 점검 후 저장소 등록시스템관리자
    보존 활동장기 보존 가능한 포맷으로 변환데이터사서, 시스템관리자
    접근·이용·재이용공개·인용 정보 제공, 재이용 문의 처리데이터사서

    이렇게 정리하면 빠진 서비스(예: 재평가나 폐기 정책)를 쉽게 찾을 수 있습니다. 같은 문제를 저장소 내부 기능 중심으로 보는 표준이 OAIS 참조모형이고, 이 모형은 저장소에 닿기 전 연구자의 생성 활동까지 포함한다는 점에서 범위가 더 넓습니다.

    자주 하는 오해

    오해바로잡기
    단계를 순서대로 밟아야 하는 절차 규정이다.실제 자료는 단계를 건너뛰거나 되돌아가는 일이 흔합니다. 모형은 점검을 위한 틀이지 필수 순서가 아닙니다.
    보존만을 다루는 모형이다.구상과 생성부터 접근·재이용까지 전 과정을 포함합니다.
    OAIS의 다른 이름이다.OAIS는 아카이브 내부 기능과 정보 패키지를 규정한 ISO 14721이고, 이 모형은 연구자 활동까지 포함하는 순환 틀입니다.
    디지털 자료에만 의미가 있다.이름은 디지털이지만 개념(선별, 평가, 재이용)은 다른 자료에도 통용됩니다. 다만 모형은 디지털 환경을 가정합니다.
    한 기관이 모든 활동을 해야 한다.역할은 연구자, 데이터사서, 시스템 관리자 등에 나뉘며 일부는 외부 서비스에 맡길 수 있습니다.

    논문에서는 이렇게 쓰입니다

    실제 논문에서

    이 용어를 직접 쓴 국내 논문 문장을 아직 수집하지 못했습니다. 수집되는 대로 출처와 함께 싣겠습니다.

    예시 문장

    아래는 용어의 쓰임을 보여 주려고 만든 예시로, 실제 논문에서 가져온 문장이 아닙니다.

    본 연구는 DCC 큐레이션 생애주기모형의 각 단계를 기관레포지토리 운영 프로세스에 대응시켜 서비스 공백을 분석하였다.

    DCC 모형의 단계를 실제 기관레포지토리 업무 절차와 비교하여 개선점을 도출하는 연구방법을 설명한 문장이다.

    "한 대학 도서관은 DCC 생애주기모형의 보존작업 단계를 기준으로, 기탁된 연구데이터 파일의 포맷을 장기보존이 가능한 형식으로 변환하는 절차를 설계하였다."

    이 문장은 모형의 여러 단계 중 보존 단계 하나를 실제 업무 절차로 구체화한 사례입니다. 모형이 추상적인 순환도가 아니라 실무 설계의 기준으로 쓰일 수 있음을 보여줍니다.

    조금 더 깊게 보면

    모형은 순환 구조를 강조하지만 실제 연구데이터는 단계를 건너뛰거나 되돌아가는 경우가 많아, 모형을 절차 규정으로 오독하면 실무와 어긋납니다. OAIS가 저장소 내부 기능에 초점을 두는 반면 이 모형은 생성 단계의 연구자 활동까지 포함한다는 점에서 범위가 다릅니다.

    DCC 큐레이션생애주기모형은 개념화부터 생성, 평가·선정, 처분, 재사용에 이르는 단계를 순환 구조로 제시해, 각 단계에서 필요한 관리 행위를 체계적으로 계획하도록 돕는다. 순환 구조로 설계된 만큼 재사용 단계에서 얻은 피드백이 다시 개념화 단계로 이어지는 반복적 개선을 전제로 한다.

    모형의 각 단계마다 필요한 역할(연구자, 데이터사서, 시스템관리자)이 다르게 배정되는 경우가 많다.

    주의할 점

    생애주기모형은 순차적으로 보이지만 실제로는 각 단계가 반복적·순환적으로 이루어지며 특정 단계로 되돌아갈 수 있다는 점에 유의해야 한다.

    헷갈리기 쉬운 용어

    디지털 자료의 관리와 보존을 말하는 용어와 표준이 비슷합니다.

    용어무엇인가범위
    큐레이션 생애주기모형DCC가 제시한 순환 모형구상부터 재이용까지 전 과정
    OAIS 참조모형장기 보존 아카이브의 기능과 정보모형 표준주로 저장소 내부
    디지털 큐레이션디지털 자료를 장기 관리하는 활동 전반활동 개념
    연구자료 큐레이션원자료를 재사용할 수 있게 정리·관리하는 작업연구 데이터 중심
