    그리드시스템 (Grid System)

    고고학
    한 줄 정의: 발굴조사구역을 일정한 크기의 격자로 구획하여 각 격자마다 좌표를 부여함으로써 유물과 유구의 출토 위치를 체계적으로 기록하는 방법이다.

    쉽게 풀면

    발굴 현장을 바둑판처럼 네모난 칸으로 나누고 각 칸에 번호를 붙여서 물건이 나온 위치를 정확히 기록하는 방법이다.

    왜 중요한가

    발굴 구역을 일정한 크기의 격자로 나누어 관리하는 방식으로, 넓은 유적을 체계적으로 구획해 조사 진행 상황을 통제하고 유물·유구의 위치를 격자 좌표로 간편하게 기록할 수 있게 해 줍니다. 동일한 좌표 체계를 지표조사나 유물 분포 분석에도 적용하면 서로 다른 조사 결과를 비교할 수 있게 되어, 그리드시스템은 발굴 기록의 표준화와 재현 가능성을 높이는 기초 도구로 다뤄진다.

    논문에서는 이렇게 쓰입니다

    조사구역을 5m×5m 그리드시스템으로 구획하고 각 그리드에 알파벳과 숫자를 조합한 좌표를 부여하여 출토유물의 위치를 기록하였다.

    조사 방법 항목에서 발굴 현장의 공간 관리 체계를 설명할 때 사용되며, 이후 공간분석이나 유물 분포도 작성의 기초 좌표 자료가 된다.

    발굴 그리드시스템의 좌표 오차가 유물 분포도 작성의 정확도에 미치는 영향을 검토하였다.

    논문에서는 그리드시스템이 발굴 기록의 표준화와 재현 가능성을 높이는 기초 도구로 다뤄진다.

    조금 더 깊게 보면

    격자는 인위적 구획일 뿐 실제 유구의 경계와 무관하게 그어지므로, 하나의 유구가 여러 격자에 걸쳐 있을 경우 격자별로 분리 기록된 자료를 다시 통합해서 해석해야 유구 전체상을 파악할 수 있습니다. 그리드시스템은 발굴 현장뿐 아니라 지표조사나 유물 분포 분석에서도 동일한 좌표 체계를 적용해 서로 다른 조사 결과를 비교할 수 있게 해준다는 점에서 방법론적 의의가 크다. 격자는 인위적 구획일 뿐 실제 유구의 경계와 무관하게 그어지므로, 하나의 유구가 여러 격자에 걸쳐 있을 경우 격자별로 분리 기록된 자료를 다시 통합해서 해석해야 유구 전체상을 파악할 수 있다. 격자 번호는 발굴 기록 카드, 사진, 유물 라벨에 일관되게 기입되어야 자료 간 혼선을 막을 수 있다.

    주의할 점

    그리드 경계가 실제 유구를 가로질러 지나가는 경우 유구가 여러 구획으로 분절되어 기록될 수 있으므로 통합 도면화 작업이 별도로 필요하다. 그리드 경계가 실제 유구를 가로질러 지나가는 경우 유구가 여러 구획으로 분절되어 기록될 수 있으므로 통합 도면화 작업이 별도로 필요하다. 측량 오차가 누적되면 격자 좌표 자체가 실제 위치와 어긋날 수 있어 정기적인 기준점 재확인이 필요하다.
