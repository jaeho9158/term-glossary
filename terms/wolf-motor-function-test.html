    울프 운동기능 검사 (Wolf Motor Function Test)

    재활학·물리치료학
    한 줄 정의: 여러 상지 과제를 수행하는 데 걸린 시간과 동작의 질을 함께 평가하는 뇌졸중 상지 기능 검사입니다.

    쉽게 풀면

    손을 탁자 위에 올리기, 캔 들어 올리기, 연필 집기처럼 쉬운 동작부터 복잡한 동작까지 차례로 하게 하면서 걸리는 시간을 재고 동작이 얼마나 자연스러운지도 점수로 매깁니다. 빠르기와 질을 동시에 본다는 점이 특징입니다.

    왜 중요한가

    강제유도운동치료의 대규모 임상시험에서 주요 결과 변수로 쓰이면서 널리 알려졌고, 지금도 상지 기능 향상을 보고하는 뇌졸중 재활 논문에서 자주 쓰입니다.

    논문에서는 이렇게 쓰입니다

    "강제유도운동치료 후 울프 운동기능 검사의 평균 수행 시간은 유의하게 단축되었고 기능 능력 점수는 증가하였다."

    시간 점수와 질 점수 두 지표를 함께 보고하는 전형적 서술입니다.

    조금 더 깊게 보면

    Wolf 등이 개발하고 이후 뇌졸중 환자용으로 수정된 판이 널리 쓰입니다. 기능 과제들과 근력 과제로 구성되며, 각 과제는 제한 시간 안의 수행 시간과 0~5점의 기능 능력 척도로 채점합니다. 수행하지 못하면 최대 제한 시간을 기록하므로 분석 시 중앙값이나 로그 변환을 쓰는 경우가 있습니다.

    주의할 점

    기존 항목 '강제유도운동치료'는 치료법이고 울프 운동기능 검사는 그 효과를 재는 도구입니다. 수행 시간은 짧을수록, 기능 능력 점수는 높을수록 좋다는 방향 차이에 주의해야 합니다.
