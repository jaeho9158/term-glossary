    사용자여정지도 (user journey map)

    디자인학
    한 줄 정의: 사용자가 목표를 달성하기까지 거치는 단계별 행동, 생각, 감정을 시간 순으로 시각화하여 경험 전반을 조망하는 도구이다.

    쉽게 풀면

    사용자가 처음부터 끝까지 어떤 과정을 거치면서 무엇을 느끼는지를 지도처럼 한눈에 정리한 그림이에요.

    논문에서는 이렇게 쓰입니다

    "사용자여정지도 분석 결과 결제 단계에서 감정 곡선이 급격히 하락하는 지점이 확인되었다."

    경험의 각 단계에서 사용자 감정 변화를 시각화하여 문제 지점을 식별한 분석 사례를 설명한다.

    주의할 점

    사용자여정지도는 대표적인 하나의 경로만 다루기 쉬워, 다양한 사용자 유형별로 경로가 달라질 수 있다는 점을 간과하지 않아야 한다.
