# 카테고리 개편 + 검색/브라우징 개선 설계

## 배경 / 문제
- `terms.json` 총 3,755개 용어가 13개 대분류(stat/method/tool/ethics/physchem/bioearth/neuro/medhealth/psych/socialecon/eng/cs/math)에만 담겨 있고, 카테고리당 평균 ~290개.
- 하위분류는 `assets/category-data.js`의 `SUB_CATEGORY_RULES`에 슬러그를 수동 나열하는 방식인데, 전체 108개 슬러그만 커버 — 96% 이상이 "일반 용어" 버킷에 뭉쳐 있어 사실상 미분류 상태.
- 검색(`assets/site.js` `render()`)은 제목/영문/별칭 단순 substring 포함 여부만 필터링, 정렬/우선순위 없음. 자동완성 없음.
- 결과: 용어가 많아질수록 원하는 용어를 찾기 어렵고, 카테고리 브라우징도 300개 가까운 평면 목록이라 불편.

## 목표
1. `terms.json`에 `subcategory` 필드를 추가해 하위분류를 데이터 자체에 귀속시킨다 (외부 슬러그 목록 매핑 방식 폐기).
2. 13개 대분류는 유지하고, 카테고리당 4~6개의 고정 하위분류 체계를 설계해 기존 3,755개 용어를 전량 재분류한다.
3. 검색 결과를 정확도 순(완전일치 > 접두일치 > 포함)으로 정렬하고, 각 결과에 카테고리/하위분류 태그를 표시하며, 타이핑 중 자동완성 드롭다운을 제공한다.
4. 이후 신규 용어 생성 루틴(`glossary-term-expansion` 스케줄러)도 하위분류를 함께 지정하도록 갱신해 재방치를 막는다.

## 데이터 모델 변경
`terms.json` 각 항목에 `subcategory` (string) 필드 추가:
```json
{
  "slug": "p-value",
  "title_ko": "p값",
  "title_en": "p-value",
  "categories": ["stat"],
  "subcategory": "추론통계·가설검정",
  "definition": "...",
  "related": [...]
}
```
- 용어가 `categories`를 2개 이상 가질 경우, `subcategory`는 첫 번째(주) 카테고리 기준 하위분류로 지정한다.
- `assets/category-data.js`의 `SUB_CATEGORY_RULES` 슬러그 목록 방식은 제거하고, `CATEGORY_LABELS`/`CATEGORY_ORDER`/`CATEGORY_DESCRIPTIONS`는 유지한다. 대신 카테고리별 하위분류 순서를 정의하는 `SUB_CATEGORY_ORDER = { stat: ["기술통계·확률분포", "추론통계·가설검정", ...], ... }` 객체를 새로 추가한다.

## 마이그레이션 (1회성, 기존 3,755개 재분류)
- 카테고리별로 서브에이전트를 배정(카테고리당 1~2개, 총 ~15~20개), 각자 담당 카테고리의 전체 용어 목록(slug/title_ko/definition)을 보고 위 하위분류표 중 하나를 매핑.
- 각 서브에이전트는 `{slug: subcategory}` 매핑 JSON만 반환 (파일 직접 수정 금지 — 병렬 쓰기 충돌 방지).
- 모든 결과 수합 후 스크립트로 `terms.json`에 일괄 반영, 매핑 누락 슬러그가 없는지 검증.

## 검색/브라우징 UI 변경 (`assets/site.js`)
- 검색 매칭 함수에 우선순위 스코어 부여: 완전일치(0) > 접두일치(1) > 포함(2), 동일 점수 내에서는 기존 순서 유지.
- 검색 결과 각 항목에 `카테고리 > 하위분류` 태그를 작게 표시.
- 검색창 입력 이벤트에 자동완성 드롭다운 추가: 상위 8~10개 결과를 드롭다운으로 미리보기, 클릭 시 해당 용어 페이지로 이동. 기존 카테고리 아코디언 렌더링(`render()`)은 그대로 유지하되 드롭다운이 우선 표시.
- 카테고리 브라우징(`category.html`, index의 아코디언)은 `subcategory` 필드를 그룹 키로 사용하도록 `render()`의 `subMap` 로직을 `SUB_CATEGORY_RULES` 조회 방식에서 `term.subcategory` 직접 참조로 변경.

## 검증
- `terms.json` 전체가 유효 JSON이고 모든 항목에 `subcategory`가 존재.
- 각 카테고리별로 `subcategory` 값이 해당 카테고리의 정의된 목록 안에 있는지 검사 (오타/이탈 방지).
- `category.html`/`index.html`을 브라우저에서 열어 하위분류 아코디언이 정상 렌더링되는지, 검색 자동완성이 동작하는지 수동 확인.
