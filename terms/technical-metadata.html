    기술적메타데이터 (Technical Metadata)

    관리메타데이터›기술적메타데이터
    문헌정보학
    한 줄 정의: 디지털 파일의 형식, 해상도, 압축 방식, 생성에 사용된 하드웨어·소프트웨어 환경 등 기술적 속성을 기록하는 메타데이터 유형으로, 파일의 장기 판독 가능성과 마이그레이션 계획 수립에 활용된다.

    쉽게 풀면

    디지털 파일이 어떤 형식으로 만들어졌는지, 어떤 프로그램으로 만들었는지 같은 기술적인 정보를 담은 메타데이터이다.

    왜 중요한가

    디지털 파일의 형식, 해상도, 생성 환경 등 기술적 속성을 기록해 파일의 장기 판독 가능성과 마이그레이션 계획 수립에 활용되며, 디지털보존 실무의 필수 메타데이터 유형으로 다뤄집니다. 보존 담당자는 이 정보를 근거로 어떤 파일들이 조만간 마이그레이션 대상이 되는지 우선순위를 정한다.

    논문에서는 이렇게 쓰입니다

    이 연구는 기술적메타데이터에 기록된 파일 형식 정보를 활용해 노후 포맷 자료의 마이그레이션 대상을 자동으로 식별하는 방법을 제안하였다.

    기술적메타데이터의 파일 형식 정보로 오래된 포맷 자료를 자동으로 찾아낼 수 있다는 점을 제안한 문장이다.

    "디지털 아카이브는 기술적메타데이터를 통해 파일 손상 여부를 주기적으로 점검하는 체계를 구축하였다."

    파일에 담긴 기술 정보를 활용해 시간이 지나도 자료가 손상되지 않았는지 주기적으로 확인할 수 있다는 뜻이다.

    조금 더 깊게 보면

    기술적메타데이터의 구체적 항목은 자료 유형(이미지, 오디오, 텍스트 등)에 따라 서로 다른 표준(예: 이미지용 NISO MIX)을 적용해야 하므로, 단일한 항목 목록으로 일반화하기는 어렵습니다. NISO MIX는 이미지 파일의 압축 방식·색공간·스캐너 모델 등을 표준 필드로 정의하며, 오디오·비디오에는 각각 별도의 기술적메타데이터 표준(예: AES-57)이 쓰인다. 체크섬 값은 파일 무결성 검증에, 생성 소프트웨어 정보는 향후 마이그레이션 시 원본 재현 가능성 판단에 활용된다. 해상도나 색심도 같은 값은 후속 마이그레이션 시 원본과 동등한 품질을 재현할 수 있는지 판단하는 기준으로도 쓰인다. 최근에는 파일 자체에 임베드된 메타데이터(EXIF 등)를 자동 추출해 별도 기록 작업 없이 기술적메타데이터를 채우는 도구도 널리 쓰인다.

    주의할 점

    기술적메타데이터는 파일 형식별로 기록해야 할 세부 속성이 달라, 이미지·음성·영상 등 매체 유형에 따라 별도의 기술적메타데이터 스키마가 필요할 수 있다는 점에 유의해야 한다.

    기술적메타데이터가 자동 생성 도구에 의존할 경우 도구 버전이 바뀌면 값의 형식이나 정밀도가 달라질 수 있어, 장기간에 걸친 값 비교에는 주의가 필요하다.
