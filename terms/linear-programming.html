    선형계획법 (Linear Programming)

    볼록 최적화›선형계획법
    수학
    한 줄 정의: 모든 조건과 목표가 일차식(직선 형태)으로 표현되는 상황에서, 여러 제약 조건을 만족하며 목표를 최대 또는 최소로 만드는 해를 찾는 최적화 기법이다.

    쉽게 풀면

    공장에서 제품 A와 B를 만드는데, 원자재와 작업 시간이 한정되어 있다고 해보자. "이익을 최대로 만들려면 A와 B를 각각 몇 개씩 만들어야 할까?"라는 질문에 답하는 것이 선형계획법이다. 여기서 "선형(linear)"이라는 말은 이익 계산식이나 원자재 사용량 계산식이 모두 단순한 일차식(곱셈과 덧셈만으로 이루어진 직선 형태)이라는 뜻이다. 제약 조건들을 그래프로 그리면 여러 개의 직선이 만드는 다각형 영역이 나오는데, 목표를 최대/최소로 만드는 답은 항상 이 다각형의 꼭짓점 중 하나에서 나온다는 것이 핵심 원리이다.

    왜 중요한가

    선형계획법은 제한된 자원 안에서 최선의 결과를 찾는 문제를 수학적으로 정확히 풀 수 있게 해주는 대표적인 최적화 도구여서, 물류·생산 계획·투자 배분처럼 현실적인 의사결정 문제를 다루는 연구에서 폭넓게 쓰인다. 계산적으로도 비교적 효율적으로 풀리는 알고리즘이 잘 정립되어 있어, 더 복잡한 비선형 최적화 문제를 풀기 전 단계로 문제를 선형 형태로 근사하는 데도 자주 활용된다. 이 때문에 운용과학뿐 아니라 컴퓨터공학, 경제학 등 자원 배분이 핵심인 여러 분야의 논문에서 반복적으로 등장한다.

    어떤 절차인가

    선형계획법(LP)은 요구 조건과 목적이 선형 관계로 표현되는 수학 모형에서 최대 이익이나 최소 비용 같은 최선의 결과를 얻는 방법이다. 수리계획법(수학적 최적화)의 특수한 경우이다. 더 엄밀하게는 선형 등식과 선형 부등식 제약 아래에서 선형 목적함수를 최적화하는 기법이다. 모형의 구성은 다음 순서를 따른다.

    1. 결정변수를 정한다.
    2. 최대화하거나 최소화할 선형 목적함수를 쓴다.
    3. 자원 한도와 같은 선형 제약식을 쓴다. 표준형은 "Ax ≤ b, x ≥ 0 아래에서 cᵀx를 최대화하는 벡터 x를 찾아라"이다.
    4. 제약을 모두 만족하는 해의 집합인 실행가능 영역(볼록 다면체)을 구한다.
    5. 이 다면체 위에서 목적함수가 가장 큰(또는 작은) 점을 찾는다. 그런 점이 있다면 알고리즘이 찾아 준다.

    예를 들어 이익 3x + 2y를 x + y ≤ 4, x + 3y ≤ 6, x ≥ 0, y ≥ 0 아래에서 최대화한다고 하자. 실행가능 영역의 꼭짓점은 (0, 0), (4, 0), (3, 1), (0, 2)이고 목적함수 값은 각각 0, 12, 11, 4이다. 최댓값은 꼭짓점 (4, 0)에서 12이다.

    언제 쓰고 무엇을 얻나

    실제 문제에서 풀이는 심플렉스 방법이 맡는다. 1947년 조지 댄치그가 발명했고, 대부분의 경우 선형계획 문제를 처음으로 효율적으로 풀었다. 이 방법은 실행가능 영역의 꼭짓점, 곧 기저 실행가능해에서 인접한 기저 실행가능해로 옮겨 가는 기하학적 조작이며, 이는 피벗 연산으로 구현된다. 꼭짓점이 최대점이 아니면 그 점에서 나가는 변 가운데 목적함수가 엄격하게 늘어나는 변이 있고, 변이 유한하면 목적함수 값이 더 큰 다른 꼭짓점으로 이어진다.

    연도·인물내용
    1827 푸리에선형 부등식계를 푸는 방법을 발표했다
    1930년대 말소련 수학자 칸토로비치와 미국 경제학자 레온티에프가 각각 독립적으로 실용적 응용을 탐구했다
    1941 히치콕수송 문제를 선형계획으로 정식화하고 심플렉스와 매우 비슷한 풀이를 제시했다
    1946~1947 댄치그미 공군 계획 문제를 위해 일반 선형계획 정식화를 독자적으로 개발하고 심플렉스 방법을 발명했다. 폰 노이만이 쌍대성 이론을 곧바로 추측했다
    1975칸토로비치와 쿠프만스가 노벨 경제학상을 공동 수상했다
    1979, 1984하치얀이 다항 시간에 풀 수 있음을 처음 보였고, 카마르카르가 내점법을 제시했다

    댄치그의 원래 예는 70명을 70개 직무에 가장 알맞게 배정하는 문제였다. 모든 순열을 검사하는 데 필요한 계산은 관측 가능한 우주의 입자 수를 넘는 경우의 수에 이르지만, 선형계획으로 놓고 심플렉스 알고리즘을 쓰면 잠깐이면 최적해를 찾는다.

    논문에는 이렇게 적는다

    • 결정변수, 목적함수, 제약식을 모두 적어 모형을 재현할 수 있게 한다. 모든 관계가 선형이라는 가정이 현실에 맞는지 서술한다.
    • 사용한 풀이 방법(심플렉스, 내점법 등)과 소프트웨어를 밝히고, 최적해와 목적함수 값을 보고한다.
    • 쌍대 문제와 그림자 가격 같은 민감도 결과를 함께 제시하면 자원 한도 변화에 따른 해석이 쉬워진다.
    • 수송, 에너지, 통신, 제조 같은 산업에서 계획, 경로, 일정, 배정, 설계 문제에 쓰이며, 다른 최적화 문제를 푸는 알고리즘의 하위 문제로 선형계획이 풀리기도 한다는 점을 언급한다.
    • 변수에 정수 제약이 붙으면 선형계획이 아니므로 정수계획법으로 구분해 쓴다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "자원 배분 문제는 선형계획법(linear programming)으로 정식화되었으며, 심플렉스 알고리즘을 이용해 최적해를 구했다."

    이 문장은 "자원을 어떻게 나눠야 가장 효율적인지를 일차식으로 이루어진 수학 문제로 바꾸고, 그 문제를 표준 알고리즘으로 풀어 최선의 답을 찾았다"는 뜻이다. 운용과학, 경제학, 네트워크 설계 논문에서 자원 최적 배분을 다룰 때 흔히 등장한다.

    "생산 공정의 재고 및 운송 비용을 최소화하는 문제를 선형계획법으로 모델링하고, 상용 최적화 솔버를 이용해 해를 구하였다."

    공급망·물류 연구에서는 여러 공장과 창고 사이의 운송량을 결정하는 문제를 선형계획법으로 표현해 총비용을 최소화하는 배치를 찾는 데 이 개념이 활용된다.

    "포트폴리오 내 자산 배분 문제를 선형계획법으로 근사하여, 제약 조건 하에서 기대수익을 최대화하는 투자 비중을 산출하였다."

    금융공학 연구에서는 위험을 단순화한 형태로 다룰 때 자산 배분 문제를 선형계획법 형태로 정식화해 계산하는 경우가 있다.

    조금 더 깊게 보면

    선형계획법 문제를 풀 때는 원래 문제(주문제)와 짝을 이루는 쌍대문제(dual problem)를 함께 고려하는 경우가 많은데, 쌍대문제의 해는 각 제약 조건이 최적값에 얼마나 영향을 미치는지에 대한 경제적 해석(그림자 가격 등)을 제공한다. 실제 계산에는 다각형의 꼭짓점을 따라가며 해를 찾는 심플렉스법과, 다각형 내부를 통과하며 해에 접근하는 내점법(interior-point method)이 주로 쓰이며, 문제의 규모나 구조에 따라 어느 방법이 더 효율적인지가 달라진다. 변수 중 일부가 정수여야 하는 경우에는 정수계획법(integer programming)이라는 확장된 형태로 다뤄진다.

    주의할 점

    선형계획법은 목적 함수와 제약 조건이 모두 일차식일 때만 적용할 수 있다. 목적 함수나 제약 조건에 제곱, 곱셈 항 등 비선형 요소가 들어가면 볼록함수 최적화나 비선형계획법 등 다른 방법을 써야 하며, 이때는 KKT 조건처럼 좀 더 일반적인 최적화 이론이 필요하다.

    헷갈리기 쉬운 용어

    용어무엇인가
    단체법선형계획 풀이의 대표 알고리즘으로, 꼭짓점을 따라 옮겨 간다
    내점법실행가능 영역의 내부를 지나 최적해에 다가가는 방법
    볼록 최적화선형계획법을 특수한 경우로 포함하는 더 넓은 최적화 분야
    정수계획법변수가 정수여야 하는 최적화 문제
    쌍대성이론선형계획과 그 쌍대 문제의 관계를 다루는 이론
