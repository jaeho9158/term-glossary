    락 프리 자료구조 (lock-free data structure)

    컴퓨터과학·AI
    한 줄 정의: 잠금 없이 원자적 연산만으로 여러 스레드가 안전하게 조작할 수 있는 자료구조입니다.

    쉽게 풀면

    여러 스레드가 같은 자료를 고칠 때 보통은 자물쇠를 걸어 한 번에 한 명만 들어가게 합니다. 락 프리 자료구조는 자물쇠 대신, 값을 읽고 바꾸는 일을 하드웨어가 통째로 보장하는 원자적 명령으로 처리합니다. 다른 스레드가 먼저 바꿔 버렸으면 실패를 감지해 다시 시도하는 방식으로, 누구도 멈춰 기다리지 않습니다.

    왜 중요한가

    락을 쥔 스레드가 중간에 멈추면 나머지 전부가 기다려야 하는 문제를 없애 주어, 지연이 중요한 시스템이나 인터럽트 처리 경로에서 유리합니다. 어떤 스레드가 죽거나 지연되어도 전체 시스템은 반드시 진전한다는 보장이 성립합니다. 고성능 큐, 메모리 할당기, 런타임 내부 구조 등에서 실제로 널리 쓰입니다.

    논문에서는 이렇게 쓰입니다

    "비교 후 교환 연산 기반 락 프리 큐를 도입하여 고경합 구간에서 잠금 기반 구현 대비 꼬리 지연을 크게 낮추었다."

    경쟁이 심한 상황에서 자물쇠를 쓰지 않는 방식이 최악 지연을 줄였다는 뜻입니다.

    "락 프리 자료구조를 적용한 결과 다중 스레드 환경에서 잠금 대기로 인한 성능 저하가 크게 줄어드는 것으로 나타났다."

    잠금을 쓰지 않음으로써 여러 스레드가 동시에 접근할 때 생기는 병목을 줄인다는 점을 설명한 서술입니다.

    조금 더 깊게 보면

    핵심 도구는 비교 후 교환 명령으로, 기대한 값과 현재 값이 같을 때만 새 값으로 바꾸고 결과를 알려 줍니다. 진행 보장은 강도에 따라 나뉘어, 적어도 한 스레드는 반드시 진전하는 락 프리와 모든 스레드가 유한 단계 안에 끝나는 웨이트 프리로 구분됩니다. 값이 A에서 B로 갔다가 다시 A로 돌아와 변화를 눈치채지 못하는 ABA 문제와, 다른 스레드가 참조 중인 노드의 안전한 회수 문제가 구현의 최대 난점이며 태그 포인터나 위험 포인터로 대응합니다. 뮤텍스 같은 락으로 상호 배제를 강제하는 대신, compare-and-swap(CAS) 같은 원자적 하드웨어 명령으로 공유 자료구조를 갱신하며, 여러 스레드가 동시에 시도하더라도 적어도 하나의 스레드는 유한한 단계 안에 반드시 진행에 성공하도록 설계합니다.

    주의할 점

    뮤텍스를 쓰지 않는다고 해서 항상 빠른 것은 아니며, 경합이 낮은 상황에서는 잘 만든 잠금 구현이 더 빠른 경우도 흔합니다. 올바른 구현에는 메모리 배리어에 대한 정확한 이해가 필수라서, 직접 작성하기보다 검증된 라이브러리를 쓰는 것이 권장됩니다. 락이 없어 스레드가 뻗어도 다른 스레드가 멈추지 않는다는 장점이 있지만, CAS 재시도 루프에서 특정 스레드가 계속 실패하는 기아(starvation) 가능성이 남아 있어 이를 없애려면 더 강한 보장인 wait-free 설계가 필요합니다.

    관련 용어

    메모리 배리어 뮤텍스 경쟁 상태 임계 구역 교착 상태 프로세스와 스레드 분산 합의 알고리즘 결함허용 GPU(그래픽 처리 장치) 클러스터 컴퓨팅
