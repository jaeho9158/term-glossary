    부호화 모델 (Encoding model)

    뇌과학·신경과학 측정·도구
    한 줄 정의: 자극이나 과제에서 뽑은 특징으로 뇌 활동을 예측하는 회귀 모델로, 예측이 되는 뇌 부위에는 그 특징의 정보가 담겨 있다고 해석하는 분석 방법이다.

    쉽게 풀면

    영화나 음성 같은 자극에서 움직임의 양, 단어의 의미 같은 특징을 숫자로 뽑아 두고, 이 특징들로 뇌 신호가 어떻게 변할지를 맞춰 보는 방법이다. 어떤 뇌 부위에서 예측이 잘 맞으면 그 부위가 그 특징을 다루고 있다고 해석한다.

    왜 중요한가

    자연스러운 영화나 이야기처럼 복잡한 자극에서 뇌 부위별로 무엇을 표현하는지를 보는 fMRI 연구에서 쓰인다. 논문에서는 어떤 특징 공간을 썼는지와 예측 성능을 어떻게 검증했는지가 핵심이다.

    어떤 절차인가

    • 자극을 지각하거나 과제를 수행하는 동안 뇌 활동을 기록한다. 이어서 각 시점의 자극에서 특징 집합(특징 공간)을 뽑는다. 예를 들어 영상은 화면 부위별 움직임의 양이나 장면에 있는 물체의 의미 범주로 나타낼 수 있다(Dupré la Tour 등, 2025).
    • 각 특징 공간은 ‘이 정보가 뇌 어딘가에 표현되어 있다’는 하나의 가설이다. 이를 검정하려고 특징에서 뇌 활동을 예측하는 회귀 모델을 훈련시키며, 그 모델이 부호화 모델이다(Dupré la Tour 등, 2025).
    • 복셀별 부호화 모델(VEM)에서는 fMRI의 공간 단위(복셀)마다 모델을 따로 맞춘다(Dupré la Tour 등, 2025).
    • 고차원 모델은 과적합 위험이 크므로 능형 회귀 같은 정규화를 쓴다. 자극과 BOLD 반응 사이의 시간 지연을 고려하려고 특징을 여러 지연 시간으로 복제해 지연별 가중치를 따로 추정한다(Dupré la Tour 등, 2025).

    언제 쓰고 무엇을 얻나

    • 얻는 것: 예측 정확도를 피질 표면에 투영한 지도로 특징 공간의 정보가 피질 전체에 어떻게 표현되는지 본다. 회귀 가중치로는 복셀이 어떤 특징 조합에 가장 잘 반응하는지(복셀 조율)를 본다(Dupré la Tour 등, 2025).
    • 가설 비교: 같은 자료에서 여러 특징 공간의 예측 정확도를 비교하면 서로 경쟁하는 가설을 비교하는 셈이다. 한 복셀이 여러 특징 공간을 함께 표현할 수 있으므로 여러 특징 공간을 한꺼번에 넣은 결합 모델도 맞춘다(Dupré la Tour 등, 2025).
    • 장점: 많은 특징을 동시에 쓸 수 있어 자연스러운 자극과 과제 분석에 맞다. 모델 성능을 훈련에 쓰지 않은 별도 시험 자료로 평가해서 과적합과 1종 오류 부풀림을 줄이고, 결과가 새 참가자와 새 자극으로 일반화된다고 소개된다(Dupré la Tour 등, 2025).
    • 적용 예: 다섯 가지 특징 공간(음향부터 고차 개념까지)을 쓴 복셀별 부호화 모델로 자연 언어 청취 fMRI 자료를 분석했다. 소뇌의 언어 반응은 낮은 수준의 음향·음소 특징보다 고차 개념 특징으로 거의 다 설명되었다고 보고했다(LeBel 등, 2021).

    논문에는 이렇게 적는다

    자극과 과제, 특징 공간과 추출 방법, 회귀 방법과 정규화, 시간 지연 처리 방식, 훈련·시험 자료의 분할, 예측 성능 지표(결정계수 R2나 상관계수 r)와 유의성 검정 방법을 적는다. 잡음 한계(noise ceiling)를 추정했다면 함께 밝힌다. 특징 공간끼리 상관이 있으면 결합 모델에서 각 공간의 기여를 어떻게 나눴는지도 쓴다.

    논문에서는 이렇게 쓰입니다

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "소뇌는 피질에 비해 ‘사회’나 ‘사람’ 같은 단어 범주를 표현하는 복셀의 비율이 높았고, 정신·구체·장소 단어를 표현하는 복셀은 적었다."

    복셀별 부호화 모델의 가중치로 부위마다 선호하는 의미 범주를 비교한 결과이다.

    "WordNet 의미 특징은 초기 시각 영역과 움직임에 민감한 영역도 예측하였는데, 의미 특징이 저수준 시각 특징과 상관되어 있기 때문이다."

    특징 공간끼리 상관이 있으면 예측이 잘 맞아도 어떤 정보 때문인지 구별하기 어렵다는 예이다.

    조금 더 깊게 보면

    능형 회귀의 정규화 강도는 교차 검증으로 정하며, 띠 능형 회귀에서는 복셀마다 특징 공간별로 따로 정한다. 한 복셀에서 예측이 가장 좋은 특징 공간을 그 복셀에 표현된 정보에 대한 가장 좋은 가설로 본다.

    특징 공간끼리 상관이 있을 때는 띠 능형 회귀가 구별에 도움을 주고, 분산 분할 등으로 결합 모델에서 각 공간의 기여를 추정한다. 잡음 한계는 복셀의 예측 정확도가 도달할 수 있는 상한으로, 같은 자극을 반복했을 때 재현되는 설명 가능 분산과 연결된다.

    주의할 점

    특징 공간이 서로 상관되면 예측이 잘 맞아도 어떤 정보 때문인지 해석이 달라질 수 있다.
