    경계주사 (Boundary Scan (JTAG))

    전기전자공학
    한 줄 정의: 칩의 입출력 핀마다 셀을 두고 사슬로 이어, 기판 위 배선 연결 상태를 검사하는 표준 기법입니다.

    쉽게 풀면

    부품이 촘촘히 실장된 기판에서는 납땜이 제대로 되었는지 탐침으로 일일이 확인하기 어렵습니다. 경계주사는 칩의 각 핀 안쪽에 작은 셀을 두고 이들을 사슬로 이어, 전용 인터페이스로 원하는 값을 핀에 내보내거나 핀에 들어온 값을 읽을 수 있게 합니다. 한 칩이 값을 내보내고 이웃 칩이 그 값을 읽으면, 두 칩 사이 배선이 끊겼는지 붙었는지 곧바로 알 수 있습니다.

    왜 중요한가

    표면실장과 볼 그리드 배열 패키지가 보편화되면서 물리적 탐침 접근이 어려워졌고, 이 문제를 풀기 위해 만들어진 국제 표준 인터페이스가 산업 전반에 자리 잡았습니다. 지금은 기판 검사뿐 아니라 내부 스캔 테스트의 접근 통로, 프로그래머블 소자의 구성 데이터 주입, 프로세서 디버깅 포트로도 널리 쓰여 사실상 범용 검사·디버그 창구 역할을 합니다.

    논문에서는 이렇게 쓰입니다

    "경계주사 인터페이스를 통해 기판 위 소자 간 배선의 단선과 단락을 검사하고 동일 포트로 내부 스캔 테스트를 수행하였다."

    같은 표준 포트가 기판 검사와 칩 내부 검사에 모두 쓰이는 실제 활용을 보여줍니다.

    조금 더 깊게 보면

    인터페이스는 클록, 모드 선택, 직렬 입력, 직렬 출력의 소수 신호로 구성되며, 모드 선택 신호로 움직이는 유한상태기계가 명령 레지스터와 여러 데이터 레지스터 가운데 무엇을 사슬에 연결할지 정합니다. 대표적인 명령으로는 핀 값을 가로채 구동하는 외부 검사 명령, 칩을 투명하게 통과시키는 우회 명령, 부품 식별 정보를 읽는 명령이 있습니다. 여러 칩을 직렬로 이어 하나의 사슬로 만들 수 있어 기판 전체를 한 포트로 검사할 수 있으며, 제조사가 제공하는 표준 기술 파일로 각 칩의 사슬 구조를 도구에 알려 줍니다.

    주의할 점

    경계주사 포트는 칩 내부에 접근할 수 있는 강력한 통로이므로, 제품 출하 시 잠그지 않으면 보안 취약점이 됩니다. 스캔체인 테스트가 칩 내부 논리를 검사한다면, 이 항목은 주로 칩 바깥의 연결 상태를 검사합니다.

    관련 용어

    테스트 용이화 설계 스캔체인 테스트 내장 자체 시험 칩 패키징 기술 하드웨어 트로이목마 탐지 누설전류 메커니즘 정적 타이밍 분석 VLSI 설계 흐름 게이트 산화막 두께 단채널 효과
