# 애드센스 "가치가 별로 없는 콘텐츠" 반려 대응 — 설계

작성일: 2026-09-09 · 상태: 구현 완료 (2026-09-09)

## 1. 배경

애드센스가 "가치가 별로 없는 콘텐츠"(최소 콘텐츠 요건 미충족)로 반려했다. 원인 분석 결과, 개별 용어 페이지 품질보다 **사이트 구조 자체** — 동일 템플릿을 38,529회 반복한 사전 페이지 + 페이지마다 광고 — 가 핵심 원인으로 판단됐다. 부수적으로, 아직 배포되지 않은 `category/{code}.html`(카테고리별 정적 링크 목록)이 **링크 385개 + 설명 2줄**인 도어웨이 페이지 패턴이라 이대로 나가면 재반려 사유를 하나 더 만든다.

용어 개별 콘텐츠 심화(정의문 보강)는 **다른 세션이 이미 진행 중**이라 이 설계는 건드리지 않는다. 이 설계가 다루는 것은 사용자가 확정한 세 가지다:

- **A. 카테고리 허브 페이지 개선** — 도어웨이 패턴 제거, 먼저 진행
- **B. 용어 비교 콘텐츠 파일럿** — 사전을 넘어서는 편집적 콘텐츠, 1~2개로 시작 후 반응 보고 확장
- **3. `about.html` 신뢰 신호 보강** — 운영 주체 명시

## 2. A — 카테고리 허브 페이지 개선

### 현재 문제

`scripts/generate-category-pages.js`가 만드는 `category/{code}.html`은 `CATEGORY_DESCRIPTIONS[code]`(55~99자, 원래 메타 설명용) 한 문장 + 그 분야 전체 용어를 정렬 없이 한 줄씩 나열한 `<ul>`뿐이다. `stat`의 경우 링크 385개, 본문 순수 텍스트는 링크 제외 약 500~700자 — Google이 예시로 드는 "얇은 콘텐츠·도어웨이 페이지" 패턴과 정확히 일치한다.

### 변경

1. **하위분류별 섹션화**: `SUB_CATEGORY_ORDER[code]`(전 분야 이미 100% 채워짐, 2026-08-30 백필 완료)로 용어를 그룹핑해 `<h2>하위분류명</h2>` + 그 아래 용어 목록으로 나눈다. 하위분류당 용어가 3개 미만이면 "기타" 섹션으로 접어 목록이 지저분해지지 않게 한다(`stat`처럼 표류하는 1~2개짜리 하위분류가 실제로 있음 — 2026-08-30 백필 시 목록에 없는 근사값으로 배정된 결과로 추정, 이번 설계에서 재분류하지 않고 접기만 한다).
2. **진짜 소개 문단**: 메타 설명(`CATEGORY_DESCRIPTIONS`, SERP 노출용 55~99자)과 별개로, 페이지 본문에 들어갈 **3~5문장짜리 소개**를 새 데이터 `CATEGORY_INTRO`로 만든다. 내용: 이 분야가 다루는 범위, 하위분류들이 서로 어떻게 다른지, 어떤 상황의 독자가 주로 찾는지. 98개 분야 전부 필요하므로 기존에 쓰던 **집필 서브에이전트(분야당 1개) → 검수 서브에이전트(사실성·중복·분량 확인)** 파이프라인을 그대로 재사용한다(이번 세션 초반 "용어 심화" 작업에서 쓴 것과 같은 구조).
3. **비교 콘텐츠 연결(B 완성 후)**: 하위분류 섹션 중 B의 비교 페이지가 다루는 용어가 있으면 그 옆에 "🔍 t검정과 무엇이 다른가" 같은 링크를 붙인다. B가 파일럿 단계라 처음엔 표시할 게 거의 없지만, 렌더링 로직 자체는 이번에 넣어 나중에 B를 확장하면 자동으로 채워지게 한다.
4. **`category.html`(허브의 허브)**: 정적 링크 목록(`<!--STATIC_CATEGORY_GROUPS-->`, 다른 세션 작업)만 있고 자체 설명이 없다. 여기에도 3~4문장짜리 총괄 소개 하나만 추가한다(98개 분야 전부는 과함 — 사이트 전체를 아우르는 문단 하나로 충분).

### 안전장치

- `renderCategoryPage`는 결정론적 생성기(기존 `build-term-page.js`와 같은 원칙)로 유지 — 서브에이전트는 `CATEGORY_INTRO` 텍스트만 산출하고, HTML 조립·이스케이프는 스크립트가 한다.
- 검수 에이전트는 각 소개 문단이 (a) 그 분야 하위분류 이름을 실제로 언급하는지 (b) 다른 분야 설명과 복붙 수준으로 겹치지 않는지 (c) 사실관계 오류가 없는지 확인한다.

## 3. B — 용어 비교 콘텐츠 파일럿

### 목적

사전적 정의 나열을 넘어서는 편집적 콘텐츠가 있다는 걸 보여준다. "헷갈리는 두 용어를 나란히 비교"는 검색 수요도 있고(예: "t검정 anova 차이") 사전 형식으로는 못 담는 가치를 준다.

### 파일럿 범위

- 카테고리 1개(통계, `stat`)에서 **1~2개**만 만든다.
- 후보 1: **t검정 vs 분산분석**(`t-test`, `anova` — 둘 다 실존, 같은 하위분류 "추론통계·가설검정" 확인됨).
- 후보 2(여유 있으면): **1종 오류 vs 2종 오류**(`type-1-error`, `type-2-error` — 둘 다 실존 확인됨).
- 반응(체류시간·검색 유입)을 보고 확장 여부를 나중에 판단한다. 확장은 "같은 과정을 더 많이 돌리는 것"이라 이번 설계에서 규모를 키울 필요는 없다.

### URL·구조

- 새 디렉터리 `compare/`, 파일명 `<slugA>-vs-<slugB>.html`(알파벳 순 — `anova-vs-t-test.html`처럼 순서가 흔들리지 않게 슬러그를 정렬해 고정).
- 페이지 구성: 정의 나란히 보기(표) → "핵심 차이 한 줄" → 각각 언제 쓰는지 → 흔한 혼동 지점 → 두 용어 각각의 `terms/*.html`로 링크.
- 생성기는 A와 마찬가지로 결정론적: 서브에이전트는 콘텐츠 JSON만 쓰고, HTML 조립은 스크립트가 한다(용어 심화 파이프라인의 `build-term-page.js` 패턴 재사용).

### 검수

콘텐츠가 새 형식이라 검수 기준도 새로 정한다: (a) 표의 각 항목이 실제로 대조되는 내용인가(같은 말 두 번 반복 아닌지) (b) "핵심 차이"가 실제 핵심을 짚는지 (c) 두 용어의 기존 `terms/*.html` 정의와 모순되지 않는지.

## 4. `about.html` 신뢰 신호 보강

### 확인된 사실 (지어내지 않음)

- 운영 주체명: **지니어스 클럽**
- 상태: **비영리 사단법인 설립을 준비 중인 단체** — 등록 완료가 아님. "등록된 비영리법인"처럼 읽히는 표현 금지.
- 그 외(설립일·인원 수·공식 명칭의 정확한 성격 등)는 확인된 바 없으므로 추가 질문 없이는 쓰지 않는다.

### 변경

- "운영 안내" 절 앞(또는 안)에 운영 주체 소개를 추가: "이 사이트는 지니어스 클럽이 운영합니다. 지니어스 클럽은 비영리 사단법인 설립을 준비하고 있는 단체로, …" 식으로 사실 그대로만.
- "콘텐츠 구성" 절에 있는 "신뢰할 수 있는 학술 자료와 연구 문헌을 참고"라는 기존 문구는 유지하되, 바로 아래에 **용어 선정·작성·검수가 실제로 어떻게 이뤄지는지**(예: 초안 작성 후 별도 검수 단계를 거친다는 등, 실제 운영 방식과 일치하는 선에서) 구체화한 문단을 한 단락 추가한다. 정확한 문구는 계획 실행 시 사용자에게 실제 검수 방식을 한 번 확인받는다(이 설계 문서에서 확정하지 않음 — 지어내지 않기 위해).
- 새로운 사실 주장(수상 이력, 회원 수, 파트너십 등)은 추가하지 않는다.

## 5. 범위 밖

- 개별 용어 페이지 심화(다른 세션 진행 중) — 건드리지 않음.
- B의 확장(파일럿 2개 이후 추가 생산) — 파일럿 결과를 보고 별도 논의.
- `stat`처럼 표류하는 소규모 하위분류의 재분류 — 이번엔 "기타"로 접기만 하고, 재분류 자체는 별도 작업.
- 광고 배치/노출 조정(원인 분석 때 제시했던 선택지 1번) — 이번엔 다루지 않음.

## 6. 완료 기준

- `category/{code}.html` 98개 전부가 하위분류 섹션 + 소개 문단을 갖추고, 어떤 페이지도 "설명 2줄 + 평면 링크 목록"이 아니다.
- `compare/` 페이지 1~2개가 생성되고, 관련 `terms/*.html`·`category/stat.html`에서 상호 링크된다.
- `sitemap.xml`에 `compare/*.html`이 포함된다.
- `about.html`에 지니어스 클럽·미등록 상태가 사실 그대로 명시된다.
- `npm test` 통과, 브라우저에서 카테고리 허브 3개(용어 많은 곳/적은 곳/중간)와 비교 페이지 1개 육안 확인.
