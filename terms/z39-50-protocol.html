    Z39.50 프로토콜 (Z39.50 Protocol)

    문헌정보학
    한 줄 정의: 서로 다른 도서관 시스템의 목록 데이터베이스를 하나의 방식으로 검색·조회할 수 있게 하는 정보검색 통신 표준입니다.

    쉽게 풀면

    도서관마다 쓰는 검색 시스템이 달라도, 같은 약속으로 질문하고 답을 받으면 서로 검색할 수 있습니다. Z39.50은 그런 약속을 정한 표준입니다. 사서가 다른 도서관 목록에서 서지레코드를 가져오는 복사목록 작업에 오래 쓰였습니다.

    왜 중요한가

    통합검색, 복사목록, 상호대차 시스템의 기반 기술로 도서관 시스템 상호운용성 연구에서 자주 언급됩니다. 웹 기반 후속 표준으로의 전환 논의에서도 기준이 됩니다.

    논문에서는 이렇게 쓰입니다

    "대상 기관의 통합도서관시스템은 Z39.50 클라이언트를 통해 외부 목록에서 MARC 레코드를 반입하는 기능을 제공하였다."

    표준을 실제 목록 업무 기능과 연결한 서술입니다.

    조금 더 깊게 보면

    미국 국가정보표준기구(NISO)의 표준으로 1988년 처음 승인되었고, 1995년판이 널리 쓰였으며 국제표준 ISO 23950과 대응합니다. 검색 속성 집합(Bib-1 등)으로 제목·저자 같은 검색 항목을 약속하고, 결과는 MARC 같은 형식으로 받습니다. 연결을 유지하는 방식이라 웹 환경에 맞춘 SRU/SRW가 후속으로 개발되었습니다. 미국 의회도서관이 유지관리 기관을 맡아 왔습니다.

    주의할 점

    통합검색은 여러 자원을 한꺼번에 찾는 서비스 개념이고, Z39.50은 그 구현에 쓰일 수 있는 통신 규칙입니다. 메타데이터를 미리 모아 오는 OAI-PMH와 달리 실시간 질의 방식입니다.
