    집합의 연산 (Set Operations)

    집합›집합의 연산
    수학
    한 줄 정의: 두 개 이상의 집합을 합치거나(합집합), 겹치는 부분만 뽑거나(교집합), 빼는(차집합·여집합) 방식으로 새로운 집합을 만드는 계산이다.

    쉽게 풀면

    친구 A는 축구와 야구를 좋아하고, 친구 B는 야구와 농구를 좋아한다고 해보자. "두 사람이 좋아하는 종목을 전부 모으면?"이라고 물으면 축구, 야구, 농구 세 가지가 나오는데 이것이 합집합(∪)이다. "두 사람이 공통으로 좋아하는 종목은?"이라고 물으면 야구만 나오는데 이것이 교집합(∩)이다. "A만 좋아하고 B는 안 좋아하는 종목은?"을 구하면 축구만 남는데 이것이 차집합(A−B)이다. 그리고 전체 종목 목록(전체집합) 중에서 A가 좋아하지 않는 것들만 모으면 여집합(Aᶜ)이 된다. 이렇게 집합끼리 더하고 빼고 겹치는 부분을 찾는 규칙 전체를 집합의 연산이라고 부른다. 특히 "(A∪B)의 여집합은 A의 여집합과 B의 여집합의 교집합과 같다"는 규칙은 드모르간의 법칙이라고 하며, 논리식이나 확률 계산을 단순화할 때 자주 쓰인다.

    왜 중요한가

    집합의 연산은 확률론, 통계학, 논리학, 데이터베이스, 컴퓨터과학 등 여러 분야의 기초 언어로 쓰인다. 표본공간에서 사건들의 관계를 다루는 확률 계산, 여러 조건을 동시에 만족하는 데이터를 추출하는 분석 절차, 논리 회로나 프로그램 조건문 설계 등 폭넓은 상황에서 합집합·교집합·차집합 개념이 그대로 활용되기 때문에 논문의 방법론 설명에서 흔히 등장한다.

    핵심 정리

    집합의 기본 연산은 네 가지이다.

    • 합집합 A ∪ B: A, B, 또는 둘 모두에 속한 원소 전체.
    • 교집합 A ∩ B: 둘 모두에 속한 원소.
    • 차집합 A ∖ B: A에는 속하고 B에는 속하지 않는 원소(상대 여집합). 기호 A − B도 쓰지만 모호할 수 있어 ISO 31-11은 A ∖ B를 쓴다.
    • 여집합 Aᶜ: 전체집합 U에서 A에 속하지 않는 원소. Aᶜ = U ∖ A이며, 전체집합이 정해져야 정의된다.

    차집합은 여집합으로 쓸 수 있다: A ∖ B = A ∩ Bᶜ.

    예시로 보기

    A = {1, 2, 3, 5}, B = {2, 4, 6}이면 A ∪ B = {1, 2, 3, 4, 5, 6}, A ∩ B = {2}, A ∖ B = {1, 3, 5}, B ∖ A = {4, 6}이다. A ∖ B와 B ∖ A가 다르므로 차집합은 순서에 따라 결과가 달라진다.

    자주 쓰는 법칙은 다음과 같다.

    • 교환법칙: A ∪ B = B ∪ A, A ∩ B = B ∩ A. 결합법칙도 성립한다.
    • 분배법칙: 교집합이 합집합에 대해, 합집합이 교집합에 대해 모두 분배된다(산술과 달리).
    • 드모르간 법칙: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ, (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ.
    • 이중 여집합: (Aᶜ)ᶜ = A. 보완 법칙: A ∪ Aᶜ = U, A ∩ Aᶜ = ∅.
    • 흡수법칙: A ∪ (A ∩ B) = A, A ∩ (A ∪ B) = A.

    자주 하는 오해

    • “차집합은 교집합과 같은 종류의 연산이라 순서가 상관없다.” 교집합과 합집합은 교환되지만 차집합은 그렇지 않다(A ∖ B ≠ B ∖ A).
    • “여집합은 집합만 있으면 구할 수 있다.” 전체집합 U를 먼저 정해야 한다. 전체집합을 정하지 않고 B ∖ A로 쓰는 것이 상대 여집합이다.
    • “합집합은 원소 수를 더하면 된다.” 겹치는 원소가 있으면 한 번만 센다. 겹침 개수만큼 빼야 한다.
    • “분배법칙은 곱셈과 덧셈처럼 한쪽 방향뿐이다.” 집합에서는 두 방향이 모두 성립한다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "두 데이터셋의 교집합에 해당하는 표본만을 분석 대상으로 선정하였다."

    이 문장은 "두 자료(예: 설문 응답자 명단과 검사 완료자 명단)에 모두 포함된 대상만 골라 분석했다"는 뜻으로, 조건을 동시에 만족하는 대상을 추출할 때 집합 연산의 개념(교집합)을 그대로 응용한 표현이다.

    "실험군과 대조군의 합집합을 전체 분석 대상으로 정의하고, 두 군의 여집합에 해당하는 결측 데이터는 제외하였다."

    두 그룹을 합쳐 전체 분석 대상을 정의하고, 그 안에 포함되지 않는 데이터는 분석에서 제외했다는, 임상·사회과학 연구에서의 표본 정의 방식이다.

    "질의 결과의 정확도는 정답 집합과 검색 결과 집합의 교집합 크기를 기준으로 정밀도와 재현율을 계산하였다."

    정보검색·자연어처리 분야에서 실제 정답과 시스템이 찾아낸 결과의 겹치는 부분(교집합)을 이용해 성능 지표를 계산했다는 서술이다.

    조금 더 깊게 보면

    집합 연산은 벤 다이어그램으로 시각화하면 이해하기 쉽지만, 실제 논문에서는 이를 정밀도(precision)·재현율(recall)·자카드 유사도(Jaccard similarity) 같은 정량 지표로 바꾸어 쓰는 경우가 많다. 예를 들어 두 집합의 교집합 크기를 합집합 크기로 나눈 값이 자카드 유사도이며, 두 집합이 얼마나 겹치는지를 하나의 수치로 요약할 때 자주 활용된다. 또한 확률론에서는 사건들의 집합 연산 결과에 확률을 부여해 덧셈정리, 조건부확률 등을 유도하는 기초로 쓰인다.

    주의할 점

    차집합(A−B)은 교집합과 다르다. 차집합은 "A에는 있지만 B에는 없는 것"만 남기는 연산이라 방향에 따라 결과가 달라지며(A−B ≠ B−A), 여집합은 반드시 "전체집합"이 정해져 있어야 정의할 수 있는 개념이라는 점도 헷갈리기 쉽다.

    헷갈리기 쉬운 용어

    용어무엇인가집합의 연산과의 관계
    드모르간의 법칙합집합·교집합과 여집합을 연결하는 법칙집합 연산의 대표적 항등식이다
    집합론 기초집합과 원소, 부분집합 등의 기본 개념연산이 정의되는 바탕이다
    여사건과 배반사건확률에서 여집합과 교집합이 공집합인 사건확률에서 집합 연산을 사건에 적용한 용어이다
