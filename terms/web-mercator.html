    웹 메르카토르 (Web Mercator)

    지도학
    한 줄 정의: 온라인 지도 서비스에서 가장 널리 쓰이는, 전통적인 메르카토르 도법을 구형 지구에 단순화하여 적용한 지도 투영법입니다.

    쉽게 풀면

    웹 메르카토르는 우리가 인터넷에서 흔히 보는 지도 앱(포털 지도, 내비게이션 등)의 배경 지도가 대부분 사용하는 투영법입니다. 화면을 확대·축소해도 도형이 정사각형 타일 형태로 자연스럽게 이어지도록 설계되어 있어서, 빠르게 지도를 불러오고 부드럽게 확대·축소하는 웹 환경에 적합합니다. 다만 극지방으로 갈수록 실제 면적보다 훨씬 크게 표현되는 왜곡이 크다는 특징이 있습니다.

    왜 중요한가

    대부분의 웹지도 플랫폼이 표준으로 채택하면서 사실상 온라인 지도 산업의 기본 좌표계가 되었기 때문에, 웹지도학 연구와 실무에서 웹 메르카토르의 특성과 한계를 이해하는 것은 필수적입니다. 특히 면적 비교가 중요한 분석에서는 이 투영법의 왜곡을 감안해야 합니다.

    논문에서는 이렇게 쓰입니다

    "웹지도 서비스와의 호환을 위해 좌표계를 웹 메르카토르(Web Mercator)로 변환하여 타일 지도를 제작하였다."

    온라인 지도 플랫폼에서 바로 사용할 수 있도록 좌표계를 웹 메르카토르로 맞췄다는 의미입니다.

    "고위도 지역의 면적 통계지도를 제작할 때 웹 메르카토르의 왜곡을 피하기 위해 별도의 등적투영법을 적용하였다."

    면적 왜곡이 큰 웹 메르카토르 대신 면적을 보존하는 다른 투영법을 선택했다는 뜻입니다.

    조금 더 깊게 보면

    웹 메르카토르는 계산의 단순함과 속도를 위해 지구를 완전한 구체로 가정하고 투영하는 방식으로, 실제 지구의 타원체 형상을 반영하는 정밀한 측지 좌표계와는 미세한 차이가 있습니다. 이 투영법은 정사각형 타일 단위로 지도를 나누어 전송하는 슬리피 맵 방식과 결합되어 널리 쓰입니다.

    주의할 점

    웹 메르카토르는 항해나 방향 안내에는 적합하지만 면적 비교에는 부적합하므로, 통계지도나 면적 기반 분석에는 다른 투영법을 사용하는 것이 바람직합니다.
