    선형이차조절기 (Linear Quadratic Regulator)

    전기전자공학
    한 줄 정의: 상태 오차와 입력 에너지에 대한 이차형식 비용함수를 최소화하는 최적의 상태 피드백 이득을 구하는 선형 시스템용 최적제어 기법입니다.

    쉽게 풀면

    목적지까지 최대한 빠르면서도 연료를 아끼며 운전하는 방법을 수학적으로 찾는 것과 비슷합니다. 선형이차조절기(LQR)는 "상태가 목표에서 얼마나 벗어났는가"와 "제어 입력을 얼마나 많이 썼는가"를 동시에 고려한 비용을 정의하고, 이 비용을 최소화하는 피드백 제어 법칙을 계산합니다. 상태 오차를 지나치게 줄이려다 입력을 과도하게 쓰지 않도록, 두 요소 사이의 균형점을 수학적으로 찾아주는 방법입니다.

    왜 중요한가

    LQR은 선형 시스템에 대해 폐형(closed-form) 해를 가지는 대표적인 최적제어 기법으로, 안정성이 이론적으로 보장되면서도 설계자가 원하는 성능과 제어 노력의 균형을 가중치 행렬로 직관적으로 조정할 수 있어 제어 시스템 설계에서 기본 도구로 다뤄집니다.

    어떤 절차인가

    선형 시스템 ẋ = Ax + Bu 와 비용 J = ∫(xᵀQx + uᵀRu) dt 에서, 무한 구간 LQR은 다음 순서로 이득을 구합니다.

    1. 가중 행렬 Q(상태 오차의 비용, 반정치)와 R(입력 크기의 비용, 정치)을 정합니다.
    2. 대수 리카티 방정식 AᵀP + PA − P B R⁻¹ BᵀP + Q = 0 을 풉니다.
    3. 이득 K = R⁻¹ BᵀP 를 구하고 제어 법칙 u = −K x 를 씁니다.
    4. (A, B)가 안정화 가능하고 (Q1/2, A)가 검출 가능하면 폐루프 A − BK 는 안정합니다.

    가상의 스칼라 예: ẋ = x + u (불안정한 플랜트, a = 1, b = 1)에서 Q = 1 로 두고 R 만 바꿔 보았습니다(코드 계산).

    RP이득 K폐루프 극 a−bK해석
    12.4142.414−1.414기준
    1020.4882.049−1.049입력에 더 큰 비용 → 이득 감소, 응답이 느려짐
    1 (Q=10)4.3174.317−3.317상태 오차에 더 큰 비용 → 이득 증가, 응답이 빨라짐

    R이 크면 입력을 아끼므로 이득이 줄어 극이 덜 왼쪽에 놓이고, Q가 크면 오차를 빨리 줄이려 이득이 커집니다. 이것이 Q와 R의 균형으로 성능을 조절한다는 설명의 구체적 모습입니다.

    언제 쓰고 무엇을 얻나

    • 언제 쓰나: 모델이 선형(또는 선형화 가능)하고 상태 전부를 쓸 수 있을 때 입력 에너지와 오차 사이의 균형을 정량적으로 정하려는 경우입니다.
    • 얻는 것: 안정성이 보장되는 최적 이득과 체계적 설계 절차. 다입출력 시스템에도 같은 절차를 씁니다. 고전적으로 LQR은 입력 쪽에서 큰 안정 여유(위상 여유 60도 이상 등)를 갖는 것으로 알려져 있습니다.
    • Q, R 선택: 시행착오가 많고, 브라이슨 규칙처럼 각 변수의 허용 최대값의 제곱의 역수로 대각 성분을 정하는 출발점이 교재에 소개됩니다(Bryson & Ho, 1975).
    • 한계: 상태를 모두 안다고 가정하므로 실제로는 상태 관측기와 함께 쓰이고(LQG), 모델 오차에는 별도 강인성 검증이 필요합니다.

    논문에는 이렇게 적는다

    • 플랜트 모델과 선형화 점, Q·R 값, 선택 이유(튜닝 과정)를 적습니다.
    • 이득 K와 폐루프 극, 비용 함수 값을 제시합니다.
    • 시뮬레이션·실험에서 상태 응답, 입력 크기(포화 여부), 정착시간, 정상상태 오차를 보이고 Q, R를 바꾼 민감도 결과를 함께 보입니다.
    • 모든 상태를 측정하지 않았다면 추정기를 쓴 구성임을 명시합니다.

    예시 문장

    아래는 용어의 쓰임을 보여 주려고 만든 예시로, 실제 논문에서 가져온 문장이 아닙니다.

    "The linear quadratic regulator gain is computed by solving the algebraic Riccati equation associated with the weighting matrices Q and R."

    가중치 행렬 Q와 R에 대응하는 대수 리카티 방정식을 풀어 LQR 이득을 계산했다는 내용으로, 설계 절차를 설명하는 문맥입니다.

    "By increasing the control weighting matrix R, the LQR produces a smoother control effort at the cost of slower response."

    입력 가중치 행렬 R을 키우면 LQR이 더 완만한 제어 입력을 만들지만 응답 속도는 느려진다는 내용으로, 가중치 조정에 따른 성능 변화를 다루는 문맥입니다.

    조금 더 깊게 보면

    LQR의 최적 이득은 대수 리카티 방정식(ARE)의 해로부터 얻어지며, 상태 가중치 행렬 Q와 입력 가중치 행렬 R을 조정함으로써 상태 오차 억제와 제어 노력 절감 사이의 상대적 비중을 설계자가 결정할 수 있습니다. 다만 이 기법은 시스템이 가제어해야 하며, 모든 상태를 알고 있다는 것을 전제로 하는 상태 피드백 방식이라는 점이 특징입니다.

    주의할 점

    LQR은 모든 상태를 측정할 수 있다고 가정하므로, 실제로는 상태 추정을 위한 관측기와 함께 사용되는 경우가 많다는 점을 유의해야 합니다.

    헷갈리기 쉬운 용어

    피드백 설계 방법 중 자주 비교되는 용어입니다.

    용어설계 기준특징
    LQR이차 비용 최소화Q, R 가중치로 성능-입력 균형
    극배치 설계원하는 극 위치 지정극은 정하지만 입력 크기는 간접적으로만 통제
    LQGLQR + 칼만 필터잡음과 상태 추정을 포함
