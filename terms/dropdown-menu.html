    드롭다운메뉴 (Dropdown Menu)

    디자인학

    ✓ 출처 대조 2026-11-08

    한 줄 정의: 클릭이나 탭 시 목록이 아래로 펼쳐져 여러 선택지 중 하나를 고를 수 있게 하는 UI 컴포넌트이다.

    쉽게 풀면

    누르면 아래로 목록이 쭉 펼쳐져서 그중 하나를 고를 수 있게 해주는 메뉴이다.

    왜 중요한가

    드롭다운 메뉴는 클릭이나 호버로 선택지 목록을 펼치는 컨트롤로, 화면 공간을 절약하면서 여러 옵션 중 하나를 고르게 하는 폼과 내비게이션의 기본 요소이다. 표준 HTML 요소로 구현하면 키보드 조작과 스크린리더 지원을 자동으로 얻기 때문에, 접근성 측면에서 가장 안전한 선택 컨트롤 중 하나로 권장된다. 긴 옵션 목록을 다루는 드롭다운은 입력한 글자로 목록을 좁혀 주는 자동완성 기능을 결합해, 스크롤만으로 원하는 항목을 찾는 부담을 줄이는 방식으로 개선되는 경우가 많다. 선택된 값이 드롭다운을 닫은 뒤에도 항상 화면에 보이도록 유지하는 것이 사용자가 나중에 다시 확인할 때 혼란을 줄이는 기본 설계 원칙이다. 옵션이 계층 구조를 가질 때는 상위 항목을 선택하면 하위 옵션 목록이 새로 나타나는 연쇄형 드롭다운이 쓰이며, 이는 단일 목록형 드롭다운과 구현 방식이 다르다.

    핵심 정리

    드롭다운 목록(drop-down list)은 목록 상자와 비슷한 그래픽 제어 요소로, 클릭하거나 마우스를 올리면 목록이 펼쳐져 값 하나를 고르게 한다. 닫혀 있을 때는 값 하나만 보이고, 선택한 뒤에는 다시 선택된 값을 보인다. 드롭 메뉴, 풀다운 목록, 픽리스트(picklist)라고도 부른다. 웹에서는 HTML의 select와 option 요소로 만든다.

    Macintosh에서는 이름을 나눠 쓴다. 팝업 메뉴(pop-up menu)는 닫혀 있을 때 마지막에 고른 항목을 보이며 하나를 고르는 데 쓰고, 풀다운 메뉴(pull-down menu)는 제목이 고정되어 있고 명령을 내리거나 여러 항목을 고를 때 쓴다.

    예시로 보기

    • HTML의 option은 선택지 하나이고, 값이 없으면 글자가 제출 값이 된다. 미리 고른 항목이 없으면 첫 항목이 선택된다.
    • optgroup으로 선택지를 제목 아래 묶을 수 있다. 첫 항목을 값이 빈 안내 문구(placeholder)로 둘 수 있다.
    • multiple을 주면 0개 이상을 고를 수 있고 목록 상자로 그려진다. 이때는 둘 이상 고를 수 있다고 사용자에게 알려야 한다.

    자주 하는 오해

    • 네이티브 select는 스타일을 바꾸기 어렵다. 완전히 바꾸려면 비시맨틱 요소, 자바스크립트, WAI-ARIA로 만든 맞춤 드롭다운을 써야 하고, 그만큼 접근성 구현을 직접 맡게 된다.
    • 각 select는 label과 연결하고 name을 준다. 암묵적 역할은 단일 선택이면 combobox, 다중 선택이면 listbox이다.
    • 키보드 조작은 표준이 없어 브라우저와 운영체제마다 다르다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    본 연구는 드롭다운메뉴 항목 수 증가가 모바일 환경에서의 선택 오류율에 미친 영향을 조사하였다.

    목록형 선택 UI의 항목 수가 실제 선택 정확도에 미친 영향을 실험한 연구이다.

    "항목을 계층적으로 분류한 드롭다운메뉴가 평면적으로 나열한 메뉴보다 탐색 시간을 단축시키는 것으로 나타났다."

    메뉴 항목을 의미 있는 그룹으로 묶어 보여주는 방식이 사용자의 탐색 부담을 줄인다는 내용이다.

    조금 더 깊게 보면

    선택지가 5개 미만이면 라디오 버튼이 더 빠르고, 수십 개가 넘으면 검색이 가능한 콤보박스가 낫다는 것이 사용성 연구의 일관된 권고로, 드롭다운은 그 중간 범위에 적합하다. 국가 선택처럼 긴 목록을 드롭다운으로 두는 것은 대표적 사용성 문제이며, 모바일에서는 네이티브 피커로 대체된다. 호버로 열리는 내비게이션 드롭다운은 터치 기기에서 작동하지 않고, 마우스 경로가 살짝 벗어나면 닫히는 문제로 클릭 방식이 권장된다. 옵션을 숨긴다는 점에서 인터랙션 비용이 항상 추가된다는 점도 고려해야 한다. 네이티브 select 요소로 만든 드롭다운은 운영체제가 렌더링을 담당해 스타일링이 제한적이지만 접근성이 자동 보장되는 반면, 커스텀 드롭다운은 자유로운 디자인이 가능한 대신 키보드 탐색과 스크린리더 지원을 개발자가 직접 구현해야 한다.

    주의할 점

    드롭다운메뉴는 항목이 많아지면 스크롤 부담이 커져 다른 선택 UI(예: 검색형 자동완성)가 더 나을 수 있다.

    헷갈리기 쉬운 용어

    용어한 줄 설명
