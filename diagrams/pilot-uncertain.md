# 파일럿 — 확신이 낮아 넣지 않은 연결

- late-phase-ltp — CREB → 특정 표적 유전자(Arc, BDNF 등)로의 구체적 연결: 유전자별 기여가 연구마다 달라 생략
- neuroinflammation-cascade — 별아교 반응 → 미세아교 재활성의 되먹임 호: 방향·주도 신호가 모델마다 달라 생략
- microglial-priming — 프라이밍 상태의 분자 표지(MHC-II, CD68 등)를 노드로 넣지 않음: 종·모델 간 일관성 낮음
- astrocyte-neuron-lactate-shuttle — 락테이트 → 기억 형성(Suzuki 2011)으로의 연결: 에너지 기능과 신호 기능 구분 논쟁
- tripartite-synapse — 신경교전달물질 → 시냅스 가소성 조절 화살표: 생리적 방출 여부 논쟁(Fiacco·McCarthy 2018)이라 자식 노드만 두고 '논쟁 중' 표기
- reactive-astrocyte — A1 → 뉴런 사멸을 일으키는 독성 인자(포화 지질, Guttenplan 2021) 연결 생략: 후속 연구 단계
- synaptic-pruning — 'don't eat me' 신호(CD47-SIRPα) 억제 edge 생략: 적용 범위(부위·시기) 제한적
- anti-nmda-receptor-encephalitis — 바이러스 뇌염(HSV) 후 발병 경로를 유발 요인에 명시하지 않고 '등'으로 처리
- hippocampal-remapping — 리맵핑 유형과 기전(내후각 격자 이동 등) 연결 생략
