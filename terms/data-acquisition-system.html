    데이터 수집장치(DAQ) (Data Acquisition System)

    공학
    한 줄 정의: 여러 센서로부터 들어오는 아날로그 신호를 디지털 값으로 변환해 컴퓨터에서 저장·처리할 수 있도록 다채널로 동시에 수집하는 계측 시스템.

    쉽게 풀면

    여러 종류의 센서(온도, 압력, 힘, 진동 등)에서 동시에 쏟아지는 아날로그 전기 신호를 컴퓨터가 이해할 수 있는 디지털 숫자로 바꿔서 저장하는 장비다. 채널이 여러 개 있어 수십 개의 센서 신호를 동시에, 정해진 속도로 계속 기록할 수 있어 실험 중 발생하는 모든 데이터를 놓치지 않고 모을 수 있다. 복잡한 실험 시스템에서 여러 센서의 데이터를 통합해 하나의 시간축으로 정리하는 핵심적인 역할을 한다.

    왜 중요한가

    데이터 수집장치는 실험 결과의 신뢰도를 결정하는 계측 인프라이기 때문에 기계, 전기전자, 토목, 항공우주 등 실험 기반 공학 논문의 방법론 섹션에서 빠지지 않고 등장합니다. 여러 센서 신호를 동시에 정확한 타이밍으로 기록해야 하는 구조 시험, 진동 실험, 열유체 실험 등에서 실험 설계의 핵심 장비로 다뤄집니다. 최근에는 실시간 모니터링과 자동화된 데이터 처리가 요구되는 스마트 센서 시스템 연구와도 밀접하게 연결됩니다.

    논문에서는 이렇게 쓰입니다

    "실험 중 스트레인 게이지, 열전대, 가속도계 신호는 DAQ를 이용하여 10 kHz로 동기 수집하였다."

    여러 종류의 센서 신호를 초당 만 번(10kHz) 속도로 동시에 데이터 수집장치를 이용해 기록했다는 뜻이다.

    "교량 구조 건전성 모니터링을 위해 다채널 DAQ를 현장에 설치하여 장기간 변형률 데이터를 연속적으로 기록하였다."

    토목구조 분야에서 실시간·장기 모니터링에 DAQ가 활용된 사례를 설명한 문장이다.

    "풍동 실험에서 압력 센서 배열의 신호는 고속 DAQ를 통해 동시 수집되어 표면 압력 분포를 재구성하는 데 사용되었다."

    항공우주·유체역학 분야에서 다채널 압력 데이터를 수집해 유동 특성을 분석한 문장이다.

    조금 더 깊게 보면

    데이터 수집장치의 핵심 성능은 샘플링 속도, 분해능(비트 수), 채널 수, 그리고 여러 채널 신호를 동시에 확보하는 방식(동시 샘플링 여부)으로 결정됩니다. 아날로그 신호를 디지털로 변환하기 전에는 원치 않는 고주파 성분이 왜곡을 일으키지 않도록 저역통과 필터를 거치는 전처리 단계가 흔히 포함됩니다. 논문에서 DAQ 사양(샘플링 속도, 분해능 등)을 함께 명시하는 이유는 측정된 신호가 실제 물리 현상을 얼마나 충실히 재현했는지를 독자가 판단할 수 있게 하기 위해서입니다.

    주의할 점

    샘플링 속도가 측정하려는 신호의 최고 주파수의 2배(나이퀴스트 기준)보다 낮으면 신호가 왜곡되어 잘못된 데이터를 얻을 수 있다.
