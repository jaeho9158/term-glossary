    엡실론-델타 논법 (Epsilon-Delta Definition of Limit)

    수학
    한 줄 정의: 임의의 ε>0에 대해 적당한 δ>0이 있어서 0<|x−a|<δ이면 |f(x)−L|<ε가 되게 할 수 있을 때 f(x)의 극한이 L이라고 정하는, 극한의 엄밀한 정의이다.

    쉽게 풀면

    'x가 a에 가까워지면 f(x)가 L에 가까워진다'는 말에서 '가까워진다'를 숫자로 바꾼 정의다. 상대가 허용 오차 ε를 아무리 작게 정해도, 나는 그에 맞는 입력 범위 δ를 찾아서 x를 a에서 δ보다 가깝게만 두면(단, x = a는 빼고) f(x)가 L에서 ε보다 가깝게 있음을 보여야 한다. 이런 δ를 모든 ε에 대해 찾을 수 있으면 극한은 L이다.

    왜 중요한가

    극한은 조임정리, 연속, 미분, 적분의 바탕이다. 직관적인 설명만으로는 극한의 합·곱 법칙 같은 기본 성질을 증명할 수 없는데, 엡실론-델타 정의가 있으면 부등식만으로 이를 증명할 수 있다. 해석학 교재가 극한과 연속을 모두 이 정의 위에 세우는 이유다.

    핵심 정리

    함수 f가 a를 포함하는 열린 구간에서(a 자신은 빼도 된다) 정의되어 있을 때, limx→a f(x) = L은 다음을 뜻한다.

    • 모든 ε > 0에 대하여 어떤 δ > 0이 존재하여, 0 < |x − a| < δ이면 |f(x) − L| < ε이다.
    • ε는 출력값이 L에서 벗어나도 되는 폭, δ는 입력값이 a에서 떨어져도 되는 폭이다.
    • 0 < |x − a|가 x = a를 빼므로 f(a)의 값은 극한에 영향을 주지 않는다. 이를 뺀 근방(구멍 뚫린 근방)이라고 부르며, a를 포함하는 |x − a| < δ로 정의하는 방식은 덜 일반적이다.
    • f가 a에서 정의되고 limx→a f(x) = f(a)이면 f는 a에서 연속이다.

    증명하는 순서

    OpenStax 『Calculus Volume 1』은 엡실론-델타 증명을 다음 다섯 단계로 정리한다.

    1. ε > 0이 주어졌다고 둔다.
    2. ε로 δ를 정하는 식을 고른다.
    3. 0 < |x − a| < δ라고 가정한다.
    4. 이 가정으로 |f(x) − L| < ε를 보인다.
    5. limx→a f(x) = L이라고 결론짓는다.

    2단계의 δ는 보통 |f(x) − L|을 |x − a|로 묶는 계산을 거꾸로 따라가 찾는다.

    예시로 보기

    극한고르는 δ이유
    limx→1 (2x + 1) = 3δ = ε/2|(2x + 1) − 3| = 2|x − 1| < 2δ = ε
    limx→2 (4x + 1) = 9δ = ε/4|(4x + 1) − 9| = 4|x − 2| < ε
    limx→4+ √(x − 4) = 0δ = ε20 < x − 4 < ε2이면 √(x − 4) < ε
    limx→−1 (x2 − 2x + 3) = 6δ = min{1, ε/5}δ ≤ 1이면 |x − 3| < 5이므로 |x + 1||x − 3| < 5|x + 1| < ε

    일차함수는 기울기로 나누면 δ가 바로 나온다. 이차함수는 |x − 3| 같은 다른 인수가 커지지 않도록 δ를 먼저 1 이하로 묶는다.

    극한이 없음을 보이기

    극한이 없다는 것은 정의를 부정한 문장, 곧 '어떤 L을 골라도, 어떤 ε가 있어서 모든 δ에 대해 0 < |x − a| < δ이면서 |f(x) − L| ≥ ε인 x가 있다'를 보이는 일이다.

    f(x) = |x|/x는 x > 0에서 1, x < 0에서 −1이다. ε = 1/2로 두면, L ≥ 0일 때는 x = −δ/2에서 |f(x) − L| = L + 1 ≥ 1이고, L < 0일 때는 x = δ/2에서 |f(x) − L| = |L| + 1 ≥ 1이다. 어느 쪽이든 ε를 넘으므로 x → 0일 때 극한은 없다. 한쪽 극한이 각각 1과 −1로 서로 달라 양쪽 극한이 없는 경우이기도 하다.

    극한 법칙의 증명

    합의 법칙 lim(f + g) = L + M은 f에 맞는 δ1과 g에 맞는 δ2를 각각 ε/2로 구한 뒤 δ = min{δ1, δ2}로 두고 삼각부등식을 쓰면 나온다. 조임정리의 엡실론-델타 증명도 위아래 두 함수의 δ 가운데 작은 쪽을 고르는 같은 방식이다.

    자주 하는 오해

    • ε와 δ의 순서: '모든 ε에 대해 δ가 존재'이다. 순서를 바꿔 '어떤 δ가 모든 ε에 통한다'로 읽으면 다른 명제가 된다.
    • δ는 하나로 정해지지 않는다. 어떤 δ가 통하면 그보다 작은 양수도 모두 통하므로 가장 큰 δ를 찾을 필요는 없다.
    • f(a)가 정의되지 않아도 극한은 있을 수 있다. 예를 들어 (2x2 − x − 1)/(x − 1)은 x = 1에서 정의되지 않지만 x → 1일 때 극한은 3이며, δ = ε/2로 보일 수 있다.

    역사

    • 1817년: 베르나르트 볼차노가 연속함수를 정의하면서 이 방법의 기본을 내놓았지만, 그의 작업은 생전에 알려지지 않았다.
    • 1821년: 오귀스탱루이 코시는 『해석학 강의(Cours d'analyse)』에서 연속을 무한소로 정의했다. 주디스 그래비너는 코시가 증명에서 엄밀한 엡실론-델타 정의를 썼다고 본다.
    • 1861년: 카를 바이어슈트라스가 오늘날 쓰는 꼴의 엡실론-델타 정의를 처음 제시하고 lim 표기도 도입했다.
    • 1908년: G. H. 하디가 『A Course of Pure Mathematics』에서 lim 아래에 화살표를 쓰는 현대 표기를 도입했다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "For every ε > 0 there exists δ > 0 such that 0 < |x − a| < δ implies |f(x) − L| < ε."

    해석학 교재와 논문에서 극한을 정의하거나 증명할 때 쓰는 표준 문장이다. '모든 ε에 대해 어떤 δ가 존재한다'는 순서가 핵심이다.

    "Given ε > 0, choose δ = min{1, ε/5}; then |f(x) − 6| < ε whenever 0 < |x + 1| < δ."

    이차식처럼 기울기가 변하는 함수에서 δ를 먼저 1 이하로 제한해 다른 인수의 크기를 묶은 뒤 ε에 맞추는 전형적인 증명 단계다.

    조금 더 깊게 보면

    정의는 '모든 ε > 0에 대하여 δ > 0이 존재하여, 0 < |x − a| < δ이면 |f(x) − L| < ε'의 꼴이다. 0 < |x − a|라는 조건 때문에 x = a는 빠지므로 f(a)의 값이나 정의 여부는 극한과 상관이 없다. 함수가 a에서 정의되어 있고 극한이 f(a)와 같으면 f는 a에서 연속이다. 한쪽 극한은 0 < x − a < δ 또는 0 < a − x < δ로 조건을 바꿔 정의한다.

    주의할 점

    ε와 δ의 순서를 바꾸면 다른 명제가 된다. δ는 ε(그리고 a)에 따라 고를 수 있지만, ε를 먼저 고르는 쪽은 상대다. 한 가지 ε에서 δ를 찾았다고 끝나지 않고 모든 ε > 0에 대해 찾아야 한다. 또 δ를 찾을 때 쓴 부등식은 x가 a 근처일 때만 성립해도 되므로, δ에 1 같은 상한을 함께 두는 일이 많다.
