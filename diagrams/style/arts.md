# 예술·디자인 스타일 가이드
(검수 통과 스펙 약 90개를 관찰한 결과. 이 분야군에는 음악·무용·영화·연극·게임·디자인뿐 아니라 화장품·섬유 용어도 섞여 있다.)
## 자주 맞는 type
- procedure: 예술 형식의 "구성 순서". 소나타형식(제시부→발전부→재현부→코다), 론도 형식, 프라이타크의 피라미드, 5막구조, 그리스비극구조, 디자인씽킹, 더블다이아몬드. 단계 번호가 자동으로 붙으니 라벨에 숫자를 쓰지 않는다.
- hierarchy: 분류·구성요소 트리. 혼보스텔-작스 분류체계, 삼점조명(키·필·백), 12음기법(P·R·I·RI), 쇼트스케일, 에포트(라반), 카노모델, 바틀 플레이어 유형론.
- contrast: 쌍개념·논쟁·변종 비교. 아폴론적/디오니소스적, 정격종지(PAC/IAC), 극양식과 서사양식, 내러톨로지-루돌로지, 수중유형/유중수형(에멀젼), 평직/능직·주자직, RGB/CMYK.
- chain: 효과·기전의 인과 연쇄. 쿨레쇼프효과, 숏리버스숏, MDA 프레임워크, 콘텐츠밸류체인, 멜라닌생성·경피흡수(화장품), 소스·싱크 경제모델. 3~5노드가 대부분.
## 라벨 관례
- 라벨은 한글 10자 내외의 명사구, 부연은 sub에 둔다. 예: 라벨 "제시부", sub "주제 제시·조성 대립".
- 영문 약어는 sub에 병기한다: "PAC", "IAC", "P·기본 음렬", "RI·전위의 역행"; contrast 머리 라벨에는 "수중유형 O/W"처럼 약어를 붙이기도 한다.
- 고유명·원어는 한글 표기를 쓰고 연도·저자는 notes에 넣는다: "『비극의 탄생』 1872", "Hunicke 등(2004)"은 source에 둔다.
- 음악 기호(V–I, IV–I, V–vi)는 en dash, 변형 표기는 A′처럼 프라임 부호를 쓴다.
- contrast는 최상위 axis에 비교 기준을 한마디로 쓴다: "정격종지(V–I)의 두 형태", "기본 조직", "색상 모델", "분산상과 연속상".
## 색 쓰는 법
- blue: 주제·본체·기본 형식(원형음렬, 제시부, A, 아폴론적). 반복되는 중심 재료도 blue(ABA의 A와 A′).
- amber: 대조·변형·외부 개입(ABA의 B 대조 부분, 발전부, 디오니소스적 도취, 불완전정격종지, 막명악기).
- green: 해소·바람직한 결과(재현부, 완전정격종지 "가장 강한 종결감", 매력적 요구, 가벼운 사용감).
- violet: 방법·도구·변환·매개(역행·전위, 에포트의 무게·시간·공간·흐름, 병치 편집, 능직·주자직).
- gray: 기준·부가·배경(코다, 전명악기 "후대 추가", 기본 요구, 평직의 특성 행).
- rose: 문제·한계에만 쓴다. 예술 용어는 "나쁜 것"이 드물어 쇼트스케일의 익스트림 클로즈업처럼 강도 끝단 표시 외에는 거의 안 쓴다.
- bio 모드는 화장품·피부 용어(멜라닌생성, 경피흡수, 각질층)에서만 고려한다.
## 피할 것
- 취향·해석이 갈리는 개념을 단정하지 않는다: 아폴론/디오니소스는 "이성 대 감정으로 축소 금물" 한계 note를 달았다. 대립 쌍은 가치 서열(green/rose)로 칠하지 않는다.
- 역사적 서술이 불확실하면 limit note로 밝힌다: 쿨레쇼프효과는 "원본 필름 소실, 재현 실험의 효과 크기가 소문보다 작다".
- 형식 구조를 고정 순서로 오해하게 하지 않는다: 디자인씽킹은 "단계는 순차가 아니라 반복적으로 오감", 소나타형식은 "코다·서주는 선택적".
- 평직 같은 단순한 대상을 열등하게 그리지 않는다("단순하다고 저급한 조직은 아님"). contrast 양쪽 행 수를 맞추고 한쪽만 green으로 칠하지 않는다.
- 분야 분류가 걸치는 용어(화장품 유화·섬유 조직)는 예술 은유로 풀지 말고 기전 그대로 쓴다.
## v2 새 type
- 위 관찰은 cycle·matrix·venn·timeline·plot이 생기기 전 스펙 기준이다. 새로 쓸 때는 README의 9개 type 중 개념에 가장 맞는 것을 고른다.
## 좋은 예
- apollonian-dionysian (contrast): 두 원리를 axis로 묶고 한쪽 우위를 피하며, 출처 연도 note와 "축소 금물" limit note를 함께 단다.
- kuleshov-effect (chain): 4노드 연쇄에 gray 기준 쇼트→violet 병치→amber 관객 구성→blue 결과로 역할 색을 맞추고, 효과 크기 논란을 limit note로 정직하게 밝힌다.
- 보조 참고: sonata-form (procedure)은 4노드·색 역할(blue/amber/green/gray)·선택 부분 note가 간결하다.
