    확장칼만필터 (Extended Kalman Filter (EKF))

    로봇공학
    한 줄 정의: 비선형 시스템 모델을 매 시점 야코비안으로 선형화하여 칼만 필터의 예측·갱신 구조를 적용하는 상태 추정 기법.

    쉽게 풀면

    칼만 필터는 원래 직선적인 문제에만 쓸 수 있는데, 곡선적인(비선형) 문제도 매 순간 살짝 직선처럼 근사해서 칼만 필터를 쓸 수 있게 만든 방법입니다.

    왜 중요한가

    비선형 운동 모델과 센서 모델을 매 시점 선형화해 칼만필터를 적용하는 방법으로, 이동로봇 위치추정과 관성·GPS 융합에서 사실상의 기본 추정기입니다. 다중센서융합 논문에서 새 방법의 비교 기준이며, ROS의 로봇 위치추정 패키지도 이 방식을 기본으로 합니다.

    어떤 절차인가

    시스템을 xk = f(xk−1, uk) + wk, 관측을 zk = h(xk) + vk로 둡니다. f와 h는 비선형 함수이고, w와 v는 평균 0인 잡음으로 공분산이 각각 Q, R입니다. 한 번의 반복은 두 단계입니다.

    1. 예측: 상태는 비선형 모델 그대로 전파합니다. x̂− = f(x̂, u). 공분산은 f를 현재 추정치에서 선형화한 야코비안 F로 전파합니다. P− = F P FT + Q.
    2. 갱신: h를 예측치에서 선형화한 야코비안 H로 칼만 이득을 구합니다. K = P−HT(H P−HT + R)−1. 그리고 x̂ = x̂− + K(z − h(x̂−)), P = (I − K H)P−.

    선형 칼만 필터와 다른 점은 상태 전파와 예측 관측에는 비선형 함수 자체를 쓰고, 선형화는 공분산과 이득을 구하는 데만 쓴다는 것입니다(Gelb, 1974).

    언제 쓰고 무엇을 얻나

    이동 로봇의 위치추정, 관성 센서와 GPS의 융합, 거리·방위 같은 비선형 관측을 쓰는 항법에서 쓰입니다(다중센서융합, IMU). 계산이 가볍고 구현이 쉬워 실무의 기본 추정기로 자리잡았습니다(Thrun, Burgard, & Fox, 2005).

    가상의 한 단계 예를 계산해 보겠습니다. 직선 위의 위치 x를 추정하고, 직선에서 옆으로 3 m 떨어진 비콘까지의 거리 h(x) = √(x² + 3²)를 잽니다. 사전 추정치 x̂ = 4, 분산 P = 1, 관측 잡음 분산 R = 0.04, 관측값 z = 5.3입니다.

    양값계산
    예측 관측 h(x̂)5.000√(4² + 3²)
    야코비안 H0.800x ÷ √(x² + 9) = 4 ÷ 5
    혁신(잔차) z − h0.3005.3 − 5
    혁신 분산 S0.680H·P·H + R
    칼만 이득 K1.176P·H ÷ S
    갱신 추정치 x̂4.3534 + K × 0.3
    갱신 분산 P0.0588(1 − K·H) × P

    관측이 아주 정확(R이 작음)해서 분산이 1에서 0.059로 크게 줄었습니다. 관측이 더 멀리 떨어진 위치에서 만들어졌다면 H의 값이 달라져 같은 관측이라도 정보량이 달라진다는 점이 선형 필터와의 차이입니다.

    논문에는 이렇게 적는다

    • 상태 벡터, 운동 모델 f와 관측 모델 h, 입력 u를 식으로 제시하고, 야코비안을 해석적으로 유도했는지 수치 미분을 썼는지 밝힙니다.
    • 잡음 공분산 Q, R의 값과 결정 방법(센서 사양, 시험 데이터, 시행착오 조정)을 적습니다. EKF의 성능은 이 값에 민감합니다.
    • 초기 상태와 초기 공분산을 적고, 발산 여부를 점검한 방법(잔차가 평균 0 부근에 머무는지, 추정 공분산이 실제 오차와 맞는지)을 보고합니다.
    • 비교 대상(무향 칼만 필터, 파티클필터)과 같은 데이터·초기 조건에서 정확도와 계산 시간을 함께 제시합니다.
    • 선형화 오차 때문에 비일관성이 생길 수 있고, 가우시안 단봉 분포만 표현한다는 한계를 명시합니다.

    논문에서는 이렇게 쓰입니다

    실제 논문에서

    국내 학술지 논문에서 이 용어가 쓰인 문장을 그대로 옮겼습니다. 제목·학술지·연도와 원문 링크를 함께 적었습니다.

    • “본 연구는 실측 기반 유속 자료의 품질 향상을 위한 EKF 필터 적용 가능성을 제시하며, 향후 실시간 유속 품질 진단 및 자동 보정 시스템 개발의 기초자료로 활용될 수 있다.”

      저유속 구간에서의 유속 보정 필터 적용 및 성능 평가, 한국방재학회논문집, 2025 · KCI 한국학술지인용색인 · 원문 보기 ↗

    예시 문장

    아래는 용어의 쓰임을 보여 주려고 만든 예시로, 실제 논문에서 가져온 문장이 아닙니다.

    EKF는 비선형 함수 f, h를 현재 추정치 주변에서 1차 테일러 전개하여 얻은 야코비안 F, H를 이용해 표준 칼만 필터의 공분산 전파 및 갱신식을 적용한다.

    복잡한 곡선 함수를 특정 지점에서의 접선(1차 근사)으로 바꾸어, 원래 칼만 필터의 계산식을 그대로 사용할 수 있게 한다는 뜻입니다.

    "확장칼만필터는 비선형 운동 모델을 가진 로봇의 위치 추정 문제에서 관측값과 예측값을 결합해 오차를 줄이는 데 활용된다."

    로봇의 움직임이 단순한 직선 운동이 아니라 복잡한 비선형 모델을 따를 때도, 센서 관측과 예측을 결합해 위치 오차를 계속 줄여나가는 방법을 소개한 문장입니다.

    조금 더 깊게 보면

    선형화가 현재 추정치 주변에서 이루어지므로 초기 추정이 나쁘거나 비선형성이 강하면 발산할 수 있고, 가우시안 단봉 분포를 가정하므로 여러 가설이 공존하는 위치 상실 상황은 표현하지 못합니다. 이 두 한계가 파티클필터가 전역 위치추정에 쓰이는 이유이며, 언센티드 칼만필터는 선형화 대신 샘플링으로 비선형성을 다루는 대안입니다.

    EKF의 예측 단계는 비선형 운동 모델로 상태를 그대로 전파하되 공분산은 그 시점의 야코비안으로 선형화해 전파하며, 갱신 단계는 실제 관측값과 예측 관측값의 차이(잔차)에 칼만 이득을 곱해 상태를 보정하는 구조를 갖는다.

    비선형성이 강한 구간에서는 이 선형화 근사의 오차가 누적되어 추정치와 실제 공분산이 어긋나는 비일관성이 생기며, 이는 필터가 스스로는 감지하지 못하는 조용한 실패로 이어질 수 있다.

    주의할 점

    비선형성이 강하거나 초기 오차가 크면 선형화 오차가 누적되어 발산할 위험이 있습니다. EKF는 가우시안 단봉 분포만을 표현할 수 있어, 위치를 완전히 잃어버려 여러 가능성이 동시에 존재하는 전역 위치추정 상황에는 근본적으로 적합하지 않다.

    헷갈리기 쉬운 용어

    필터비선형 처리분포 가정대표적 용도
    칼만 필터선형 모델 필요가우시안선형 시스템의 상태 추정
    확장 칼만 필터(EKF)야코비안으로 선형화가우시안 단봉로봇 위치추정, 센서 융합
    무향 칼만 필터시그마 포인트를 비선형 함수에 직접 통과가우시안강한 비선형에서 EKF의 대안
    파티클필터다수의 가중 입자로 분포 근사제한 없음(다봉 가능)위치를 잃은 상황의 전역 위치추정
