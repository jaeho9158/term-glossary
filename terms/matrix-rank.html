    행렬의 랭크 (Rank of a Matrix)

    수학

    ✓ 출처 대조 2026-11-08

    한 줄 정의: 행렬 안에 들어 있는 행(또는 열) 중에서 서로 다른 정보를 담고 있는, 진짜로 "독립적인" 행(또는 열)의 개수이다.

    쉽게 풀면

    설문지에 "키(cm)"와 "키(m)"를 동시에 묻는 문항이 있다고 해보자. 숫자만 다를 뿐 사실은 같은 정보이므로, 두 문항 중 하나는 없어도 된다. 행렬의 랭크(Rank)는 표(행렬) 안에 이런 식으로 "다른 행(또는 열)을 조합해서 그대로 만들어낼 수 있는 중복된 정보"를 제외하고, 진짜로 새로운 정보를 담은 행(또는 열)이 몇 개인지를 세는 값이다. 랭크가 낮다는 것은 겉보기엔 데이터가 많아 보여도 실제 담긴 정보는 훨씬 적다는 뜻이다.

    왜 중요한가

    행렬의 랭크는 데이터나 시스템 안에 실제로 얼마나 많은 독립적인 정보가 들어 있는지를 알려주기 때문에, 통계학, 신호처리, 딥러닝 등에서 데이터 압축, 차원 축소, 모델 경량화의 이론적 근거로 자주 쓰인다. 연립방정식의 해가 존재하는지, 유일한지를 판단하는 데도 필수적이며, 최근에는 대규모 모델을 효율적으로 학습시키는 저랭크 근사 기법의 핵심 개념으로 다시 주목받고 있다. 이 때문에 이론 논문뿐 아니라 응용 연구에서도 랭크 개념이 자주 등장한다.

    핵심 정리

    m×n 행렬 A의 랭크는 일차독립인 열의 최대 개수이며, 열공간의 차원과 같다. 일차독립인 행의 최대 개수(행 랭크)도 언제나 열 랭크와 같으므로 하나의 값 rank(A)로 부른다.

    • rank(A) ≤ min(m, n)이다. 이 값과 같으면 풀랭크, 작으면 랭크 부족이라 한다.
    • x → Ax라는 선형사상의 상(image)의 차원이 rank(A)이고, rank(A) + dim(커널) = n이다(랭크-영공간 차원 정리).
    • 정사각행렬은 풀랭크일 때만 역행렬을 가진다.
    • rank(Aᵀ) = rank(A)이고, rank(AB) ≤ min(rank A, rank B)이다.

    예시로 보기

    A = [[1, 2, 1], [−2, −3, 1], [3, 5, 0]]를 가우스 소거로 행사다리꼴 [[1, 0, −5], [0, 1, 3], [0, 0, 0]]로 바꾸면 0이 아닌 행이 2개이므로 rank(A) = 2이다. 실제로 셋째 행은 첫째 행에서 둘째 행을 뺀 것과 같다. 3×3 행렬이지만 풀랭크가 아니므로 역행렬이 없다.

    M = [[1, 2], [2, 4]]에서는 둘째 열이 첫째 열의 2배라 rank(M) = 1이다. Mx = 0의 해는 (−2, 1)의 상수배라 영공간의 차원이 1이고, 1 + 1 = 2 = 열의 수가 되어 위 정리와 맞는다.

    계산할 때는 소거 후 피벗의 개수를 센다. 부동소수점 계산에서는 단순 소거가 불안정할 수 있어 특이값분해로 0이 아닌 특이값의 개수를 세는 방법을 쓰며, 어느 값까지 0으로 볼지 정하는 허용오차는 행렬과 용도에 따라 달라진다.

    자주 하는 오해

    • “행 랭크와 열 랭크는 다를 수 있다.” 어떤 행렬이든 두 값은 같다.
    • “랭크는 0이 아닌 원소의 개수이다.” 원소가 모두 0이 아니어도 [[1, 2], [2, 4]]처럼 랭크가 1일 수 있다. 세는 대상은 서로 독립인 행·열의 수이다.
    • “풀랭크는 정사각행렬에만 있다.” 직사각행렬도 랭크가 min(m, n)이면 풀랭크이다. 다만 역행렬은 정사각이면서 풀랭크일 때만 존재한다.
    • “랭크는 계산 방법과 무관하게 하나로 정해진다.” 이론상으로는 그렇지만, 잡음이 있는 실제 자료에서는 매우 작은 특이값을 0으로 볼지에 따라 계산된 값이 달라진다.

    조금 더 깊게 보면

    행렬의 랭크는 특이값분해에서 0이 아닌 특이값의 개수와 정확히 일치하기 때문에, 실제 계산에서는 랭크를 직접 정의대로 구하기보다 특이값분해를 통해 유효한 랭크를 추정하는 경우가 많다. 특히 실제 데이터에는 잡음이 섞여 있어 이론적으로는 풀랭크이지만 매우 작은 특이값들이 존재하는 경우가 흔한데, 이때는 일정 기준 이하의 특이값을 무시하는 "유효 랭크(effective rank)" 개념을 사용해 데이터의 본질적인 차원을 추정한다. 논문에서 랭크가 언급될 때는 정확한 랭크인지, 아니면 잡음을 고려한 근사적 랭크인지 구분해서 읽는 것이 좋다.

    주의할 점

    랭크가 min(m, n)과 같으면 "풀랭크(full rank)"라고 하며, 정사각행렬은 풀랭크일 때만 역행렬이 존재한다. 직사각행렬은 풀랭크여도 역행렬이 없다.

    헷갈리기 쉬운 용어

    용어무엇인가랭크와의 관계
    행렬식정사각행렬에 하나의 수를 대응시키는 값정사각행렬은 행렬식이 0이 아니면 풀랭크이다
    역행렬곱해서 단위행렬이 되는 행렬정사각행렬이 풀랭크일 때만 존재한다
    특이값분해행렬을 세 행렬의 곱으로 나누는 방법0이 아닌 특이값의 개수가 랭크이다
