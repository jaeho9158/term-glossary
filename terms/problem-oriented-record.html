    문제중심기록 (Problem-Oriented Medical Record)

    간호기록›문제중심기록
    간호학
    한 줄 정의: 대상자의 문제 목록을 중심으로 자료, 계획, 경과를 체계적으로 정리하는 기록 방식이다.

    쉽게 풀면

    환자의 문제를 목록으로 만들고, 그 문제를 중심으로 기록을 정리하는 방법이에요. 예를 들어 환자의 모든 문제를 번호가 매겨진 목록으로 만들어두고, 각 문제마다 계획과 경과를 따로 정리하는 기록 방식이다. 여러 진료과가 하나의 환자 파일을 함께 보는 것처럼, 문제중심기록도 여러 직종이 같은 문제 목록을 공유하는 구조다.

    왜 중요한가

    대상자의 문제 목록을 중심으로 자료, 계획, 경과를 정리함으로써, 문제 중심의 체계적인 접근으로 여러 직종 간 협업 기록을 용이하게 하는 방식으로 다뤄진다.

    논문에서는 이렇게 쓰입니다

    문제중심기록에서 각 문제별로 SOAP기록을 작성하였다.

    문제중심기록이 SOAP기록의 상위 틀로 사용됨을 보여준다.

    "문제 목록에 새로운 진단이 추가되자 관련 부서 기록에도 해당 문제 번호를 참조하는 경과기록이 이어졌다."

    문제 목록의 갱신이 여러 부서의 기록에 일관되게 반영되는 문제중심기록의 통합적 특징을 보여준다.

    문제중심기록에서는 '#1 고혈압, #2 당뇨' 처럼 문제 목록을 만들고 각 문제별로 SOAP 형식의 경과기록을 이어 붙인다.

    문제 목록을 기준으로 여러 직종의 기록이 통합되는 실제 방식을 보여주는 문장이다.

    조금 더 깊게 보면

    이 방식도 문제목록의 정확성과 최신성에 크게 의존하므로, 목록 관리가 소홀해지면 기록의 연속성이 저하될 수 있다. 문제중심기록은 자료(Database), 문제목록, 초기계획, 경과기록의 네 가지 구성요소로 이루어지며, SOAP(또는 SOAPIE·SOAPIER)는 이 중 경과기록 부분을 작성하는 구체적 형식에 해당한다. 이 방식은 여러 직종이 같은 문제 목록을 공유하기 때문에, 한 직종이 파악한 문제가 다른 직종의 기록에도 참조되어 팀 전체의 정보 공유를 돕는다는 점이 강조된다. 이 방식은 자료(Database), 문제목록, 초기계획, 경과기록의 네 요소로 구성되며 SOAP 계열 형식은 그중 경과기록에 해당한다.

    주의할 점

    문제중심기록은 문제 목록 관리가 정확해야 전체 기록의 일관성이 유지된다.

    문제중심기록은 여러 직종이 같은 문제 목록을 공유하기 때문에, 한 직종이 파악한 문제가 다른 직종의 기록에도 참조되어 팀 전체의 정보 공유를 돕는다는 점이 강조된다.

    문제중심기록은 문제 목록 관리가 정확해야 전체 기록의 일관성이 유지된다. 문제 목록에 없는 새로운 증상이 경과기록에만 언급되고 목록에 반영되지 않으면 다른 직종이 이를 놓칠 위험이 있다.
