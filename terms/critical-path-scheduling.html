    주공정일정계획 (Critical Path Scheduling)

    산업공학
    한 줄 정의: 프로젝트를 구성하는 여러 작업들의 선후 관계를 분석하여, 전체 프로젝트 완료 기간을 결정짓는 가장 긴 작업 경로인 주공정을 찾아 일정을 관리하는 기법입니다.

    쉽게 풀면

    여러 작업이 얽혀 있는 건축 프로젝트를 생각해 보세요. 어떤 작업은 다른 작업이 끝나야만 시작할 수 있고, 어떤 작업은 동시에 진행해도 상관없습니다. 이 작업들을 순서대로 연결했을 때 가장 오래 걸리는 경로가 바로 주공정이며, 이 경로에 있는 작업이 하루라도 늦어지면 전체 프로젝트도 그만큼 늦어집니다. 주공정일정계획은 이 핵심 경로를 찾아내 집중적으로 관리하는 방법입니다.

    왜 중요한가

    프로젝트를 구성하는 모든 작업을 똑같이 관리하는 것은 비효율적이며, 실제로 전체 일정에 영향을 주는 것은 주공정에 속한 작업들뿐입니다. 주공정일정계획은 관리자가 한정된 관리 역량을 일정에 결정적인 영향을 미치는 작업에 집중할 수 있게 해주기 때문에 프로젝트 관리와 생산 스케줄링 연구에서 널리 활용됩니다.

    논문에서는 이렇게 쓰입니다

    "본 연구는 대형 건설 프로젝트의 작업 네트워크를 분석하여 주공정을 식별하고 지연 위험이 높은 작업을 도출하였다."

    여러 작업 간의 연결 관계를 분석해 전체 공기를 결정하는 핵심 작업들을 찾아내고, 지연 가능성이 큰 작업을 파악했다는 뜻입니다.

    "제안된 방법은 자원 제약 하에서도 주공정일정계획을 유지하며 총 완료 시간을 단축하였다."

    인력이나 장비 같은 자원이 한정된 상황에서도 주공정을 관리하면서 전체 프로젝트 기간을 줄이는 방법을 다뤘다는 의미입니다.

    조금 더 깊게 보면

    주공정일정계획은 대체로 각 작업의 최조착수시각과 최지착수시각을 계산하여, 이 두 값의 차이인 여유시간(float)이 0인 작업들을 주공정으로 판별합니다. 여유시간이 있는 작업은 어느 정도 지연되어도 전체 일정에 영향을 주지 않지만, 여유시간이 0인 주공정 작업은 조금이라도 지연되면 프로젝트 전체 완료일이 늦춰집니다.

    주의할 점

    기본적인 주공정일정계획은 각 작업의 소요 시간이 확정적으로 주어진다고 가정하므로, 실제 현장에서 소요 시간이 불확실한 경우에는 확률적 기법을 함께 고려해야 합니다.
