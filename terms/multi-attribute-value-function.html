    다속성가치함수 (Multi-Attribute Value Function)

    산업공학
    한 줄 정의: 여러 개의 평가 속성을 하나의 종합 점수로 통합하여 대안들의 상대적 가치를 비교할 수 있게 해주는 수학적 함수입니다.

    쉽게 풀면

    노트북을 고를 때 가격, 성능, 무게, 배터리 지속시간 등 여러 기준을 동시에 고려하게 됩니다. 다속성가치함수는 이런 여러 기준 각각의 점수를 매기고, 기준별 중요도(가중치)를 곱해 더함으로써 하나의 종합 점수로 합쳐주는 계산식입니다. 이 종합 점수를 비교하면 여러 대안 중 어떤 것이 전반적으로 더 나은지 판단할 수 있습니다.

    왜 중요한가

    산업공학의 설비 선정, 공급업체 평가, 입지 선정 등 다기준 의사결정 문제는 서로 성격이 다른 여러 기준을 동시에 고려해야 합니다. 다속성가치함수는 이런 복잡한 문제를 하나의 비교 가능한 수치로 정리해 합리적이고 일관된 의사결정을 지원합니다.

    논문에서는 이렇게 쓰입니다

    "비용, 납기, 품질 세 가지 속성에 대해 가법형 다속성가치함수를 구성하여 공급업체 대안을 평가하였다."

    이 예문은 여러 평가 기준의 점수를 가중합으로 결합해 공급업체를 비교한 사례입니다.

    "입지 후보지에 대해 다속성가치함수를 적용한 결과와 전문가 정성평가 결과를 비교 검증하였다."

    이 예문은 정량적 다속성가치함수 평가 결과의 타당성을 정성적 평가와 비교해 확인한 사례입니다.

    조금 더 깊게 보면

    다속성가치함수는 흔히 각 속성별 단일가치함수(single attribute value function)를 정의한 뒤, 속성 간 가중치를 곱하여 합산하는 가법형(additive) 형태로 구성됩니다. 각 속성의 가중치는 스윙가중치법과 같은 기법으로 산정되는 경우가 많으며, 속성 간 상호작용이 존재할 경우 곱셈형이나 다른 비선형 형태가 사용되기도 합니다.

    주의할 점

    가법형 함수는 속성들이 서로 독립적이라는 가정을 전제로 하는데, 실제로는 속성 간 상충 관계나 상호작용이 존재할 수 있어 이 가정이 항상 성립하지는 않습니다.
