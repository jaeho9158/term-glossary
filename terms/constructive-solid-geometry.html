    조합입체기하 (Constructive Solid Geometry)

    기계공학
    한 줄 정의: 정육면체, 원기둥, 구와 같은 기본 도형들을 합집합, 교집합, 차집합 같은 불리언 연산으로 조합하여 복잡한 3차원 형상을 만드는 모델링 방식입니다.

    쉽게 풀면

    레고 블록을 조합하듯이, 기본 도형들을 서로 더하거나 빼서 원하는 형상을 만드는 방법이라고 생각하면 됩니다. 예를 들어 큰 원기둥에서 작은 원기둥을 빼면 파이프 모양이 만들어지고, 정육면체와 구를 합치면 모서리가 둥근 상자 형태를 만들 수 있습니다. 이 방식은 어떤 도형을 어떤 순서로, 어떤 연산으로 조합했는지를 그대로 기록해 두기 때문에, 나중에 기본 도형의 크기만 바꿔도 전체 형상이 다시 계산됩니다.

    왜 중요한가

    조합입체기하는 형상을 단순한 기본 도형과 논리적 연산의 조합으로 정의할 수 있어 개념이 직관적이고 데이터 구조가 간결하기 때문에, 초기 CAD 시스템의 근간이 되었으며 지금도 기계 부품의 개념 설계와 해석용 형상 단순화에 활용됩니다.

    논문에서는 이렇게 쓰입니다

    "조합입체기하(constructive solid geometry) 기법을 이용해 복잡한 부품 형상을 기본 도형들의 불리언 연산으로 재구성하였다."

    복잡한 부품을 단순한 도형들의 조합으로 다시 표현해서 다루기 쉽게 만들었다는 뜻입니다.

    "본 연구는 조합입체기하 트리 구조를 경계표현법으로 변환하여 렌더링 및 가공 경로 생성에 활용하였다."

    불리언 연산의 조합 이력을 면과 모서리로 이루어진 다른 방식의 데이터로 바꿔서 화면 표시와 가공 계획에 사용했다는 의미입니다.

    조금 더 깊게 보면

    조합입체기하는 기본 도형(프리미티브)과 불리언 연산 순서를 이진 트리 구조로 저장하며, 이 트리를 CSG 트리라고 부릅니다. 이 방식은 형상의 이력이 명확하고 자료구조가 간단하다는 장점이 있지만, 곡면이 복잡한 형상을 표현하는 데는 한계가 있어 실제 CAD 시스템에서는 경계표현법과 결합되어 사용되는 경우가 많습니다.

    주의할 점

    조합입체기하는 기본 도형의 조합만으로는 자유곡면과 같은 복잡한 형상을 정밀하게 표현하기 어렵기 때문에, 정교한 곡면 설계에는 NURBS 곡면 모델링 등 다른 방식이 함께 필요합니다.
