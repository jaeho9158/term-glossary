    전자문서교환 (Electronic Data Interchange (EDI))

    경영학
    한 줄 정의: 발주서, 송장, 선적통지 등 기업 간 거래문서를 표준화된 전자 형식으로 컴퓨터 시스템 간 직접 교환함으로써 서류 처리시간과 오류를 줄이는 정보시스템 기술이다.

    쉽게 풀면

    회사끼리 주고받는 발주서나 송장 같은 서류를 종이 대신 정해진 전자 형식으로 컴퓨터끼리 바로 주고받는 방식이다.

    논문에서는 이렇게 쓰입니다

    EDI는 ANSI X12, UN/EDIFACT 같은 국제표준 문서형식을 사용해 서로 다른 기업의 정보시스템 간 자동화된 데이터 교환을 가능하게 한다.

    구매기업의 발주 데이터가 EDI 표준 형식으로 변환되어 공급업체 시스템에 자동 입력되면 수작업 재입력 없이 즉시 주문처리가 이루어진다.

    주의할 점

    전통적 EDI는 구축비용과 표준 준수 부담이 커서 중소기업 확산에 제약이 있었으며 최근에는 웹 기반 API 연동으로 대체되는 추세다.
