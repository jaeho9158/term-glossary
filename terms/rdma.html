    RDMA(원격 직접 메모리 접근) (RDMA (Remote Direct Memory Access))

    컴퓨터과학·AI

    ✓ 출처 대조 2026-11-08

    한 줄 정의: 네트워크로 연결된 다른 컴퓨터의 메모리에 운영체제나 CPU를 거치지 않고 직접 접근해 데이터를 주고받는 기술.

    쉽게 풀면

    보통 컴퓨터 간에 데이터를 주고받으려면 운영체제와 CPU가 데이터를 여러 번 복사하고 처리하는 과정을 거쳐야 해서 시간이 걸린다. RDMA는 이 과정을 생략하고, 한 컴퓨터가 다른 컴퓨터의 메모리에 마치 자신의 메모리인 것처럼 직접 데이터를 읽고 쓸 수 있게 해준다. 그 결과 지연 시간이 크게 줄고 CPU 부담도 낮아진다. 흔히 인피니밴드 네트워크와 함께 쓰이며, 대규모 분산 학습에서 GPU 간 데이터 교환 속도를 끌어올리는 데 중요한 역할을 한다.

    왜 중요한가

    RDMA는 대규모 분산 시스템에서 통신 지연과 CPU 오버헤드를 줄이는 핵심 기술이기 때문에, 대규모 언어모델 학습이나 분산 데이터베이스, 고성능 컴퓨팅(HPC) 연구에서 시스템 성능을 좌우하는 요소로 다뤄진다. GPU 클러스터의 규모가 커질수록 노드 간 통신이 전체 학습 속도의 병목이 되는 경우가 많아, RDMA 기반 네트워크 설계와 최적화는 시스템 논문에서 빠지지 않는 주제이다.

    핵심 정리

    • RDMA는 한 컴퓨터의 메모리에서 다른 컴퓨터의 메모리로, 양쪽 운영체제를 거치지 않고 네트워크로 데이터를 옮기는 기술이다. 처리량이 높고 지연이 낮아 대규모 병렬 컴퓨터 클러스터에서 특히 유용하다.
    • 네트워크 어댑터가 데이터를 응용 프로그램 메모리와 선로 사이에서 직접 옮기므로 운영체제 버퍼로의 복사가 없다(제로카피). CPU 작업, 캐시 사용, 문맥 전환도 필요 없다.
    • 수신 쪽은 요청이 끝났다는 알림을 받지 않는데, 이를 한쪽만 관여하는 통신이라고 한다. 응용은 제출 큐에 작업 요청을 넣고 완료 큐로 응답을 확인한다.
    • 구현은 InfiniBand, RoCE(RDMA over Converged Ethernet), iWARP(TCP/IP 위에서의 RDMA) 등이 있다. InfiniBand는 RDMA 기능을 제공하며 4x 링크 기준 처리량이 SDR 8 Gbit/s에서 NDR 400 Gbit/s까지 세대별로 올랐다.

    예시로 보기

    구현특징
    InfiniBand스위치드 패브릭 구조. 신용 기반 알고리즘으로 어댑터 사이 무손실 통신을 보장한다
    RoCE v1이더넷 링크 계층 프로토콜(EtherType 0x8915). 한 이더넷 브로드캐스트 영역 안에서만 쓰이고 라우팅되지 않는다
    RoCE v2UDP 위의 인터넷 계층에서 동작해 라우팅되며 UDP 목적지 포트 4791이 예약되어 있다
    iWARPTCP/IP를 전송 계층으로 쓰는 이더넷 위 RDMA. 표준 기반의 저렴한 인프라를 목표로 한다

    RoCE는 이더넷에서 돌기 때문에 InfiniBand에 가까운 성능을 내려면 무손실 이더넷이 필요할 수 있으며, 흐름 제어나 우선순위 흐름 제어(PFC)로 구성한다. PFC는 네트워크 전체 교착 상태를 일으킬 수 있다.

    자주 하는 오해

    • RDMA는 TCP/IP를 대체하는 새 프로토콜 이름이 아니라 전송 방식의 한 종류이며, 위의 구현마다 장비와 조건이 다르다.
    • RoCE v2는 UDP를 쓰므로 자체 신뢰성이 없다. 이를 보완하려면 LAN 전체를 컨버지드 이더넷 스위치로 구성하거나 핸드셰이크를 더하는 신뢰성 RoCE를 써야 하며, 후자는 성능이 줄어든다.
    • RDMA 전송에는 신뢰 연결(RC)과 비신뢰 데이터그램(UD)이 있다. RC는 요청을 잃지 않게 보존하고, UD는 연결이 없어 큐 하나로 여러 호스트를 상대할 수 있다.
    • InfiniBand는 1999년 Future I/O와 NGIO의 통합에서 나왔고 1.0 명세는 2000년에 나왔다.

    조금 더 깊게 보면

    RDMA는 커널을 거치지 않고 데이터를 전송하는 커널 바이패스(kernel bypass)와, CPU 개입 없이 네트워크 카드가 직접 메모리에 접근하는 제로카피(zero-copy) 방식을 함께 활용해 낮은 지연 시간을 달성한다. 이를 구현하는 방식으로는 인피니밴드 외에도 이더넷 위에서 RDMA를 구현한 RoCE(RDMA over Converged Ethernet)나 iWARP 같은 프로토콜이 있으며, 어떤 프로토콜을 쓰느냐에 따라 필요한 네트워크 장비와 설정이 달라진다.

    주의할 점

    RDMA를 쓰려면 이를 지원하는 전용 네트워크 카드와 스위치가 필요하며, 일반적인 클라우드 인스턴스에서는 항상 지원되지는 않는다.
