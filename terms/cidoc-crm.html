    CIDOC 개념참조모델 (CIDOC Conceptual Reference Model)

    박물관학
    한 줄 정의: CIDOC 개념참조모델이란 서로 다른 문화유산 기관의 소장품 정보를 공통된 개념 구조로 표현하여 데이터 교환과 통합 검색을 가능하게 하는 국제 표준 데이터 모델을 말합니다.

    쉽게 풀면

    박물관마다 소장품 정보를 기록하는 방식이 다르면, 여러 기관의 자료를 한꺼번에 검색하기가 어렵습니다. CIDOC 개념참조모델은 이런 문제를 해결하기 위해 만들어진 일종의 공통 언어입니다. "이 물건은 누가, 언제, 어디서 만들었는가"와 같은 정보를 어느 기관이든 같은 구조로 표현하도록 정해두면, 서로 다른 시스템끼리도 정보를 주고받고 통합해서 검색할 수 있게 됩니다.

    왜 중요한가

    박물관학에서 CIDOC 개념참조모델은 디지털 소장품 정보 통합과 국제 협력 연구의 기반 기술로 다뤄집니다. 여러 기관의 데이터를 연계하는 통합 플랫폼이나 연구 목적의 데이터 통합 작업에서 이 모델을 참조하는 사례가 논문에서 자주 언급됩니다.

    논문에서는 이렇게 쓰입니다

    "소장품 데이터베이스를 CIDOC CRM 구조에 맞춰 재설계함으로써 타 기관 자료와의 연계 검색이 가능해졌다."

    이 문장은 이 모델을 적용해 서로 다른 기관 간 정보 연동이 실현된 사례를 설명합니다.

    "문화유산 통합 정보시스템 구축 연구에서는 CIDOC CRM을 기반으로 한 데이터 스키마 설계 방안이 제안되었다."

    이 예문은 이 모델이 시스템 설계 단계에서 이론적 토대로 활용됨을 보여줍니다.

    조금 더 깊게 보면

    CIDOC 개념참조모델은 사물, 사건, 사람, 장소, 시간 등을 개체와 그 사이의 관계로 표현하는 방식을 사용합니다. 이를 통해 단순한 목록형 데이터베이스보다 훨씬 유연하게 복잡한 역사적 맥락과 관계를 기술할 수 있으며, 국제박물관협의회 산하 위원회를 중심으로 지속적으로 개정되고 있습니다.

    주의할 점

    이 모델은 개념적 구조를 제공할 뿐 특정 소프트웨어나 데이터베이스 제품을 의미하는 것은 아니므로, 실제 도입 시에는 이를 구현하는 별도의 시스템 설계가 필요합니다.
