    MARC고정길이필드 (MARC Fixed Field)

    MARC›MARC레코드›MARC필드›MARC고정길이필드
    문헌정보학
    한 줄 정의: MARC레코드에서 008 필드처럼 각 자리의 위치가 미리 정해진 코드 값을 담는 필드로, 언어, 발행국, 자료 대상 수준 등 검색과 분류에 활용되는 구조적 정보를 담고 있다.

    쉽게 풀면

    MARC에서 자리마다 어떤 값이 들어갈지 미리 정해져 있는 필드로, 언어나 발행국 같은 코드 정보를 담는다.

    왜 중요한가

    고정길이필드(리더, 006/007/008)는 자료유형·언어·출판연도·대상 이용자 등을 정해진 위치의 부호로 담아, 시스템이 텍스트 파싱 없이 검색 제한과 통계 집계를 할 수 있게 합니다. 목록에서 '연도 범위'나 '자료 유형' 필터는 이 필드에 의존합니다. 자료의 언어나 출판 연도, 대상 독자층 같은 정보를 텍스트 필드에서 매번 문자열로 찾아 해석하는 대신 정해진 위치의 부호 하나만 읽으면 되므로, 대량의 레코드를 다루는 시스템에서는 고정길이필드가 처리 속도와 검색 필터링의 효율성을 크게 높여 줍니다.

    논문에서는 이렇게 쓰입니다

    본 연구는 MARC고정길이필드의 언어 코드 값을 활용해 다국어 장서의 언어별 분포를 자동으로 집계하였다.

    고정길이필드의 코드 값을 이용해 장서의 언어 분포를 자동으로 집계했다는 점을 설명한 문장이다.

    "타 기관에서 이관된 서지레코드 중 상당수는 MARC고정길이필드 값이 비어 있거나 기본값으로 남아 있어 별도의 보정 작업이 필요했다."

    기관 간 데이터를 합칠 때 고정길이필드가 제대로 채워지지 않아 손질이 필요했다는 실무적 어려움을 설명한 문장이다.

    조금 더 깊게 보면

    고정길이 부호는 입력 오류가 눈에 잘 띄지 않아 품질이 낮은 경우가 많고, 자료유형별로 008 필드의 자릿수 정의가 달라 리더의 유형 부호를 먼저 해석해야 읽을 수 있습니다. 가변길이필드의 텍스트와 고정필드 부호가 불일치하는 레코드가 흔하다는 점이 데이터 정제 연구에서 반복 보고됩니다. 006은 하나의 레코드가 여러 성격을 겸하는 혼합자료의 추가 특성을, 007은 매체별 물리적 특성을, 008은 모든 레코드에 공통되는 일반 고정길이 정보를 담당하도록 역할이 나뉘어 있어, 세 필드는 서로 다른 층위의 정보를 보완적으로 제공합니다.

    주의할 점

    MARC고정길이필드는 각 자리 위치의 의미가 표준 코드표에 정의되어 있어, 코드표를 확인하지 않고 임의로 값을 해석하면 오류가 생길 수 있다는 점에 유의해야 한다.

    고정길이필드의 부호는 사람이 눈으로 보아도 무엇을 뜻하는지 직관적으로 알기 어려워 입력 오류가 나도 쉽게 발견되지 않으므로, 정기적인 자동 검증 절차 없이는 부정확한 값이 오랫동안 방치될 위험이 있다.
