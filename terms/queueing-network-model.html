    대기네트워크모형 (Queueing Network Model)

    산업공학
    한 줄 정의: 여러 개의 대기행렬 노드가 서로 연결되어 고객이나 작업이 노드 사이를 이동하는 시스템 전체를 분석하는 확률모형입니다.

    쉽게 풀면

    병원을 예로 들면 환자가 접수창구를 거쳐 진료실로 가고, 다시 검사실이나 수납창구로 이동하는 것처럼 여러 단계의 대기 지점을 순서대로 혹은 선택적으로 거치는 경우가 많습니다. 대기네트워크모형은 이렇게 여러 개의 대기행렬(노드)이 서로 연결된 전체 시스템을 하나의 모형으로 분석하는 도구입니다. 한 노드에서의 병목이 다른 노드의 대기시간에 어떻게 영향을 미치는지도 함께 볼 수 있습니다.

    왜 중요한가

    실제 생산시스템이나 서비스시스템은 하나의 대기행렬로 끝나지 않고 여러 공정이나 창구가 연결되어 있으므로, 개별 대기모형만으로는 전체 흐름을 설명하기 어렵습니다. 대기네트워크모형은 시스템 전체의 처리량과 병목 지점을 파악해 생산라인 설계나 서비스 프로세스 개선에 활용된다는 점에서 중요합니다.

    논문에서는 이렇게 쓰입니다

    "본 연구는 개방형 대기네트워크모형을 이용하여 다단계 생산공정의 병목 공정을 식별하였다."

    여러 공정이 연결된 생산라인 전체를 하나의 네트워크로 보고 병목 지점을 찾아냈다는 뜻입니다.

    "Jackson 네트워크 형태의 대기네트워크모형을 적용하여 각 노드의 정상상태 확률분포를 도출하였다."

    대기네트워크의 대표적 이론적 형태를 이용해 시스템이 안정 상태에 이르렀을 때의 확률적 특성을 계산했다는 의미입니다.

    조금 더 깊게 보면

    대기네트워크모형은 크게 고객이 시스템 밖에서 들어와 밖으로 나가는 개방형 네트워크와, 고정된 수의 고객이 네트워크 내부를 순환하는 폐쇄형 네트워크로 구분됩니다. 각 노드 간 이동 확률과 각 노드의 서비스율이 전체 시스템의 처리량과 대기시간을 결정하는 주요 요소입니다.

    주의할 점

    노드 수가 많아지고 노드 간 이동 규칙이 복잡해질수록 해석적으로 정확한 해를 구하기 어려워, 시뮬레이션이나 근사적 방법에 의존하는 경우가 많습니다.
