    계산토크제어 (Computed Torque Control)

    로봇공학
    한 줄 정의: 로봇의 비선형 동역학 모델을 역동역학으로 계산해 상쇄하고, 남은 선형화된 오차 시스템에 PID와 같은 선형제어기를 적용하는 제어 기법이다. 피드백 선형화의 대표적인 응용이다.

    쉽게 풀면

    로봇의 복잡한 물리 특성을 미리 계산해서 없애버리고, 남은 간단한 오차만 PID로 다스리는 방법이에요.

    왜 중요한가

    로봇의 동역학 모델로 비선형 항을 소거해 각 관절을 독립적인 선형 2차 시스템으로 바꾸는 방법으로, 고속 궤적 추종에서 PID만으로는 얻을 수 없는 정밀도를 제공합니다. 모델 기반 로봇 제어의 출발점이어서 적응·강건 제어 논문의 비교 기준으로 쓰입니다.

    논문에서는 이렇게 쓰입니다

    제안된 계산토크제어기는 질량행렬과 코리올리항을 실시간 보상하여 선형 오차 동역학을 얻고 이를 PD제어로 안정화하였다.

    논문에서 계산토크제어는 동역학 기반 제어의 대표 예시로, 모델 기반 보상과 피드백 제어를 결합한 방식으로 설명됩니다.

    조금 더 깊게 보면

    완전한 동역학 모델을 전제로 하므로 동역학 파라미터 식별 정확도가 성능을 좌우하고, 모델 오차와 마찰은 그대로 외란으로 남습니다. 역동역학 제어·피드백 선형화와 동의어로 쓰이며, 계산 부담 때문에 과거에는 실용성이 의심되었지만 지금은 제어 주기 안에 충분히 계산되어 보편화되었습니다.

    주의할 점

    계산토크제어는 정확한 동역학 모델을 필요로 하므로 모델 불확실성이 크면 성능이 크게 저하될 수 있다.
