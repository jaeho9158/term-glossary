    자원기술프레임워크 (Resource Description Framework)

    문헌정보학
    한 줄 정의: 웹상의 자원에 관한 정보를 주어-서술어-목적어로 이루어진 트리플 형태로 표현하는 시맨틱웹의 기본 데이터 모형으로, 링크드 데이터와 온톨로지 구축의 기술적 토대가 된다.

    쉽게 풀면

    웹에 있는 정보를 '무엇이-어떤 관계로-무엇과 연결된다'는 세 부분 문장 형태로 표현하는 시맨틱웹의 기본 데이터 형식이다.

    왜 중요한가

    시맨틱웹의 기본 데이터 모형으로, 링크드데이터와 온톨로지 구축의 기술적 토대가 되며, 도서관계에서는 BIBFRAME 같은 차세대 서지데이터 모형의 기반 기술로 다뤄집니다. MARC 레코드가 하나의 자료 안에 여러 정보를 뭉쳐 담는 방식이라면, RDF는 자료·저자·주제 같은 개별 자원을 각각 독립된 노드로 두고 그 사이의 관계를 트리플로 연결하므로, 서로 다른 기관이 만든 데이터라도 같은 자원을 가리키는 노드끼리 자연스럽게 이어 붙일 수 있습니다.

    논문에서는 이렇게 쓰입니다

    본고는 자원기술프레임워크의 트리플 구조가 서로 다른 기관의 서지데이터를 상호 연결하는 링크드 데이터 구현의 기초가 된다고 설명하였다.

    RDF의 트리플 구조가 여러 기관 데이터를 서로 연결하는 링크드 데이터 구현의 기반이 된다는 점을 설명한 문장이다.

    연구팀은 자원 간 관계를 주어-서술어-목적어 트리플로 표현하는 자원기술프레임워크를 활용해 온톨로지를 구축하였다.

    트리플 형태의 데이터 모형이 시맨틱웹과 링크드 데이터 구축의 기술적 토대가 됨을 보여주는 서술이다.

    조금 더 깊게 보면

    RDF 자체는 데이터를 표현하는 형식일 뿐 의미 관계의 논리적 정합성을 보장하지 않으므로, 실제 추론이 필요한 경우 OWL 같은 온톨로지 언어와 결합해 사용해야 합니다. 같은 트리플 집합이라도 RDF/XML, Turtle, JSON-LD 같은 여러 문법으로 직렬화될 수 있어, 겉보기에 형식이 달라 보이는 데이터라도 실제로는 동일한 주어-서술어-목적어 구조를 담고 있는 경우가 많습니다.

    주의할 점

    자원기술프레임워크는 데이터 표현 모형일 뿐이므로, 실제 의미 있는 정보 연계를 위해서는 SKOS나 OWL 같은 어휘·온톨로지 표준과 함께 사용해야 한다는 점에 유의해야 한다.

    RDF는 이름을 붙일 수 없는 임시 자원을 나타내는 빈 노드도 허용하는데, 이런 노드는 다른 데이터셋과 연결할 고유 식별자가 없어 링크드데이터로서의 연결 가능성이 제한된다는 점을 설계 시 고려해야 하며, 가능하면 안정적인 식별자를 가진 자원으로 표현하는 편이 바람직하다. 이는 데이터 설계 단계에서부터 고려할 사항이다.
