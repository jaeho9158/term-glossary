    GeoJSON 형식 (GeoJSON Format)

    지도학
    한 줄 정의: JSON 문법을 이용해 점, 선, 면 등의 지리 도형과 속성 정보를 표현하는 텍스트 기반 공간자료 형식입니다.

    쉽게 풀면

    GeoJSON은 지도 도형을 웹에서 흔히 쓰는 JSON이라는 텍스트 형식으로 표현한 것입니다. 메모장으로도 열어서 내용을 확인할 수 있을 만큼 구조가 단순하고 사람이 읽기에도 어렵지 않습니다. 웹 지도 서비스와 프로그래밍 언어 대부분이 JSON을 기본으로 다루기 때문에, GeoJSON은 웹에서 지도 데이터를 주고받을 때 특히 편리합니다. 하나의 파일 안에 여러 도형과 속성을 함께 담을 수 있다는 점도 특징입니다.

    왜 중요한가

    웹 기반 지도 서비스와 오픈소스 GIS 생태계가 확산되면서 브라우저에서 바로 읽고 렌더링할 수 있는 GeoJSON의 활용도가 크게 늘었습니다. 연구자들도 분석 결과를 웹 지도나 대화형 시각화로 공유할 때 자주 사용하며, 데이터 공유의 개방성과 재현성을 높이는 형식으로 다뤄집니다.

    논문에서는 이렇게 쓰입니다

    "수집된 관측 지점 좌표를 GeoJSON(GeoJSON) 형식으로 정리하여 웹 기반 시각화 도구에 입력하였다."

    현장에서 얻은 좌표 자료를 웹에서 바로 표시할 수 있도록 GeoJSON으로 변환했다는 의미입니다.

    "공개된 행정경계 GeoJSON 파일을 활용하여 지역 단위 통계지도를 제작하였다."

    이미 배포된 GeoJSON 경계 자료를 불러와 통계지도의 바탕 도형으로 사용했다는 뜻입니다.

    조금 더 깊게 보면

    GeoJSON은 점(Point), 선(LineString), 면(Polygon) 및 이들의 복합 형태를 하나의 표준 문법으로 표현하며, 좌표는 일반적으로 위경도(WGS84) 기준으로 기록됩니다. 속성 정보는 도형과 함께 key-value 쌍으로 저장되어 별도의 테이블 파일 없이도 자료를 한 파일에 담을 수 있습니다.

    주의할 점

    텍스트 기반이라 대용량 자료에서는 파일 크기가 커지고 처리 속도가 느려질 수 있어, 방대한 자료에는 다른 형식이 더 적합할 수 있습니다. 좌표계 표기가 명시되지 않은 경우 다른 좌표계 자료와 혼동할 위험도 있습니다.
