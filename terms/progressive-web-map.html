    프로그레시브 웹지도 (Progressive Web Map)

    지도학
    한 줄 정의: 프로그레시브 웹지도는 프로그레시브 웹 앱(PWA) 기술을 적용해 오프라인 사용, 빠른 로딩, 앱과 유사한 사용 경험을 제공하는 웹지도를 말합니다.

    쉽게 풀면

    보통 웹지도는 인터넷이 연결되어 있어야만 사용할 수 있습니다. 하지만 프로그레시브 웹지도는 한 번 방문한 지도 데이터를 기기에 저장해 두었다가, 인터넷이 끊겨도 어느 정도 사용할 수 있도록 만든 지도입니다. 마치 자주 가는 길을 미리 사진으로 찍어 저장해 두었다가, 신호가 안 잡히는 곳에서도 그 사진을 보며 길을 찾는 것과 비슷합니다. 또한 별도의 앱을 설치하지 않아도 브라우저에서 앱과 비슷한 사용 경험을 제공하는 것이 특징입니다.

    왜 중요한가

    프로그레시브 웹지도는 웹지도학에서 네트워크 환경이 불안정한 상황에서도 안정적인 지도 서비스를 제공하기 위한 방안으로 다뤄집니다. 모바일 환경에서 데이터 사용량과 로딩 속도를 줄이는 데도 유리해, 사용자 경험 개선과 관련된 연구에서 다뤄지는 주제입니다. 별도 앱 설치 없이 접근할 수 있다는 점도 서비스 확산에 유리한 요소로 언급됩니다.

    논문에서는 이렇게 쓰입니다

    "프로그레시브 웹지도 기술을 적용한 결과 재접속 시 지도 로딩 시간이 단축되는 것으로 나타났다."

    프로그레시브 웹지도 기술 적용 후 로딩 속도가 개선된 결과를 설명하는 문장입니다.

    "네트워크 연결이 불안정한 현장 조사 환경에서 프로그레시브 웹지도의 오프라인 기능이 유용하게 활용되었다."

    현장 조사처럼 인터넷 연결이 어려운 환경에서 오프라인 기능이 활용된 사례를 설명합니다.

    조금 더 깊게 보면

    프로그레시브 웹지도는 서비스 워커와 같은 브라우저 기술을 활용해 지도 타일과 관련 데이터를 기기에 캐시로 저장합니다. 이 방식은 앞서 설명한 타일 캐싱 개념을 클라이언트 측에서도 적용한 형태라고 볼 수 있습니다. 오프라인 상태에서는 이미 저장된 범위의 지도만 제한적으로 사용할 수 있는 것이 일반적입니다.

    주의할 점

    프로그레시브 웹지도가 완전한 오프라인 지도 기능을 대체하는 것은 아니며, 저장되지 않은 지역의 지도는 여전히 인터넷 연결이 필요하다는 한계가 있습니다.
