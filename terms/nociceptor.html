    통각수용기 (Nociceptor)

    뇌과학·신경과학
    한 줄 정의: 통각수용기는 조직을 손상시키거나 손상시킬 가능성이 있는 자극을 감지해 척수와 뇌로 위험 신호를 보내는 감각 뉴런이다.

    쉽게 풀면

    뜨거운 것에 닿거나 베였을 때 먼저 반응하는 것이 통각수용기다. 이 감각 뉴런은 해로울 수 있는 열, 압력, 화학 자극을 전기 신호로 바꿔 중추로 보낸다. 실제 통증 감각은 신호를 받은 뇌에서 만들어진다. 전달 섬유에 따라 첫 번째의 날카로운 통증과 늦게 오는 둔한 통증이 나뉜다.

    왜 중요한가

    통각수용기는 통증 연구와 진통제 개발 논문의 출발점이다. TRPV1 같은 이온 채널이 표적으로 자주 다뤄지고, 염증에서 생기는 감작은 만성 통증 논의와 연결된다. 통각, 통증, 통각수용기를 구분하는 것은 논문 해석의 기본이다.

    어디에 있고 어떻게 생겼나

    통각수용기는 신경 말단으로 감각을 받고, 신호는 후근신경절이나 삼차신경절에 있는 세포체에서 시작된다. 얼굴 부위는 삼차신경절이 담당한다. 발생 과정에서는 신경능선 줄기세포에서 나오며 비펩타이드형은 RUNX1에 의존한다.

    유형은 몇 가지로 나뉜다. 다중양식 통각수용기는 기계, 열, 화학 자극에 모두 반응하고 C 섬유에서 가장 흔하며 물질 P와 CGRP를 방출한다. 침묵 통각수용기는 정상 자극에는 반응하지 않고 염증이 있을 때 주로 활성화된다. 전달 섬유는 Aδ 섬유와 C 섬유이며 수초 여부와 지름에 따라 전도 속도가 다르다.

    맡은 기능

    통각수용기는 열, 기계, 화학 자극을 신경말단에서 전기 신호로 바꾸고, 역치를 넘으면 활동전위가 중추로 전달된다. 변환에는 TRP 채널, ASIC, P2 퓨린 수용체, TrkA 같은 수용체와 채널이 관여한다.

    • 열: TRPV1 채널이 반응하며 약 43°C 부근의 열에 활성화된다고 기술된다.
    • 기계: 압력, 피부 변형, 피부를 절개하는 손상이 포함된다.
    • 화학: 캡사이신, 아크롤레인, 산성 환경, 지방산 아민 등이 포함된다.
    • 신경전달물질: 주로 글루탐산이 방출되며 물질 P와 CGRP도 함께 방출된다.

    신호는 척수 뒤뿔을 거쳐 시상으로 가고, 대뇌의 여러 영역에서 위치, 강도, 정서와 인지 측면이 처리된다. 뇌에서는 엔케팔린 같은 물질로 통증을 억제하는 하행 조절이 일어난다.

    연구에서 다루는 방식

    연구에는 의식이 있는 사람 피험자와 동물 모델이 쓰인다. 침습적 측정이 활동을 바꿀 수 있고 아주 작은 구조를 기록하기 어렵다는 한계가 있다. 논문에서는 Aδ와 C 섬유의 반응을 구분해 기록하거나, TRPV1 같은 채널을 작용 물질로 조절해 반응 변화를 본다.

    해석에서는 염증이나 손상이 있으면 평소에 무해한 자극에도 반응하게 되는 감작을 고려한다. 통증 관문 조절 이론은 무해한 자극이 통증 신호를 억제할 수 있다고 설명한다. Aδ 섬유의 전도 속도는 출처별 범위가 조금 다를 수 있어, 두 출처가 일치하는 범위만 적었다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "캡사이신을 투여하자 TRPV1 경로를 통해 통각수용기 활성이 증가하였다."

    캡사이신이 TRPV1 경로를 활성화한다는 설명을 반영한다.

    "염증 모델에서 평소 무해한 자극에도 통각수용기가 반응하는 감작이 관찰되었다."

    염증이나 손상 후 감작이 일어난다는 서술에 대응한다.

    "Aδ 섬유와 C 섬유의 전도 속도 차이로 통증의 시간 양상을 설명하였다."

    빠른 날카로운 통증과 느린 지속 통증이 섬유에 따라 나뉜다는 설명이다.

    조금 더 깊게 보면

    통각을 전달하는 주된 섬유는 Aδ 섬유와 C 섬유다. Aδ 섬유는 약 5~30 m/s로 전도하며 첫 번째의 날카로운 통증을 만들고, C 섬유는 약 0.4~2 m/s로 느리게 전도하며 늦게 나타나고 오래 지속되는 통증을 만든다. 다중양식 통각수용기는 기계, 열, 화학 자극에 모두 반응하며 C 섬유에서 가장 흔하다.

    침묵 통각수용기는 정상 자극에는 반응하지 않고 염증이 있을 때 주로 활성화된다. 통각수용기는 1906년 찰스 스콧 셔링턴이 처음 기술했다.

    주의할 점

    통각수용기는 감각 뉴런의 말단이고, 통각은 감지 과정이며, 통증은 뇌에서 만들어지는 의식적 지각이다. 세 가지는 서로 다른 개념이다. 통각수용기는 피부의 일반적 온도 범위를 감지하는 온도수용기와도 구별된다. TRPM8은 냉자극 감지 채널이고 TRPV1은 유해한 열 감지 채널이다. 한국어 표기로는 위키백과 한국어판의 통각수용기가 확인되며, 다른 표기는 이번 조사에서 확인하지 못했다.
