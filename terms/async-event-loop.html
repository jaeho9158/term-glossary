    비동기 처리와 이벤트 루프 (Asynchronous Programming and Event Loop)

    컴퓨터과학
    한 줄 정의: 시간이 걸리는 작업의 완료를 기다리지 않고 다른 일을 먼저 처리한 뒤, 그 작업이 끝나면 결과를 처리하도록 계속 순회하며 확인하는 프로그램 실행 방식입니다.

    쉽게 풀면

    식당 종업원을 생각해 봅시다. 종업원이 한 테이블의 음식이 나올 때까지 주방 앞에 가만히 서서 기다린다면(동기 처리), 그 사이 다른 손님은 아무도 응대받지 못합니다. 하지만 유능한 종업원은 주문만 넣어두고 곧바로 다른 테이블로 이동해 다른 손님을 받다가, 음식이 준비됐다는 벨이 울리면 그때 가서 서빙합니다(비동기 처리). 이때 "지금 어떤 벨이 울렸는지" 계속 돌아다니며 확인하는 종업원의 순회 동작이 바로 이벤트 루프입니다. 프로그램도 파일 읽기나 네트워크 응답처럼 시간이 걸리는 작업을 기다리는 동안 다른 코드를 실행하고, 작업이 끝나면 이벤트 루프가 그 결과(콜백)를 처리하도록 순서를 조율합니다.

    논문에서는 이렇게 쓰입니다

    "제안 시스템은 비동기 처리와 이벤트 루프 기반으로 구현되어, 다수의 네트워크 요청을 동시에 대기하면서도 단일 스레드로 높은 처리량을 달성하였다."

    이 문장은 "여러 요청을 각각 별도의 실행 흐름 없이도, 하나의 실행 흐름이 대기 시간을 낭비하지 않고 번갈아 처리하도록 설계해 효율을 높였다"는 뜻입니다.

    주의할 점

    비동기 처리는 프로세스와 스레드를 여러 개 두어 병렬로 실행하는 것과는 다른 개념입니다. 스레드를 여러 개 쓰는 것은 실제로 여러 작업을 동시에 진행하는 것이지만, 이벤트 루프 기반 비동기 처리는 보통 하나의 실행 흐름 안에서 대기 시간만 겹쳐 쓰는 방식이라, 계산량이 많은 작업 자체를 빠르게 만들어주지는 않습니다.
