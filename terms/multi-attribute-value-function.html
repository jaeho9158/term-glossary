    다속성가치함수 (Multi-Attribute Value Function)

    산업공학
    한 줄 정의: 서로 다른 여러 평가 기준(속성)의 점수를 가중치를 적용해 하나의 종합적인 가치 점수로 결합하는 함수로, 다기준 의사결정에서 대안을 비교하는 데 사용됩니다.

    쉽게 풀면

    노트북을 살 때 가격, 성능, 무게, 디자인처럼 여러 기준을 동시에 고려해서 최종 점수를 매기는 상황을 생각해보세요. 다속성가치함수는 이렇게 서로 다른 성격의 여러 기준 각각의 점수를, 기준별 중요도(가중치)를 곱해 더하는 방식으로 하나의 종합 점수로 합쳐주는 수학적 도구입니다. 이를 통해 겉보기에 비교하기 어려운 대안들(가격은 싸지만 성능이 낮은 제품 vs 비싸지만 성능이 좋은 제품)을 하나의 잣대로 순위를 매길 수 있습니다.

    왜 중요한가

    산업공학의 의사결정분석에서는 설비 선정, 공급업체 평가, 입지 선정 등 여러 기준을 동시에 만족시켜야 하는 문제가 흔합니다. 다속성가치함수는 이런 다기준 문제를 하나의 종합 지표로 정리해 대안 간 비교와 최적 대안 선택을 체계적으로 수행할 수 있게 해줍니다.

    논문에서는 이렇게 쓰입니다

    "본 연구는 스윙가중치법으로 산정한 가중치를 다속성가치함수에 대입하여 후보 설비 대안들의 종합 점수를 계산하였다."

    여러 기준별 가중치를 결합해 각 설비 대안의 최종 순위를 매겼다는 뜻입니다.

    "공급업체 평가에서 품질, 납기, 비용 세 속성에 대한 다속성가치함수를 구성하여 최적 공급업체를 선정하였다."

    여러 평가 기준을 하나의 함수로 종합해 공급업체를 비교했다는 의미입니다.

    조금 더 깊게 보면

    가장 단순한 형태는 각 속성의 값(정규화된 점수)에 가중치를 곱해 모두 더하는 가법형(additive) 모형이며, 속성 간 상호작용이 있는 경우에는 곱셈형이나 비선형 형태의 함수를 사용하기도 합니다. 각 속성의 값을 비교 가능한 점수로 변환하는 과정(정규화)과 가중치를 정하는 과정(스윙가중치법 등)이 함수 구성의 핵심 단계입니다.

    주의할 점

    가법형 모형은 속성 간 독립성을 가정하는 경우가 많아, 속성들이 서로 강하게 연관되어 있는 상황에서는 결과가 왜곡될 수 있습니다. 가중치와 정규화 방식의 선택에 따라 최종 순위가 달라질 수 있으므로 민감도 분석이 함께 필요합니다.
