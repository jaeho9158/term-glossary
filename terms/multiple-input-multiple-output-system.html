    다중입출력 시스템 (Multiple-Input Multiple-Output System)

    전기전자공학
    한 줄 정의: 송신 측과 수신 측 모두 여러 개의 안테나를 사용하여 동일 시간·주파수 자원에서 데이터 전송 성능을 높이는 무선통신 기술입니다.

    쉽게 풀면

    한 사람이 한 개의 파이프로 물을 보내는 것보다 여러 개의 파이프를 동시에 사용하면 더 많은 물을 보낼 수 있는 것과 비슷합니다. MIMO는 송신기와 수신기 양쪽에 여러 개의 안테나를 두어, 같은 주파수와 시간 자원 안에서도 여러 갈래의 신호 경로를 동시에 활용합니다. 이를 통해 더 많은 데이터를 보내거나, 같은 데이터를 여러 경로로 중복 전송하여 통신의 신뢰성을 높일 수 있습니다.

    왜 중요한가

    주파수 자원이 제한된 무선통신 환경에서 데이터 전송량을 늘리는 것은 매우 중요한 과제입니다. MIMO는 추가 주파수 대역 없이도 안테나 수를 늘려 전송 용량과 신뢰성을 동시에 개선할 수 있어, 이동통신 표준을 포함한 다양한 무선 시스템에서 핵심 기술로 자리잡았습니다.

    논문에서는 이렇게 쓰입니다

    "4x4 MIMO 구성을 통해 단일 안테나 대비 채널 용량이 크게 증가함을 확인하였다."

    안테나 개수 증가에 따른 용량 향상을 설명하는 예입니다.

    "제안한 프리코딩 기법은 MIMO 채널에서 공간 다중화 이득을 극대화하도록 설계되었다."

    MIMO 시스템의 송신 신호 처리 기법을 설명하는 예입니다.

    조금 더 깊게 보면

    MIMO는 크게 여러 개의 독립적인 데이터 스트림을 동시에 보내 전송률을 높이는 공간 다중화와, 같은 데이터를 여러 경로로 보내 신뢰성을 높이는 공간 다이버시티로 나누어 활용할 수 있습니다. 채널 상태에 따라 두 방식 사이에서 절충하거나 결합하는 다양한 신호처리 기법이 연구되어 왔습니다.

    주의할 점

    MIMO의 이득은 안테나 사이의 채널이 서로 충분히 구분되는 조건에서 잘 발휘되며, 안테나 간 상관도가 높은 환경에서는 기대한 만큼의 성능 향상을 얻기 어려울 수 있습니다.
