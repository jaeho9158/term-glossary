    대규모 언어 모델 (LLM)

    머신러닝›인공신경망›대규모 언어 모델
    컴퓨터과학·AI
    한 줄 정의: 수많은 텍스트 데이터를 학습해 다음에 올 단어를 예측하는 방식으로 문장을 생성하고 이해하는 초대형 인공신경망 모델이다.

    쉽게 풀면

    책을 수억 권 읽은 사람에게 "옛날 옛적에 한 마을에"라고 운을 떼면, 그 사람은 이야기가 어떻게 이어질지 자연스럽게 예측해서 다음 문장을 이어갈 수 있을 것이다. LLM(Large Language Model)은 바로 이런 방식으로 작동한다.

    인터넷의 방대한 글을 학습해서 "이 단어 다음에는 어떤 단어가 올 확률이 높은가"를 통계적으로 익히고, 이를 반복해 자연스러운 문장을 만들어낸다. ChatGPT나 Claude 같은 서비스의 핵심 엔진이 바로 이 LLM이다.

    왜 중요한가

    LLM은 자연어처리 연구의 패러다임을 특정 과제마다 별도 모델을 학습하던 방식에서, 하나의 거대한 사전학습 모델을 다양한 과제에 적용하는 방식으로 바꾸어 놓았다.

    그 결과 기계번역, 요약, 질의응답 같은 전통적인 자연어처리 분야뿐 아니라 의료, 법률, 교육, 소프트웨어 개발 등 실무 전반에서 LLM을 활용한 응용 연구가 폭발적으로 늘어났다.

    동시에 환각, 편향, 비용, 안전성 같은 LLM 고유의 문제들이 새로운 연구 주제로 떠오르면서, 오늘날 컴퓨터과학·AI 논문에서 가장 빈번하게 다뤄지는 주제 중 하나가 되었다.

    핵심 정리

    • 대규모 언어 모델(LLM)은 매우 많은 텍스트로 다음에 올 말을 예측하도록 학습한 신경망이다. 대부분 트랜스포머 구조(Vaswani 등, 2017)를 쓰며, 파라미터(가중치) 수가 수십억에서 수천억 개에 이른다.
    • Brown 등(2020)의 GPT-3는 1,750억 개 파라미터 모델로, 예시 몇 개만 프롬프트에 넣어도 새 과제를 수행하는 ‘few-shot’ 능력을 보였다. 이후 사전학습 뒤 사람의 선호나 지시에 맞춰 추가 학습(미세조정)하는 방식이 일반화되었다.
    • Kaplan 등(2020)은 모델 크기, 데이터 양, 계산량을 늘릴수록 손실이 멱법칙으로 줄어든다는 경험적 규칙(스케일링 법칙)을 보고했다.
    • 활용 방식은 프롬프트로 지시하는 방식(프롬프트 엔지니어링), 특정 자료로 추가 학습하는 미세조정, 외부 문서를 검색해 붙이는 검색증강생성(RAG) 등이다.

    글은 먼저 정수 토큰으로 바뀌어 모델에 들어간다. 바이트 쌍 인코딩(BPE)은 가장 자주 붙어 나오는 기호 쌍을 반복해서 합쳐 어휘를 만드는 방식이다. 주의(attention)는 고정된 문맥 창 안에서만 작동하며, 1억 1,700만 개 파라미터의 GPT-2는 문맥 창이 약 1,000토큰이었다. 사전학습한 모델은 지시 튜닝과 사람 피드백 기반 강화학습(RLHF)으로 다듬어 지시를 따르는 보조자로 쓴다. 환각은 검색증강생성(RAG)이나 미세조정으로 줄이려는 시도가 있다.

    예시로 보기

    트랜스포머 모델의 크기를 어림해 보자. Kaplan 등(2020)은 임베딩을 뺀 파라미터 수를 N ≈ 12 · L · d²로 어림했다(L은 층 수, d는 은닉 차원). GPT-3는 L = 96, d = 12,288로 알려져 있어 계산하면 12 × 96 × 12,288² ≈ 1,739억 개로, 보고된 1,750억 개와 비슷하다.

    메모리도 어림할 수 있다. 파라미터마다 16비트(2바이트)로 저장하면 1,750억 × 2바이트 = 350 GB로, 단일 그래픽 카드 한 장에 올릴 수 없는 크기이다. 그래서 논문에서는 모델 병렬화나 양자화(더 적은 비트로 저장)를 쓴다고 적다. 위 계산은 저장에 필요한 최소 메모리 어림이며, 실제로는 활성값과 학습 상태 때문에 훨씬 더 필요하다.

    자주 하는 오해

    오해바로잡기
    LLM은 사실을 저장한 데이터베이스다.통계적으로 그럴듯한 말을 생성하는 모델이어서 사실과 다른 내용을 자신 있게 만들어 낼 수 있다(환각현상; Ji 등, 2023).
    모델이 클수록 항상 좋다.Hoffmann 등(2022)은 주어진 계산량에서 모델 크기와 학습 데이터 양을 함께 늘려야 한다고 보고했다. 크기만의 문제는 아니다.
    모델이 말을 이해한다는 증거다.이해 여부는 논쟁이 있는 주제이다. Bender 등(2021)은 형태만 학습한 모델의 한계와 위험을 지적했다.
    같은 질문에는 늘 같은 답을 낸다.샘플링 설정(온도 등)에 따라 달라지므로, 논문에서는 모델 버전, 날짜, 설정을 적어야 재현이 가능하다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "본 연구는 GPT-4 기반 대규모 언어 모델(LLM)을 활용하여 환자 상담 기록을 자동으로 요약하는 파이프라인을 제안한다."

    이 문장은 연구자가 방대한 텍스트로 학습된 언어 모델을 도구로 사용해, 긴 글을 짧게 요약하는 작업을 자동화했다는 뜻이다.

    "소규모 법률 문서 코퍼스로 LLM을 파인튜닝한 결과, 판례 검색 과제에서 범용 모델 대비 정확도가 유의하게 향상되었다."

    법률 문서로 이미 학습된 대규모 언어 모델을 추가로 특화 학습시켰더니, 관련 판례를 찾아내는 작업에서 일반 모델보다 더 정확한 결과를 냈다는 뜻이다.

    "코드 생성 벤치마크에서 여러 LLM의 성능을 비교한 결과, 모델 크기 증가가 항상 성능 향상으로 이어지지는 않는 것으로 나타났다."

    프로그램 코드를 자동으로 작성하는 능력을 여러 언어 모델로 시험해봤더니, 모델이 크다고 해서 반드시 성능이 더 좋아지는 것은 아니었다는 뜻이다.

    조금 더 깊게 보면

    현재의 LLM 대부분은 트랜스포머 구조를 기반으로 하며, 방대한 텍스트로 다음 단어를 예측하도록 사전학습한 뒤, 사람이 선호하는 답변 형태에 맞추기 위해 지시문 미세조정(instruction tuning)이나 인간 피드백 기반 강화학습(RLHF) 같은 후처리 단계를 거치는 경우가 많다. 논문에서는 모델의 능력을 파라미터 수, 학습 데이터 규모, 다양한 벤치마크 점수 등으로 비교하며, 최근에는 단순히 모델을 키우는 것 외에도 검색증강생성(RAG), 도구 사용, 추론 시간 확장 같은 기법들이 성능 향상의 주요 축으로 함께 다뤄진다.

    주의할 점

    LLM은 다음에 올 단어를 확률적으로 예측할 뿐, 사실 여부를 직접 "확인"하지는 않는다. 그래서 그럴듯하지만 틀린 내용을 마치 사실처럼 만들어내는 환각현상이 발생할 수 있으며, 이는 LLM의 근본적인 한계로 논의된다.
