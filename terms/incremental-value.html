    증분 가치 (Incremental value)

    통계
    한 줄 정의: 이미 쓰고 있는 예측 변수나 모형에 새 변수(생체표지자, 검사 등)를 더했을 때 예측 성능이 추가로 얼마나 좋아지는지를 가리키는 개념이다.

    쉽게 풀면

    기존 모형으로도 이미 예측이 되는데, 새 지표를 하나 더했더니 얼마나 더 잘 맞히게 되었는지를 따지는 것이다. 새 지표가 결과와 관련이 있다는 사실만으로는 부족하고, 이미 가진 정보 위에 더해지는 몫이 있어야 한다.

    왜 중요한가

    새 생체표지자나 검사의 유용성을 주장하는 논문에서 자주 등장하는 논거이다. 논문을 읽을 때는 기준 모형이 무엇인지, 성능 향상을 어떤 지표(AUC 변화, 재분류 개선, 우도비 검정)로 쟀는지, 신뢰구간이 0을 포함하는지 확인해야 한다.

    계산과 범위

    • 기준 모형에 새 변수를 더한 확장 모형을 만들어, 두 모형의 성능 차이를 본다. 흔한 지표는 ROC 곡선 아래 면적(AUC, c 통계량)의 변화이다.
    • 한 연구는 나이, 입원 시 신경학적 중증도, 입원 시 혈당으로 이루어진 기준 모형에 CRP-알부민 비를 더해 AUC, DeLong 검정, 우도비 검정, 부트스트랩 낙관 보정 성능으로 비교했다(Toprak 등, 2026).
    • AUC 변화만으로는 부족하다는 지적이 있다. AUC가 유의하게 변하지 않아도 새 표지자가 개인의 위험 구간을 바꿀 수 있고, 반대로 확립된 위험 인자 각각은 c 통계량에는 작은 영향만 주면서도 많은 환자를 더 정확히 재분류한다(Cook, 2007). 이런 한계를 보완하려고 통합 민감도·특이도와 재분류표에 바탕을 둔 두 새 지표가 제안되었다(Pencina 등, 2008).

    해석 기준

    • 새 표지자가 결과와 통계적으로 유의하게 연관된다는 것만으로는 충분하지 않다(Pencina 등, 2008). 연관성과 추가적인 임상적 유용성은 같지 않다(Toprak 등, 2026).
    • 뇌졸중 중환자 146명 연구의 주 분석(141명)에서는 기준 모형에 입원 시 CRP-알부민 비를 더하자 AUC가 0.768에서 0.783으로 바뀌었다(ΔAUC +0.016, 95% 신뢰구간 −0.024~+0.055, DeLong p = 0.444). 신뢰구간이 효과 없음과 불확실한 임상적 의미의 양의 효과를 모두 포함해, 증분 예측 가치가 입증되지 않았다고 결론지었다(Toprak 등, 2026).
    • c 통계량은 위험 구간으로 나누는 모형의 평가에서는 최적이 아닐 수 있고, 보정(calibration)도 정확한 위험 평가에 같이 중요하다(Cook, 2007).

    보고 방법

    • 기준 모형에 들어간 변수를 사전에 정해 밝힌다.
    • 확장 모형과 기준 모형의 성능을 같은 자료에서 비교하고, 변화량(ΔAUC 등)에 신뢰구간을 붙인다. 과적합을 줄이려고 부트스트랩 같은 낙관 보정을 했는지 적는다(Toprak 등, 2026).
    • AUC 하나만 보고하지 말고 보정과 재분류 지표도 함께 보고하는 편이 좋다(Cook, 2007; Pencina 등, 2008).
