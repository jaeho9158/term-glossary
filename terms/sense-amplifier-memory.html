    메모리 감지증폭기 (Sense Amplifier)

    전기전자공학
    한 줄 정의: 메모리 셀이 비트라인에 만든 미약한 전압 차이를 온전한 논리 레벨로 증폭해 읽어내는 회로입니다.

    쉽게 풀면

    메모리 셀 하나는 아주 작아서, 저장된 값을 읽으려고 비트라인에 연결해도 전압이 수십 밀리볼트 정도밖에 움직이지 않습니다. 감지증폭기는 이 작은 차이를 감지해 0과 1로 딱 떨어지는 전압으로 부풀려 주는 회로입니다. 보통 두 개의 인버터를 서로 물려 만든 구조를 쓰는데, 아주 작은 불균형만 주어져도 양쪽이 빠르게 반대 방향으로 밀려나 결정이 내려집니다.

    왜 중요한가

    메모리의 읽기 속도와 동작 가능한 최저 전압이 사실상 이 회로의 감도에 의해 결정되기 때문에, 메모리 설계에서 가장 민감한 블록으로 다뤄집니다. 셀이 작아질수록 비트라인에 생기는 신호가 더 작아지므로 감지증폭기의 오프셋을 줄이는 기법이 미세공정 메모리 논문의 단골 주제이며, 저항변화 메모리 같은 새 메모리에서도 읽기 회로 설계가 핵심 과제로 제시됩니다.

    논문에서는 이렇게 쓰입니다

    "오프셋 보정 기법을 적용한 감지증폭기를 사용해 비트라인 신호가 40mV 수준인 조건에서도 읽기 오류율을 낮추었다."

    감지 회로의 입력 오프셋을 줄여 더 작은 신호까지 정확히 판별하도록 개선한 사례입니다.

    조금 더 깊게 보면

    동적 램에서는 셀의 전하를 비트라인과 나누어 쓰는 전하 공유 방식으로 신호를 만들고, 읽는 과정에서 셀 내용이 파괴되므로 감지 직후 같은 값을 다시 써 넣는 복원 동작이 뒤따릅니다. 정적 램에서는 셀이 능동적으로 비트라인을 끌어내리므로 파괴적 읽기는 아니지만, 읽는 동안 셀 내용이 뒤집히지 않도록 잡음 여유를 확보해야 합니다. 감지증폭기 자체의 입력 오프셋은 두 트랜지스터의 공정변이 부정합에서 오므로 소자 면적을 키우거나 오프셋 상쇄 기법을 쓰며, 전류 방식과 전압 방식 가운데 응용에 맞는 구조를 선택합니다.

    주의할 점

    감지증폭기는 신호를 증폭하는 회로이면서 동시에 어느 쪽인지 결정하는 회로여서, 입력 차이가 오프셋보다 작으면 임의의 방향으로 결정이 내려집니다. 이 점에서 선형 증폭기와는 성격이 다릅니다. 정적 램 셀이 저장 소자를 가리킨다면, 이 항목은 그 값을 읽어내는 주변 회로를 가리킵니다.

    관련 용어

    동적 램 셀 정적 램 셀 공정변이 부정합 차동 증폭기 저항변화 메모리
