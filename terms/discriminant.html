    이차방정식의 판별식 (Discriminant of a Quadratic Equation)

    이차방정식›이차방정식의 판별식
    수학
    한 줄 정의: 이차방정식 ax²+bx+c=0에서 b²-4ac 값의 부호로 실근의 개수(서로 다른 두 실근, 중근, 실근 없음)를 판별하는 식이다.

    쉽게 풀면

    이차방정식을 근의 공식으로 풀면 x = (-b ± √(b²-4ac)) / 2a 인데, 여기서 루트(√) 안에 들어가는 b²-4ac를 "판별식"이라고 부른다. 이 값의 부호만 보면 방정식을 실제로 풀지 않고도 답이 몇 개인지 미리 알 수 있다.

    판별식이 0보다 크면 루트 안이 양수이므로 서로 다른 두 실근이 나오고, 0이면 루트 안이 0이 되어 두 근이 겹치는 중근(하나의 실근)이 나오며, 0보다 작으면 루트 안이 음수가 되어 실수 범위에서는 근이 존재하지 않는다.

    예를 들어 x²-4x+3=0은 b²-4ac = 16-12 = 4 > 0이므로 서로 다른 두 실근(x=1, x=3)을 가지고, x²-2x+1=0은 4-4=0이므로 중근 x=1을 하나만 갖는다.

    왜 중요한가

    판별식은 방정식을 실제로 풀지 않고도 해의 성질을 미리 파악할 수 있게 해주므로, 계산 비용을 줄이거나 시스템의 정성적 특성을 빠르게 진단하는 데 유용하다. 특히 제어공학이나 회로이론에서는 시스템의 안정성이나 진동 여부가 특성방정식 근의 성질에 좌우되는 경우가 많아, 판별식과 이를 확장한 개념들이 시스템 거동을 사전에 판단하는 이론적 근거로 자주 활용된다.

    핵심 정리

    • 이차방정식 ax² + bx + c = 0 (a ≠ 0)의 판별식은 D = b² − 4ac이다. 근의 공식 x = (−b ± √D) / 2a에서 제곱근 안의 값이며, 두 근의 차는 √D / |a|이다.
    • 실수 범위에서: D > 0이면 서로 다른 두 실근, D = 0이면 하나의 근(중근, 겹친 두 근), D < 0이면 실근이 없고 서로 켤레인 두 허근이 있다.
    • 그래프로는 이차함수 y = ax² + bx + c가 x축과 두 점에서 만나는지(D > 0), 접하는지(D = 0), 만나지 않는지(D < 0)와 같다.
    • 계수가 정수이고 D가 완전제곱수이면 근이 유리수이다. b = 2b′이면 D/4 = b′² − ac를 써서 계산을 줄일 수 있다. 19세기 중반 실베스터(Sylvester)가 ‘판별식(discriminant)’이라는 이름을 도입한 것으로 알려져 있다.

    판별식이라는 용어는 영국 수학자 제임스 조지프 실베스터(Sylvester)가 1851년에 만들었다. 일반 다항식의 판별식은 계수로 이루어진 다항식 함수로, 근을 구하지 않고도 근의 성질을 알려 준다. 대수적으로 닫힌 체에서는 최고차항 계수의 2n−2제곱에 근들의 차의 제곱의 곱을 곱한 값이며, 다항식이 중근을 가질 때 정확히 0이 된다.

    예시로 보기

    판별식을 계산한 예이다.

    방정식D = b² − 4ac결과
    x² − 4x + 3 = 016 − 12 = 4서로 다른 두 실근 x = 1, 3
    x² − 2x + 1 = 04 − 4 = 0중근 x = 1
    x² + 2x + 5 = 04 − 20 = −16실근 없음, 허근 x = −1 ± 2i

    매개변수가 있는 경우: x² + kx + 9 = 0이 실근을 가질 조건은 D = k² − 36 ≥ 0, 곧 |k| ≥ 6이다. k = 6일 때 D = 0이고 중근 x = −3이 된다. 실근의 개수를 방정식을 풀지 않고도 매개변수 조건으로 바꿀 수 있다는 점이 판별식의 쓰임이다.

    삼차식 ax³ + bx² + cx + d의 판별식은 b²c² − 4ac³ − 4b³d − 27a²d² + 18abcd이고, x³ + px + q 꼴에서는 −4p³ − 27q²로 간단해진다. 실계수일 때 양수이면 서로 다른 세 실근이고 음수이면 실근 하나와 켤레 허근 둘이다. 일반 n차에서 중근이 없는 실계수 다항식의 부호는 비실근의 개수가 4의 배수이면 양수이고 아니면 음수이다.

    자주 하는 오해

    오해바로잡기
    D < 0이면 해가 없다.실수 범위에서만 그렇고, 복소수 범위에서는 항상 두 근(중복 포함)이 있다.
    D = 0이면 근이 하나뿐이다.같은 근이 두 번 겹친 것(중근)이다. 근의 중복도까지 세면 두 개이다.
    D가 클수록 좋은 해다.D의 크기는 두 근 사이 거리를 정할 뿐 좋고 나쁨과 무관하다.
    통계의 판별분석이나 판별타당도와 관련 있다.이름만 비슷한 별개 개념이다. 판별분석은 집단을 구분하는 통계 기법, 판별타당도는 측정의 타당도를 말한다.

    이차곡선에서는 이차항의 판별식 b² − ac의 부호가 곡선의 모양을 정해, 음수이면 타원(원), 0이면 포물선, 양수이면 쌍곡선이다. 대수적 수체의 판별식은 정수환의 크기를 재고 분기하는 소수를 결정하며, 에르미트(Hermite)의 정리에 따르면 판별식이 주어진 범위 안인 수체는 유한개뿐이다.

    이 용어를 직접 쓴 국내 논문 문장은 아직 모으지 못했다. 모이는 대로 출처와 함께 싣는다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "제어 시스템의 특성방정식이 이차식으로 단순화될 경우, 판별식의 부호를 통해 시스템의 진동 여부를 사전에 판단할 수 있다."

    이 문장은 공학 논문에서 시스템을 나타내는 이차방정식의 판별식 부호를 확인함으로써, 실제 값을 다 계산하지 않고도 해(근)의 성질과 시스템의 거동(진동 여부 등)을 미리 파악했다는 뜻이다.

    "조화진동자 모델의 감쇠계수를 변화시키며 판별식의 부호가 바뀌는 임계 조건을 구하였다."

    물리학에서는 감쇠진동 방정식의 판별식이 부호를 바꾸는 지점이 과감쇠·임계감쇠·부족감쇠를 가르는 경계가 된다는 점을 설명한다.

    "최소제곱법으로 얻은 이차 회귀모형의 판별식을 확인해 곡선이 실수 범위에서 교점을 갖는지 검토하였다."

    통계·데이터분석 논문에서도 회귀모형이나 곡선적합 결과를 해석할 때 판별식을 보조적으로 활용하는 경우가 있다.

    조금 더 깊게 보면

    이차방정식의 판별식 b²-4ac는 삼차방정식이나 더 고차의 다항식으로도 일반화될 수 있으며, 고차 판별식 역시 방정식이 중근을 갖는지 여부를 알려주는 역할을 한다. 또한 판별식은 이차곡선(원, 타원, 포물선, 쌍곡선)을 분류하는 데도 쓰이는데, 일반형 이차식의 계수로 만든 판별식 부호에 따라 곡선의 종류가 결정된다.

    이처럼 판별식은 단순한 근의 개수 판정 도구를 넘어, 대수학과 기하학 여러 영역에서 형태를 분류하는 공통된 원리로 확장되어 쓰인다.

    주의할 점

    판별식이 음수라고 해서 방정식에 해가 "없다"는 뜻은 아니며, 실수 범위에서만 해가 없다는 의미이다. 복소수 범위까지 확장하면 항상 두 개의 근이 존재하며, 이는 이차방정식과 인수분해가 항상 같은 방식으로 연결되지는 않는다는 점과도 관련이 있다.
