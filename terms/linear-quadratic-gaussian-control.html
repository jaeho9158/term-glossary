    선형이차가우시안 제어 (Linear Quadratic Gaussian Control)

    전기전자공학
    한 줄 정의: 가우시안 잡음이 있는 환경에서 칼만 필터로 상태를 추정하고, 그 추정값을 선형이차조절기(LQR)에 넣어 최적 제어 입력을 계산하는 기법입니다.

    쉽게 풀면

    안개 속에서 운전할 때, 먼저 흐릿하게 보이는 정보로 최대한 정확하게 도로 상황을 추측한 뒤, 그 추측을 바탕으로 운전을 결정하는 과정과 비슷합니다. LQG 제어는 두 단계로 이루어집니다. 첫 단계는 잡음이 섞인 측정값으로부터 칼만 필터를 이용해 시스템의 실제 상태를 가장 정확하게 추정하는 것이고, 두 번째 단계는 그렇게 추정된 상태를 실제 상태인 것처럼 LQR에 넣어 최적의 제어 입력을 계산하는 것입니다.

    왜 중요한가

    실제 시스템에서는 모든 상태를 정확히 측정할 수 없고 측정값에는 잡음이 섞여 있기 마련이므로, 추정과 제어를 결합한 LQG는 현실적인 제어 시스템 설계에서 널리 다뤄지는 접근법입니다. 또한 추정기와 제어기를 독립적으로 설계해도 전체 시스템이 최적이 된다는 분리 원리(separation principle)가 성립한다는 점에서 이론적으로도 중요하게 다뤄집니다.

    어떤 절차인가

    플랜트 ẋ = Ax + Bu + w, y = Cx + v (w, v: 가우시안 백색잡음)와 비용 J = E[ ∫(xᵀQx + uᵀRu) dt ] 에 대해 LQG는 다음 두 문제로 풀립니다(분리 원리).

    1. LQR 이득 K: 잡음이 없다고 보고 대수 리카티 방정식을 풀어 u = −K x̂ 를 구합니다(선형이차조절기).
    2. 칼만 필터 이득 L: 잡음 공분산으로 쌍대(dual) 리카티 방정식을 풀어 x̂̇ = A x̂ + B u + L(y − C x̂) 를 구합니다(칼만 필터).
    3. 결합: 추정 상태 x̂ 를 LQR 제어 법칙에 그대로 넣습니다(확실성 등가).

    가상의 스칼라 예: ẋ = x + u + w, y = x + v, Q = R = 1, 잡음 공분산 W = V = 1. LQR 쪽은 2p − p² + 1 = 0 의 해로 K = 1 + √2 ≈ 2.414 이고, 칼만 필터 쪽도 같은 형태의 식이어서 L = 1 + √2 ≈ 2.414 입니다. 결합 시스템의 상태를 (x, 추정오차)로 쓰면 상태 행렬이 위삼각 블록 형태(대각 성분 a−bK 와 a−Lc)가 되어 고유값은 둘 다 −√2 ≈ −1.414 입니다. 곧 폐루프 극이 제어기 설계와 추정기 설계에서 따로 정해집니다.

    언제 쓰고 무엇을 얻나

    • 언제 쓰나: 상태를 모두 잴 수 없고 측정 잡음과 공정 잡음이 있으며, 에너지(입력)와 오차를 한 비용으로 조절하고 싶은 선형 제어 문제입니다. Athans(1971)가 설계에서의 역할을 정리했습니다.
    • 얻는 것: 가정이 맞으면 비용을 최소화하는 최적 해와 체계적인 설계 절차(두 리카티 방정식)를 얻습니다.
    • 한계: Doyle(1978)은 LQG 제어기가 LQR이 가진 안정 여유를 보장하지 않을 수 있음을 반례로 보였습니다. 모델 불확실성이 클 때는 루프 전달 회복(LTR)이나 H무한 제어 같은 강인 설계를 씁니다.
    • 가정 의존: 선형 모델, 가우시안 잡음, 정확한 잡음 통계를 전제하므로 실제 잡음이 다르면 성능이 떨어집니다.

    논문에는 이렇게 적는다

    • 플랜트 모델과 잡음 가정(공분산 Qw, Rv)을 적고, 가중 행렬 Q, R의 선택 근거를 밝힙니다.
    • LQR 이득 K와 칼만 필터 이득 L, 폐루프 극(또는 고유값)을 보고합니다.
    • 성능은 시뮬레이션·실험에서 오차, 제어 입력 크기, 비용 값, 잡음 하의 응답으로 보이고, 모델 오차에 대한 민감도·강인성(안정 여유)을 함께 검증합니다.
    • 비교 대상(PID, 극배치, H무한 등)이 있다면 같은 조건에서 비교했음을 명시합니다.

    논문에서는 이렇게 쓰입니다

    예시 문장

    아래는 용어의 쓰임을 보여 주려고 만든 예시로, 실제 논문에서 가져온 문장이 아닙니다.

    "The LQG controller combines a Kalman filter for state estimation with an LQR for optimal state feedback under Gaussian noise assumptions."

    가우시안 잡음 가정 아래 칼만 필터를 이용한 상태 추정과 LQR을 이용한 최적 상태 피드백을 결합해 LQG 제어기를 구성했다는 내용입니다.

    "By the separation principle, the Kalman filter and LQR gains in the LQG design can be computed independently."

    분리 원리에 따라 LQG 설계에서 칼만 필터 이득과 LQR 이득을 각각 독립적으로 계산할 수 있다는 내용으로, 설계 절차의 편의성을 설명하는 문맥입니다.

    조금 더 깊게 보면

    LQG는 프로세스 잡음과 측정 잡음이 모두 가우시안 백색잡음이라는 가정 위에서 성립하며, 이 가정 아래에서는 추정기(칼만 필터)와 제어기(LQR)를 따로 설계해도 전체적으로 최적이 되는 분리 원리가 성립합니다. 다만 LQG 자체는 모델 불확실성에 대한 명시적인 강인성 보장을 제공하지는 않는다는 점에서 H무한 제어와 같은 강인제어 기법과 구분됩니다.

    주의할 점

    LQG는 잡음이 가우시안이라는 가정에 기반하므로, 실제 잡음이 이 가정과 크게 다르거나 모델 불확실성이 큰 경우에는 강인성이 저하될 수 있다는 한계가 있습니다.

    용어입력 정보역할
    LQR(선형이차조절기)상태를 안다고 가정이차 비용을 최소화하는 상태 피드백 이득 K
    칼만 필터잡음 섞인 측정잡음 하의 최적 상태 추정
    LQG 제어잡음 섞인 측정칼만 필터 + LQR을 결합한 출력 피드백 제어
    H무한 제어모델 불확실성최악의 경우 성능을 보장하는 강인 제어
    극배치 설계원하는 극 위치비용 최소화 없이 극을 직접 지정
