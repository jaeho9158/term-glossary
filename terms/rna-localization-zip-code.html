    RNA 국재 신호 (RNA localization zip code)

    생물학
    한 줄 정의: mRNA를 세포 안의 특정 위치로 보내도록 지정하는, mRNA 속의 짧은 서열·구조 신호입니다.

    쉽게 풀면

    편지에 우편번호를 적으면 원하는 동네로 배달되듯, 일부 mRNA에는 '이 분자를 세포의 어느 곳으로 보내라'는 표시가 들어 있습니다. 이 표시는 대개 단백질 정보가 담기지 않은 비번역 부위에 있고, 특정 단백질이 이를 알아보고 붙어서 mRNA를 목적지까지 끌고 갑니다. 이 표시를 비유적으로 '우편번호(zip code)'라고 부릅니다.

    왜 중요한가

    mRNA가 어디로 가는지가 결정되어야 국소 단백질 합성이 가능하므로, 세포 안에서 단백질이 어디에 쌓이는지를 이해하는 출발점입니다. 대표적 사례인 β-액틴 mRNA의 zip code는 원래 다른 세포 유형에서 연구되었지만, 같은 원리가 교세포 같은 새로운 세포에서도 작동하는지 확인하는 연구가 이어지고 있습니다.

    논문에서는 이렇게 쓰입니다

    "β-액틴 zip code 서열을 리포터 mRNA에 붙이자 별아교세포에서도 리포터 RNA가 세포 주변부로 국재되었다."

    해당 서열만으로도 RNA의 위치를 바꿀 수 있다는 충분성 실험을 서술한 문장입니다.

    조금 더 깊게 보면

    zip code는 단순한 염기 서열뿐 아니라 줄기-고리 같은 2차 구조로 인식되기도 합니다. 이를 인식한 RNA 결합 단백질은 운동 단백질과 세포골격을 이용해 mRNA를 이동시키고, 이동 중에는 번역을 억제하는 경우가 많습니다. 어떤 서열이 zip code인지 찾기 위해 서열을 잘게 나누어 시험하거나(MPRA) 염기를 하나씩 바꿔 보는 방법(포화 돌연변이유발)이 쓰입니다.

    주의할 점

    'zip code'는 비유적 명칭이며 모든 mRNA에 공통된 하나의 서열이 있는 것은 아닙니다. 서열을 제거했을 때 위치가 바뀌는지(필요성)와 다른 RNA에 붙였을 때 위치를 옮기는지(충분성)를 구분해 해석해야 합니다.
