    크래머 공식 (Cramer's Rule)

    수학
    한 줄 정의: 연립일차방정식의 해를 소거법 없이 행렬식(determinant)들의 비율만으로 바로 구하는 공식이다.

    쉽게 풀면

    연립방정식을 풀 때 보통은 한 변수를 다른 식에 대입하거나 더하고 빼면서 하나씩 소거해 나간다. 크래머 공식은 이런 번거로운 과정 없이, 계수들을 정해진 틀에 맞춰 행렬식이라는 하나의 숫자로 바꾼 다음, 그 숫자들끼리 나누기만 하면 각 변수의 값이 바로 나오는 지름길이다. 마치 레시피의 재료 비율표만 보고 몇 인분인지 계산하는 것처럼, 방정식을 풀지 않고도 특정 값을 뽑아낼 수 있는 공식이라고 생각하면 된다. 다만 미지수 개수만큼 행렬식을 매번 계산해야 하므로, 변수가 많아지면 오히려 비효율적이라는 한계가 있다.

    왜 중요한가

    크래머 공식은 선형방정식의 해가 계수들의 함수로서 어떻게 구성되는지를 명시적인 식으로 보여주기 때문에, 수치적으로 방정식을 반복해서 푸는 대신 해의 구조 자체를 분석해야 하는 이론적 논의(민감도 분석, 매개변수에 대한 해의 변화 등)에서 자주 인용된다. 또한 회로이론이나 제어이론처럼 변수 수가 적은 선형계를 다루는 공학 논문에서 계산 과정을 명료하게 제시하는 용도로도 쓰인다.

    핵심 정리

    • 미지수가 n개인 연립일차방정식 Ax = b에서 행렬식 det(A) ≠ 0(행렬이 가역일 조건과 같다)이면 해가 유일하며, 각 미지수는 xi = det(Ai) / det(A)이다. Ai는 A의 i번째 열을 b로 바꾼 행렬이다. 행렬 방정식 AX = B에도 확장되고 어떤 체에서도 성립한다.
    • 2×2: a1x + b1y = c1, a2x + b2y = c2의 해는 x = (c1b2 − b1c2)/(a1b2 − b1a2), y = (a1c2 − c1a2)/(a1b2 − b1a2)이다. 분모가 0이 아니어야 한다.
    • 3×3에서도 분모는 계수 행렬의 행렬식, 분자는 상수 열을 해당 열에 넣은 행렬식이다.
    • 기하학적 해석: 행렬식은 열벡터가 이루는 평행사변형의 넓이(평행육면체의 부피)이다. 한 변을 x1배 하고 카발리에리의 원리를 쓰면 이 규칙이 나온다.
    • 역사: 콜린 매클로린이 1748년에 특수한 경우를 발표했고 1729년경부터 알았을 가능성이 있다. 가브리엘 크라머가 1750년에 임의의 미지수 개수로 일반화해 발표했다.

    예시로 보기

    연립방정식 2x + y = 5, x + 3y = 10 (이 예는 설명을 위해 만든 값이다).

    • det(A) = 2·3 − 1·1 = 5이므로 해가 유일하다.
    • x = (5·3 − 1·10) / 5 = 5/5 = 1
    • y = (2·10 − 5·1) / 5 = 15/5 = 3
    • 대입하면 2·1 + 3 = 5, 1 + 3·3 = 10으로 맞는다.

    이 규칙은 해를 계수의 식으로 보여 주므로 이론적 논의에 쓰인다. 미분기하학에서는 야코비안으로 표현한 암시적 미분 공식을 준다. 정수 계획법에서는 완전단위모듈러 제약 행렬과 정수 우변이면 기저해가 정수임을 보이는 데 쓰인다. 상미분방정식에서는 매개변수 변화법으로 비동차 선형 방정식의 일반해를 구하는 데 쓰인다. 계수 행렬이 가역일 조건은 역행렬과 같다. det(A) ≠ 0이다.

    자주 하는 오해

    • “det(A) = 0이어도 쓸 수 있다”: 쓸 수 없다. 2×2에서는 분자 행렬식 중 하나라도 0이 아니면 해가 없고, 모두 0이면 부정이다. 3×3 이상에서는 분자가 0이 아니면 해가 없지만, 모든 행렬식이 0이라고 해서 부정이라고 단정할 수 없다. 예컨대 x + y + z = 1, x + y + z = 2, x + y + z = 3은 모든 행렬식이 0인데도 해가 없다.
    • “큰 연립방정식에도 효율적이다”: 단순하게 적용하면 행렬식을 n + 1개 계산해야 해서 두세 개를 넘으면 비효율적이다. 가우스 소거법은 행렬식 하나를 계산하는 비용과 비슷하다.
    • “수치 계산의 표준 방법이다”: 표준은 가우스 소거법 같은 방법이다. 다만 바레이스 알고리즘이 필요한 행렬식을 계산할 수 있고, 말라쇼노크의 알고리즘은 비용을 약 n³(1983), n³/2(1991), 행렬곱 복잡도(1997)로 줄였다. 1983년의 변형은 초기 단계를 반올림 오차 없이 계산하므로 근사를 쓸 때 가우스 소거법보다 수치적으로 안정적일 수 있다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "3개의 미지수로 이루어진 회로방정식의 해는 크래머 공식(Cramer's rule)을 이용하여 계수행렬의 행렬식으로부터 직접 도출하였다."

    이 문장은 회로 해석에서 나온 연립방정식을 반복 계산 없이 행렬식 비율로 곧바로 풀었다는 뜻이다. 공학 논문에서 변수가 2~3개인 소규모 선형계를 다룰 때, 계산 과정을 명시적으로 보여주는 용도로 자주 언급된다.

    "제어계수가 시스템 파라미터에 대해 어떻게 변하는지를 분석하기 위해, 상태방정식의 해를 크래머 공식 형태로 표현하여 각 파라미터의 기여도를 살펴보았다."

    제어이론에서 수치해 자체보다 해의 구조를 파라미터별로 분석하고자 할 때 크래머 공식이 활용되는 예이다.

    조금 더 깊게 보면

    크래머 공식으로 구한 각 변수의 값은 계수행렬의 특정 열을 상수항 벡터로 바꾼 행렬의 행렬식을, 원래 계수행렬의 행렬식으로 나눈 형태로 표현된다. 변수 개수가 n개면 행렬식을 n+1번 계산해야 하고 행렬식 계산 자체의 복잡도가 변수 수에 따라 급격히 커지기 때문에, 실제 수치 계산에서는 가우스 소거법이나 LU분해 같은 방법이 훨씬 효율적이다. 따라서 크래머 공식은 실무적 계산 도구라기보다는 해의 이론적 구조를 이해하거나 소규모 문제를 다룰 때 주로 쓰인다.

    주의할 점

    크래머 공식은 계수행렬의 행렬식이 0이 아닐 때만 사용할 수 있다. 행렬식이 0이면 해가 없거나 무수히 많은 경우이므로 이 공식 자체가 적용되지 않으며, 이런 특수한 경우는 역행렬 존재 여부와도 직결된다.
