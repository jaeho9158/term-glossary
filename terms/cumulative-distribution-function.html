    누적분포함수 (Cumulative Distribution Function)

    통계
    한 줄 정의: 어떤 값 이하가 나올 확률을 처음부터 차곡차곡 더해서 보여주는 함수입니다.

    쉽게 풀면

    시험 점수 백분위를 떠올려 보세요. "나는 80점인데, 상위 몇 %일까?"가 궁금할 때 필요한 것이 바로 "80점 이하를 받은 사람의 비율"입니다. 누적분포함수(CDF)는 이렇게 "특정 값 이하가 나올 확률"을 모든 값에 대해 계산해 둔 함수입니다.

    확률밀도함수(PDF)가 각 지점에서의 "밀도"를 보여준다면, CDF는 그 밀도를 맨 왼쪽부터 지금 지점까지 전부 쌓아 올린 "누적 합"이라고 생각하면 됩니다. 그래서 CDF는 항상 0에서 시작해 1로 끝나는, 절대 내려가지 않고 계속 올라가기만 하는 계단식(혹은 매끄러운) 곡선 모양을 갖습니다.

    왜 중요한가

    누적분포함수는 확률변수의 분포 전체를 하나의 함수로 요약해 보여주기 때문에, 분포 비교, 가설검정, 신뢰구간 계산 등 통계 분석 전반의 기초가 됩니다. 통계학뿐 아니라 신뢰성 공학, 금융 리스크 분석, 시뮬레이션 연구 등 확률적 현상을 다루는 거의 모든 분야의 논문에서 등장하는 개념입니다.

    핵심 정리

    확률변수 X의 누적분포함수(CDF) F(x) = P(X ≤ x)는 이산형이든 연속형이든 모든 확률변수에 정의됩니다.

    • 성질: 감소하지 않고(단조 증가), 오른쪽에서 연속이며, x → −∞에서 0, x → +∞에서 1입니다.
    • 구간 확률: P(a < X ≤ b) = F(b) − F(a).
    • 연속형: F′(x) = f(x)(확률밀도함수). P(X = x) = 0이므로 P(X ≤ x) = P(X < x).
    • 이산형: 확률질량이 있는 점마다 점프하는 계단 함수입니다. 점프의 크기가 그 값의 확률입니다.
    • 역함수 F⁻¹(q)는 분위수함수입니다. 백분위수, 신뢰구간의 임계값, 난수 생성(역변환법)에 쓰입니다.
    • 경험적 누적분포함수(ECDF)는 표본에서 “x 이하인 비율”로, 콜모고로프–스미르노프 검정은 ECDF와 이론 CDF의 최대 차이를 통계량으로 씁니다.

    예시로 보기

    (공식에서 직접 계산) 몇 가지 분포의 값입니다.

    분포질문계산값
    공정한 주사위P(X ≤ 3)F(3) = 3/60.500
    표준정규분포P(Z ≤ 1.96)Φ(1.96)0.9750
    표준정규분포P(−1 < Z ≤ 1)Φ(1) − Φ(−1)0.6827
    지수분포(λ = 0.5)P(X ≤ 2)F(x) = 1 − e−λx0.6321
    지수분포(λ = 0.5)P(1 < X ≤ 3)F(3) − F(1)0.3834

    역으로 Φ⁻¹(.975) = 1.96이므로 “정규분포에서 누적확률 97.5%가 되는 값이 1.96”입니다. 양측 95% 신뢰구간에 1.96이 쓰이는 이유가 이것입니다. p값도 검정통계량의 CDF에서 읽습니다. 양측검정이면 p = 2 × (1 − F(|t|))입니다(대칭 분포).

    자주 하는 오해

    • “밀도 함수 값이 확률이다”: 연속형 PDF의 값은 확률이 아니라 밀도이므로 1보다 클 수 있습니다. 확률은 PDF를 구간에서 적분한 값, 즉 CDF의 차이입니다.
    • “CDF는 정규분포에만 있다”: 모든 확률변수에 정의됩니다. 이산형이면 계단 모양입니다.
    • “연속형에서 P(X = x)는 아주 작은 양수다”: 정확히 0입니다. 그래서 연속형에서는 “x 이하”와 “x 미만”이 같지만, 이산형에서는 다릅니다.
    • “CDF는 ‘이상’을 센다”: CDF는 항상 “이하” 확률입니다. “초과”는 1 − F(x)이고, 생존분석에서는 이를 생존함수 S(x)라 부릅니다.

    예시 문장

    아래는 용어의 쓰임을 보여 주려고 만든 예시로, 실제 논문에서 가져온 문장이 아닙니다.

    "두 집단의 반응시간 분포는 콜모고로프-스미르노프 검정을 통해 누적분포함수(CDF) 상의 최대 차이를 비교하여 검정하였다."

    이 문장은 두 그룹의 데이터가 쌓여가는 패턴(CDF)을 서로 겹쳐 그려보고, 그 사이의 최대 간격이 얼마나 벌어지는지를 계산해서 두 분포가 실제로 다른지 판단했다는 뜻입니다.

    "부품의 고장시간 분포에 대한 누적분포함수를 추정하여 특정 사용 기간 내 고장 확률을 산출하였다."

    신뢰성 공학에서 부품이 특정 시점까지 고장 날 확률을 CDF를 이용해 계산했다는 뜻이다.

    "자산 수익률의 경험적 누적분포함수를 이용하여 특정 손실 수준을 넘어설 확률, 즉 VaR(Value at Risk)를 추정하였다."

    금융 리스크 분석에서 실제 관측된 데이터로부터 CDF를 구성하고, 이를 이용해 손실 위험을 수치화했다는 뜻이다.

    조금 더 깊게 보면

    CDF의 역함수는 분위수함수(quantile function)라 불리며, 특정 누적확률에 해당하는 값을 구할 때 사용되어 백분위수 계산이나 난수 생성(역변환법)에 활용됩니다. 실제 데이터를 다룰 때는 이론적 분포 대신 관측값으로부터 직접 계산한 경험적 누적분포함수(ECDF)를 자주 사용하며, 이는 표본 분포가 이론적 분포를 얼마나 잘 따르는지 시각적·통계적으로 검토하는 데 널리 쓰입니다.

    주의할 점

    CDF는 확률밀도함수(PDF)나 확률질량함수(PMF)와 헷갈리기 쉽지만 서로 다른 개념입니다. PDF/PMF 값 자체는 "그 지점에서의 확률(밀도)"이고, CDF 값은 "그 지점까지 누적된 확률"입니다. 예를 들어 연속형 변수에서는 PDF의 특정 지점 값이 1보다 클 수도 있지만, CDF 값은 언제나 0과 1 사이에 머무릅니다. 이 둘을 확률질량함수와 확률밀도함수와 함께 비교해서 이해하면 혼동을 줄일 수 있습니다.

    헷갈리기 쉬운 용어

    분포를 나타내는 함수들은 “무엇을 쌓는가”로 구분합니다.

    용어값이 뜻하는 것범위
    누적분포함수(CDF)X가 x 이하일 확률0 ~ 1, 단조 증가
    확률질량·밀도함수한 점의 확률(이산) 또는 밀도(연속)질량은 0~1, 밀도는 1보다 클 수 있음
    경험적 누적분포함수표본에서 x 이하인 비율0 ~ 1, 계단 모양
    백분위수CDF의 역함수가 주는 값자료의 단위
