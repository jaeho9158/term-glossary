    좀돌날 (Microblade)

    뗀석기›세석기›좀돌날
    고고학
    한 줄 정의: 좀돌날몸돌에서 규격화된 형태로 떼어낸 폭이 좁고 긴 돌날로, 후기구석기시대 후반에 널리 사용되었다.

    쉽게 풀면

    아주 가늘고 긴 돌날 조각으로, 여러 개를 조합해 도구를 만들었어요.

    왜 중요한가

    규격화된 형태와 제작 기법을 통해 후기구석기시대 후반 인류의 정교한 석기 제작 기술을 보여주며, 세석기 문화의 확산과 이동 경로를 추적하는 지표 유물로 활용된다.

    논문에서는 이렇게 쓰입니다

    좀돌날은 자루에 여러 개를 끼워 넣어 복합도구를 구성하는 방식으로 사용되었다.

    좀돌날 여러 개를 나무나 뼈 자루에 박아 하나의 도구로 만든 결합식 도구 제작 방식을 설명하는 문장이다.

    조금 더 깊게 보면

    좀돌날의 정확한 사용 방식은 여러 개를 자루에 결합했다는 가설이 유력하지만, 구체적인 결합 방식과 용도는 계속 연구되고 있는 사안이다.

    주의할 점

    좀돌날은 세석기 범주에 포함되지만, 세석기라는 용어가 좀돌날만을 가리키는 것은 아니다.
