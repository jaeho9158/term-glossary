    상대가치점수 (Resource-Based Relative Value Scale)

    보건학
    한 줄 정의: 각 의료행위에 투입되는 자원을 상대적 점수로 환산해 수가 산정의 기준으로 삼는 체계입니다.

    쉽게 풀면

    진료 행위마다 값을 따로 흥정할 수는 없으니, 먼저 행위들 사이의 상대적 무게를 정합니다. 의사의 업무량, 진료에 드는 인력·장비·재료 비용, 의료사고 위험도 등을 따져 각 행위에 점수를 매기고, 여기에 해마다 정하는 환산지수(점수당 금액)를 곱해 실제 수가를 계산합니다. 점수 체계가 자원 투입을 얼마나 잘 반영하느냐가 진료과 간 수익 격차를 좌우합니다.

    왜 중요한가

    수가 구조가 곧 의료 공급의 방향을 결정하기 때문에, 상대가치의 불균형은 특정 진료과 기피나 특정 시술 편중 같은 공급 왜곡으로 이어집니다. 필수의료 분야 보상 강화 논의가 대부분 이 점수 조정을 통해 이뤄진다는 점에서 정책적 비중이 매우 큽니다. 상대가치 개편의 효과를 분석하는 연구는 보건경제학의 주요 주제입니다.

    논문에서는 이렇게 쓰입니다

    "상대가치 개편으로 수술 행위의 점수가 인상된 이후 해당 시술의 시행 건수 변화를 분석하였다."

    가격 신호가 공급자 행태를 바꾸는지 확인하는, 지불제도 연구의 전형적 설계입니다.

    "검체검사 영역과 처치·수술 영역 간 상대가치의 불균형이 지속되고 있음이 지적되었다."

    자원 투입 대비 보상의 불일치가 진료과 간 격차로 이어진다는 문제 제기입니다.

    조금 더 깊게 보면

    이 체계는 미국 메디케어에서 의사 업무량, 진료비용, 의료분쟁 위험도라는 세 요소로 점수를 구성한 방식에서 출발했으며, 우리나라 건강보험도 유사한 구조의 상대가치점수표를 운영합니다. 실제 수가는 점수에 환산지수를 곱해 결정되므로, 총지출 관리와 개별 행위 보상이 서로 다른 지렛대로 조정됩니다. 점수 산정에는 표본 조사와 전문가 패널 판단이 들어가기 때문에 이해관계 조정 과정이 결과에 영향을 미치며, 신기술 도입 시 점수 신설 절차가 별도로 필요합니다.

    주의할 점

    포괄수가제가 여러 행위를 묶어 하나의 값으로 지불하는 방식이라면, 상대가치점수는 행위별수가제 아래에서 각 행위의 값을 정하는 기준표입니다. 점수 자체는 금액이 아니며, 환산지수와 곱해야 비로소 수가가 됩니다.

    관련 용어

    행위별수가제 포괄수가제 건강보험제도 국민건강보험 공급자유인수요 의료서비스 접근성 보건의료인력계획(보건인력 기획) 일차보건의료 지역사회보건요원 프로그램 민관혼합 의료체계
