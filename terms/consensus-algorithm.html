    합의 알고리즘 (Consensus Algorithm)

    컴퓨터과학·AI
    한 줄 정의: 네트워크로 연결된 여러 대의 컴퓨터가 일부 고장이나 통신 지연이 있어도 하나의 값이나 순서에 대해 서로 같은 결론에 도달하도록 만드는 절차입니다.

    쉽게 풀면

    여러 지점에 흩어진 회의 참석자들이 전화로만 연결된 채 다수결로 안건을 결정해야 하는 상황을 떠올려 보세요. 일부는 전화가 끊기고, 일부는 말이 늦게 전달되고, 심지어 누군가는 거짓 정보를 흘릴 수도 있습니다. 이런 열악한 상황에서도 "결국 모두가 같은 결정을 인정하게 만드는 규칙"이 필요합니다. 분산 컴퓨터 시스템도 마찬가지입니다. 은행 서버 여러 대가 동시에 운영되는데, 그중 한 대가 갑자기 멈추거나 네트워크가 끊겨도 "누구의 계좌에서 얼마가 빠져나갔는지"에 대해 모든 서버가 결국 같은 답을 갖고 있어야 합니다. 합의 알고리즘은 이렇게 여러 컴퓨터(노드)가 장애나 지연 속에서도 하나의 값·순서·상태에 대해 의견 일치를 이루도록 설계된 규칙과 절차를 말하며, 대표적으로 Paxos나 Raft 같은 알고리즘이 있습니다.

    논문에서는 이렇게 쓰입니다

    "제안하는 분산 시스템은 Raft 합의 알고리즘을 기반으로 노드 장애 상황에서도 데이터 일관성을 보장하도록 설계되었다."

    여러 서버 중 일부가 멈추더라도, 남은 서버들끼리 합의 알고리즘을 통해 데이터가 서로 어긋나지 않도록 유지했다는 뜻입니다.

    주의할 점

    합의 알고리즘은 단순히 여러 서버에 같은 데이터를 복사해 두는 것과는 다릅니다. 네트워크 단절이나 노드 고장처럼 예측 불가능한 상황에서도 다수의 노드가 동일한 결론에 도달하도록 보장하는 것이 핵심이며, 이 과정에서 CAP 정리가 설명하듯 일관성과 가용성 사이의 절충이 불가피하게 발생합니다.
