    기록물기술부호화표준 (Encoded Archival Description)

    문헌정보학
    한 줄 정의: 기록관리학에서 기록물군의 계층적 구조와 맥락 정보를 기술하기 위해 개발된 XML 기반 표준으로, 개별 항목이 아닌 컬렉션 단위의 계층적 기술을 지원한다는 점에서 서지목록과 차별화된다.

    쉽게 풀면

    기록물 묶음의 구조와 배경 정보를 계층적으로 표현하기 위해 만든 XML 표준이다.

    논문에서는 이렇게 쓰입니다

    본고는 기록물기술부호화표준이 아카이브 자료의 계층 구조를 온라인 검색도구에 반영하는 데 핵심적인 역할을 한다고 설명하였다.

    이 표준이 아카이브 자료의 계층 구조를 온라인에서 보여주는 데 중요한 역할을 한다는 점을 설명한 문장이다.

    주의할 점

    기록물기술부호화표준은 개별 도서 자료의 서지기술보다는 기록물군 전체의 맥락과 출처를 기술하는 데 특화되어 있어, 일반 도서 목록과 적용 목적이 다르다는 점에 유의해야 한다.
