    페이지네이션 (Pagination)

    디자인학
    한 줄 정의: 많은 양의 콘텐츠를 여러 페이지로 나누어 번호를 매겨 사용자가 원하는 페이지로 이동할 수 있게 하는 UI 패턴이다.

    쉽게 풀면

    내용이 많을 때 1, 2, 3페이지처럼 나눠서 원하는 페이지로 바로 갈 수 있게 하는 방식이다.

    왜 중요한가

    페이지네이션은 대량의 콘텐츠를 번호가 매겨진 페이지 단위로 분할해 사용자가 정보를 단계적으로 탐색하도록 돕는 UI 패턴으로, 검색 결과나 게시판형 서비스에서 흔히 쓰인다. 무한스크롤과 달리 사용자가 특정 위치로 돌아오거나 진행 상황을 인지하기 쉽다는 장점이 있다.

    논문에서는 이렇게 쓰입니다

    본 연구는 무한스크롤과 페이지네이션 방식이 사용자의 정보 검색 완료 시간에 미치는 차이를 비교하였다.

    두 가지 콘텐츠 탐색 방식의 효율성을 비교한 사용성 실험이다.

    조금 더 깊게 보면

    페이지 수가 많은 경우 페이지 번호 목록 자체가 복잡해져 별도의 축약 표시 규칙이 필요하며, 최근에는 콘텐츠 소비 패턴에 따라 무한스크롤과 혼용하는 하이브리드 방식도 늘고 있다. 무한스크롤이 연속적 탐색에 적합하다면 페이지네이션은 명확한 종료 지점과 위치 인지가 중요한 경우에 더 적합하다.

    주의할 점

    페이지네이션은 특정 정보를 다시 찾기 쉽지만 콘텐츠 소비의 몰입감은 무한스크롤보다 낮을 수 있다.

    관련 용어
