    사건수분석 (Disaster Event Tree Analysis)

    재난안전관리학
    한 줄 정의: 초기 사건이 발생한 이후 안전장치나 대응 조치의 성공·실패 여부에 따라 전개될 수 있는 다양한 결과 경로를 나뭇가지 형태로 분석하는 기법입니다.

    쉽게 풀면

    화재경보가 울렸다고 가정해 봅시다. 스프링클러가 작동하면 불이 빨리 꺼지고, 작동하지 않으면 불이 번질 수 있습니다. 대피 안내방송이 제때 나오면 인명피해가 줄고, 그렇지 않으면 늘어날 수 있습니다. 사건수분석은 이렇게 하나의 시작 사건 이후 여러 단계의 성공·실패에 따라 어떤 결과로 이어지는지 가지치기 형태로 정리하는 방법입니다.

    왜 중요한가

    사건수분석은 사고 발생 이후의 전개 과정과 각 단계별 대응책의 효과를 평가할 수 있게 해주므로, 재난 대응 체계의 취약점을 찾고 개선하는 데 중요한 도구로 사용됩니다. 결함수분석이 원인을 다룬다면 사건수분석은 결과를 다룬다는 점에서 상호 보완적입니다.

    논문에서는 이렇게 쓰입니다

    "지진 발생 이후 건물 붕괴로 이어지는 경로를 사건수분석을 통해 도식화하였다."

    지진이라는 초기 사건 이후 여러 대응 단계를 거쳐 붕괴에 이르는 과정을 나뭇가지 구조로 표현했다는 의미입니다.

    "각 대응 단계의 성공 확률을 반영하여 사건수분석 결과 최종 피해 시나리오별 발생 확률을 산출하였다."

    각 단계의 성공·실패 확률을 곱해 최종적으로 어떤 결과가 나올 확률을 계산했다는 뜻입니다.

    조금 더 깊게 보면

    사건수분석은 초기 사건에서 출발해 각 안전장치나 대응 조치의 성공/실패를 이분지 형태로 나누어가며 최종 결과 시나리오를 도출합니다. 각 경로의 확률은 단계별 성공·실패 확률의 곱으로 계산되며, 결함수분석과 결합해 전체 사고 시나리오를 정량적으로 평가하는 데 활용되기도 합니다.

    주의할 점

    사건수분석 역시 분석자가 설정한 단계와 순서에 의존하므로, 실제 현장에서 예상치 못한 순서로 사건이 전개될 가능성은 반영되기 어렵습니다.

    관련 용어

    결함수분석 보우타이 분석 시나리오기반 위험분석 최악의 시나리오 계획
