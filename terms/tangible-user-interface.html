    탠저블 사용자 인터페이스 (tangible user interface)

    디자인학
    한 줄 정의: 만질 수 있는 물리적 사물을 조작해 디지털 정보를 입력하고 표현하는 인터페이스입니다.

    쉽게 풀면

    탠저블 사용자 인터페이스는 화면 속 아이콘 대신 손에 잡히는 블록이나 물건으로 컴퓨터를 다루게 합니다. 예를 들어 탁자 위의 블록을 옮기면 화면 속 도시 모형의 건물 배치가 바뀌는 식입니다. 디지털 정보에 물리적인 형태를 입힌다는 것이 핵심 생각입니다.

    왜 중요한가

    사람이 손과 몸으로 익힌 조작 능력을 그대로 활용할 수 있어, 교육·협업·어린이용 기기 연구에서 그래픽 사용자 인터페이스의 대안으로 활발히 연구됩니다.

    논문에서는 이렇게 쓰입니다

    "탠저블 사용자 인터페이스 조건의 아동은 그래픽 인터페이스 조건보다 협동적 탐색 행동을 더 자주 보였다."

    물리적 조작 도구가 여러 아이가 함께 참여하는 행동을 더 끌어냈다는 뜻입니다.

    조금 더 깊게 보면

    MIT 미디어랩의 이시이 히로시(Hiroshi Ishii)와 울머(Ullmer)가 1997년 'Tangible Bits' 논문에서 개념을 정리했습니다. 이후 물리적 표상과 디지털 표상을 결합하는 방식, 공간적 배치 등을 분류하는 틀이 제안되었고, 모양이 스스로 바뀌는 형태 변환 인터페이스로도 연구가 확장되었습니다.

    주의할 점

    그래픽 사용자 인터페이스가 화면 속 시각 요소를 간접적으로 조작한다면, 탠저블 인터페이스는 물리적 사물 자체가 입력이자 표현이 된다는 점이 다릅니다. 단순히 물리 버튼이나 터치스크린을 쓴다고 탠저블 인터페이스가 되는 것은 아닙니다.
