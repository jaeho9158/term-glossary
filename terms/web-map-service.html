    웹지도서비스(WMS) (Web Map Service)

    지도학
    한 줄 정의: 사용자가 요청한 지리적 범위, 좌표계, 해상도에 맞춰 서버가 지도 이미지를 실시간으로 생성해 전송하는 표준화된 웹 지도 프로토콜입니다.

    쉽게 풀면

    웹지도서비스(WMS)는 사용자가 "이 위도·경도 범위를, 이 좌표계로, 이 크기로 그려주세요"라고 요청하면 서버가 그 자리에서 지도를 그려서 이미지로 돌려주는 방식입니다. 이미 잘라둔 조각을 갖다 쓰는 타일 방식과 달리, 매번 요청 조건에 맞춰 새로 그려주는 주문 제작 방식에 가깝습니다. 그래서 원하는 범위와 해상도를 자유롭게 지정할 수 있지만, 매번 서버가 실시간으로 그림을 그려야 하므로 처리 부담이 더 클 수 있습니다.

    왜 중요한가

    WMS는 국제 표준 기구가 정의한 개방형 표준 프로토콜로, 서로 다른 기관의 지도 서버와 클라이언트가 호환되어 작동할 수 있게 해줍니다. 공공 지리정보 공유, 다기관 협업 지도 시스템 구축에서 상호운용성을 확보하는 핵심 기술로 논문에서 다뤄집니다.

    논문에서는 이렇게 쓰입니다

    "본 시스템은 웹지도서비스(WMS) 표준을 준수하여 여러 기관의 지리정보 서버로부터 실시간으로 지도 레이어를 결합하였다."

    여러 기관 데이터를 하나의 지도로 통합할 때 WMS 표준을 활용했다는 설명입니다.

    "제안 방법은 WMS GetMap 요청 처리 시간을 기존 서버 구조 대비 단축하는 것을 목표로 한다."

    WMS의 대표적 요청 방식인 GetMap의 처리 성능을 개선하려는 연구를 소개합니다.

    조금 더 깊게 보면

    WMS는 대체로 지도 이미지를 요청하는 GetMap, 서비스 제공 능력을 조회하는 GetCapabilities, 특정 지물 정보를 조회하는 GetFeatureInfo 등 표준화된 요청 방식을 정의합니다. 이는 벡터·속성 데이터를 그대로 전달하는 웹 피처 서비스(WFS)와는 달리 완성된 지도 이미지를 결과로 반환한다는 점에서 구분됩니다.

    주의할 점

    WMS는 요청마다 서버가 이미지를 새로 생성하므로, 사전에 캐싱된 타일지도 서비스에 비해 동일 지역을 반복 조회할 때 응답 속도와 서버 부하 면에서 불리할 수 있습니다.
