    발생집단분석 (Outbreak Cluster Analysis)

    수의학
    한 줄 정의: 질병 발생 사례가 시간적·공간적으로 무작위 분포보다 밀집되어 나타나는지를 통계적으로 검정하는 역학 분석 방법이다.

    쉽게 풀면

    어떤 병이 여기저기 무작위로 흩어져 발생하는 것처럼 보이지만, 실제로는 특정 지역이나 특정 시기에 유독 몰려서 발생하고 있는 것은 아닌지를 통계적으로 확인하는 방법입니다. 예를 들어 한 마을에서 며칠 사이 감염 사례가 연달아 나온다면, 우연히 겹친 것인지 아니면 실제로 서로 연관된 확산인지를 숫자로 검증하는 것입니다. 이를 통해 방역 당국은 실제 전파가 일어나고 있는 곳에 자원을 집중할 수 있습니다.

    왜 중요한가

    발생집단분석은 역학조사 초기 단계에서 실제 유행이 시작된 것인지 우연한 산발적 발생인지를 조기에 판별하는 데 활용되며, 공간통계 기법을 통해 방역 자원을 집중 투입해야 할 고위험 지역을 식별하는 데 쓰인다. 식중독이나 인수공통감염병 발생 시 감염원 공통점을 찾아내는 역학조사에서도 핵심적인 분석 도구로 사용된다.

    논문에서는 이렇게 쓰입니다

    공간군집분석(SaTScan)을 이용해 럼피스킨병 발생의 시공간적 클러스터를 확인하였다.

    국지적 확산 패턴을 규명하여 방역 자원을 집중 배치하는 근거로 활용됨을 설명하는 문맥이다.

    "스캔통계량을 이용한 분석 결과 해당 시군구에서 통계적으로 유의한 시공간적 발생집단이 확인되었다."

    스캔통계량과 같은 공간통계 기법으로 발생집단의 통계적 유의성을 검증하는 전형적인 서술이다.

    조금 더 깊게 보면

    발생집단분석에는 공간적 밀집도를 검정하는 커널밀도추정이나 무어런지수(Moran's I) 같은 공간자기상관 통계, 시공간적 밀집을 동시에 검정하는 스캔통계량(scan statistic) 등이 활용된다. 분석 결과 통계적으로 유의한 집단이 확인되면, 해당 집단 내 공통 노출 요인을 찾는 후속 역학조사로 이어지는 것이 일반적이다. 분석 결과의 해석에는 사례 정의의 일관성과 자료 수집 범위가 큰 영향을 미칩니다.

    주의할 점

    통계적으로 유의한 집단이 확인되었다고 해서 반드시 하나의 감염원에서 비롯된 전파를 의미하는 것은 아니므로, 역학적 연관성에 대한 추가 조사 없이 인과관계를 단정해서는 안 된다.

    관련 용어

    역학조사 감시체계 기초감염재생산수 전파경로 요검사 전혈구검사 전신마취 핵심예방접종 살처분 항체가검사
