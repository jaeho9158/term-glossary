# 퀴즈 문제 검수 (작업지시서 C - 5번)

`quiz.html`/`assets/quiz.js`를 5개 카테고리(통계, 심리학, 컴퓨터과학·AI, 윤리·출판, 공학)에서
각 4문제씩 총 20문제를 직접 풀어보며 오답 선택지 품질을 검수했습니다.

## 결론: 오답이 전반적으로 너무 쉽게 걸러짐

`assets/quiz.js`의 오답 생성 로직(`nextQuestion` 내부)은 `allTerms`(869개 전체 용어) 중에서
완전히 무작위로 3개를 골라 오답으로 씁니다. 카테고리를 전혀 고려하지 않기 때문에, 예를 들어
통계 문제에 "무게중심"(수학), "이차방정식"(수학) 같은 완전히 다른 분야 용어가 오답으로 섞여
나옵니다. 20문제 중 19문제에서 4개 선택지 중 진짜 정답과 관련 있어 보이는 것이 1개뿐이라
찍기만 해도 정답을 맞히기 쉬운 상태였습니다.

### 실제로 뽑힌 예시

**통계 — "표준편차" 용어 맞히기**
- 정답: 분산에 제곱근을 씌워 원래 단위로 되돌린 산포도 지표.
- 오답: 제품 환경영향평가(LCA), 사회계약론, 아이트래킹 장비 설명
- → 통계 지식 없이도 "이건 통계 얘기가 아니네" 하고 소거법으로 정답 도달 가능.

**윤리·출판 — "선행과 무해성 원칙" 정의 맞히기**
- 오답: 양자화(물리), 통제집단(방법론 — 그나마 근접), 미토콘드리아(생물)
- → 3개 중 2개가 완전히 무관한 분야라 변별력이 거의 없음.

**공학 — "고유진동수" 정의 맞히기**
- 오답: 사회연결망분석, 세포주기의 조절, 로지스틱 회귀
- → 마찬가지로 전부 다른 분야, 소거법으로 즉시 정답 판별 가능.

**예외 — 통계 "2종 오류" 정의 맞히기**
- 오답에 "유의수준"(같은 stat 카테고리)이 우연히 포함되어 그나마 헷갈릴 만했음.
- 이건 무작위 추출이 우연히 같은 카테고리를 뽑은 경우일 뿐, 의도된 설계가 아님.

## 원인

`quiz.js`가 오답 후보를 뽑을 때 카테고리 필터를 걸지 않고 `allTerms`(현재 선택한 카테고리가
아니라 전체 869개 용어) 배열에서 뽑기 때문입니다. 카테고리 하나를 골라 퀴즈를 풀어도 오답은
다른 카테고리에서 튀어나올 수 있습니다.

## 제안

1. **최소 조치 (권장, 개발자 B 확인 필요)**: 오답 후보 풀을 `allTerms` 전체가 아니라
   `currentTerms`(현재 선택된 카테고리) 또는 최소한 정답 용어와 `categories`가 겹치는 용어들로
   좁힌다. 카테고리 내 용어가 4개 미만일 때만 전체 풀로 fallback.
2. **여유가 있으면**: terms.json에 `quiz_distractors: string[]`(slug 배열, 사람이 고른
   헷갈리는 오답 후보) 필드를 선택적으로 추가하고, 있으면 우선 사용 → 없으면 위 1번 로직으로
   fallback. 전체 869개 용어에 전부 채우는 건 범위가 크므로, 우선 자주 틀리기 쉬운 핵심 용어
   (예: 유의확률/유의수준/신뢰수준처럼 헷갈리는 묶음)부터 채우는 걸 추천.

## 검수 범위 관련 참고

이번 검수 시점에 `quiz.js`는 Supabase 연동(정답률/진행 기록 저장, `tg_quiz_results` 등)이
아직 없는 상태였습니다(개발자 B 작업지시서 6번 완료 기준 미충족). 로그인 후 과거 점수
확인 플로우는 그 작업이 끝난 뒤 별도로 재검수가 필요합니다.
