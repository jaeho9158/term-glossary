    병합 정렬 (merge sort algorithm)

    컴퓨터과학·AI
    한 줄 정의: 배열을 절반으로 계속 나누어 더 이상 나눌 수 없을 때까지 재귀적으로 분할한 뒤, 정렬된 작은 배열들을 순서대로 다시 합쳐 나가는 분할 정복 기반의 정렬 알고리즘.

    쉽게 풀면

    병합 정렬은 정렬되지 않은 배열을 절반으로 계속 쪼개서 원소가 하나씩만 남을 때까지 나눈 뒤(이 상태는 자동으로 정렬된 것과 같다), 두 개의 이미 정렬된 배열을 하나의 정렬된 배열로 합치는 과정을 반복해 전체를 정렬한다. 두 정렬된 리스트를 하나로 합치는 것은 각 리스트의 맨 앞 원소끼리 비교해가며 더 작은 것을 차례로 꺼내면 되므로 매우 효율적이다. 항상 O(n log n) 시간에 동작한다는 것이 보장되어 최악의 경우에도 성능이 안정적이며, 같은 값을 가진 원소들의 상대적 순서를 유지하는 안정 정렬이라는 특징도 가진다.

    왜 중요한가

    병합 정렬은 항상 O(n log n) 시간복잡도를 보장하는 안정성과, 데이터를 순차적으로 접근해도 처리할 수 있다는 특성 덕분에 대용량 데이터 처리와 병렬·분산 시스템 설계 연구에서 기본 정렬 방식으로 자주 채택됩니다. 또한 분할정복 패러다임을 대표하는 알고리즘으로서 알고리즘 교육과 복잡도 분석 이론을 설명하는 데에도 표준 예시로 폭넓게 인용됩니다.

    논문에서는 이렇게 쓰입니다

    "본 외부 정렬 시스템은 메모리에 다 담을 수 없는 대용량 데이터를 처리하기 위해 병합 정렬의 다단계 병합 방식을 채택하였다."

    최악의 경우에도 안정적인 성능이 보장되어야 하거나 대용량 데이터를 디스크 기반으로 정렬해야 하는 상황에서의 알고리즘 선택으로 설명된다.

    "제안된 병렬 병합 정렬 구현은 다중 코어 환경에서 데이터를 여러 조각으로 나누어 동시에 정렬한 뒤 병합함으로써 순차 처리 대비 처리 시간을 크게 단축하였다."

    병렬 컴퓨팅 연구에서, 분할정복 구조 덕분에 병합 정렬이 여러 프로세서에 작업을 나누어 동시에 수행하기에 적합하다는 특성을 활용한 사례를 설명합니다.

    "분산 정렬 프레임워크는 각 노드에서 지역적으로 병합 정렬을 수행한 뒤, 정렬된 부분 결과를 중앙에서 다시 병합하는 방식으로 전체 데이터셋을 정렬하였다."

    분산 시스템 연구에서, 여러 서버에 나뉘어 저장된 대용량 데이터를 각각 정렬한 뒤 하나로 합치는 데 병합 정렬의 병합 단계 원리를 응용한 사례를 설명합니다.

    조금 더 깊게 보면

    병합 정렬은 데이터를 임의 접근할 필요 없이 순서대로 읽으면서 처리할 수 있어, 하드디스크나 여러 서버에 나뉘어 저장된 대용량 데이터를 정렬하는 외부 정렬(external sorting)이나 분산 정렬 시스템에서 특히 유용하게 쓰입니다. 또한 재귀 호출 없이 작은 블록부터 점차 크게 병합해 나가는 상향식(bottom-up) 구현 방식도 자주 논의되며, 이는 재귀에 따른 함수 호출 오버헤드를 줄이는 실용적 최적화로 소개되곤 합니다.

    주의할 점

    병합 정렬은 시간 복잡도가 항상 안정적인 O(n log n)이라는 장점이 있지만, 정렬 과정에서 원본 배열과 별도로 추가 메모리 공간이 필요하다는 점에서 제자리 정렬(in-place)인 퀵정렬과 차이가 있다.
