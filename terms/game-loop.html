    게임 루프 설계 (Game Loop Design)

    문화콘텐츠학·게임학
    한 줄 정의: 게임 실행 중 입력 처리, 상태 갱신, 렌더링을 일정 주기로 반복하는 프로그램 구조를 설계하는 것을 말한다. 기술적 게임 루프와 별개로 플레이어 행동의 반복 주기를 뜻하는 코어 루프 개념과도 연결된다.

    쉽게 풀면

    게임이 계속 돌아가도록 '입력받기 → 계산하기 → 화면 그리기'를 반복하는 프로그램 구조다.

    논문에서는 이렇게 쓰입니다

    Gregory, J. (2009). Game Engine Architecture.

    이 책은 게임 루프를 게임 엔진의 핵심 아키텍처 요소로 다루며 프레임 갱신, 시간 관리, 입력 처리의 표준적 구조를 정립했다.

    주의할 점

    기술적 게임 루프(프로그램 실행 주기)와 디자인상의 코어 루프(플레이어 행동 주기)는 유사한 이름이지만 다른 개념이므로 구분해야 한다.
