    심프슨의 법칙 (Simpson's Rule)

    수치적분›심프슨의 법칙
    수학
    한 줄 정의: 곡선으로 둘러싸인 넓이(적분값)를 직접 계산하기 어려울 때, 구간을 나눠 포물선으로 근사해서 컴퓨터로 빠르게 계산하는 수치적분 방법이다.

    쉽게 풀면

    불규칙하게 굽이치는 강의 단면적을 재야 한다고 해보자. 자로 정확히 재기는 어렵지만, 몇 군데 지점의 깊이를 측정한 뒤 그 사이를 매끄러운 곡선(포물선)으로 이어 붙이면 실제 넓이에 아주 가까운 값을 얻을 수 있다. 심프슨의 법칙은 바로 이 아이디어를 수학적으로 정리한 것으로, 적분 구간을 여러 개의 작은 구간으로 나눈 뒤 각 구간을 직선이 아니라 포물선으로 근사해서 넓이를 더하는 방법이다. 직선으로만 근사하는 방법(사다리꼴 공식)보다 훨씬 정확도가 높아서, 함수의 식을 정확히 적분하기 어려울 때 컴퓨터 시뮬레이션이나 수치 계산에서 널리 쓰인다.

    왜 중요한가

    실제 연구에서 다루는 함수는 명확한 해석적 형태로 적분되지 않는 경우가 많기 때문에, 심프슨의 법칙과 같은 수치적분 방법은 시뮬레이션이나 모델 검증 과정에서 필수적으로 쓰인다. 실험으로 얻은 이산적인 측정값이나 복잡한 미분방정식의 해를 적분해야 하는 공학·물리학·생명과학 연구에서, 정확도와 계산 비용의 균형을 맞춘 근사 적분 기법으로 널리 채택된다.

    어떤 절차인가

    • 구간 [a, b]를 같은 폭 h = (b − a)/n의 n개 소구간으로 나누고, 두 소구간마다 포물선으로 근사해 넓이를 더한다. 합성 심프슨 공식은 (h/3)[f(x0) + 4f(x1) + 2f(x2) + … + 4f(xn−1) + f(xn)]이다.
    • 양 끝점의 가중치는 1, 홀수 번째 내부점은 4, 짝수 번째 내부점은 2이다.
    • 소구간의 수 n은 짝수여야 한다.

    언제 쓰고 무엇을 얻나

    • 3차 이하의 다항식은 정확히 적분한다. 오차가 4계 도함수에 의존하기 때문이다. 합성 규칙의 오차는 약 −(1/180)·h4(b − a)·f(4)(ξ)이므로 h4에 비례해 줄어든다.
    • 같은 정밀도에 필요한 구간 수가 훨씬 적다. 위키백과의 예(∫0π sin x dx, 오차 0.00001 미만)에서 심프슨은 n = 22, 합성 사다리꼴은 n = 509가 필요하다.
    • 이름은 토머스 심프슨(1710–1761)에서 왔다. 독일어권 등에서는 케플러가 1615년 포도주 통을 보다 유도했다고 해서 '케플러의 통 규칙'이라 한다.

    논문에는 이렇게 적는다

    • 논문에는 구간 수 n, 간격 h, 사용한 공식(1/3 규칙인지), 오차 추정이나 n을 늘렸을 때의 수렴 결과를 적는다.
    • n이 홀수이면 쓸 수 없다. 이때는 마지막 구간에 다른 방법을 쓰는 등의 처리가 필요하다.
    • 뾰족한 봉우리 모양처럼 좁은 부분에서 급변하는 함수에서는 심프슨 규칙이 사다리꼴 규칙보다 비효율적일 수 있다고 위키백과는 설명한다. 함수가 매끄러운지 먼저 확인한다.

    논문에서는 이렇게 쓰입니다

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "해석적으로 적분식을 풀기 어려운 비선형 모델의 누적값을 심프슨의 법칙(Simpson's rule)을 이용한 수치적분으로 계산하였다."

    이 문장은 함수 형태가 복잡해서 손으로 적분 공식을 유도하기 힘든 경우, 컴퓨터로 구간을 잘게 나눠 포물선 근사를 반복 적용함으로써 정적분 값을 근사적으로 구했다는 뜻이다. 공학, 물리학, 계량경제학 등 수치 시뮬레이션이 필요한 논문에서 자주 등장한다.

    "약물의 혈중 농도-시간 곡선 아래 면적(AUC)을 심프슨의 법칙으로 계산하여 약물 노출량을 추정하였다."

    일정 간격으로 측정한 혈중 농도 데이터를 이용해 곡선 아래 면적을 근사적으로 구함으로써, 몸속에 흡수된 약물의 총량을 추정했다는 뜻이다.

    "불규칙한 하천 단면 측량 자료에 심프슨의 법칙을 적용하여 유량 산정에 필요한 단면적을 계산하였다."

    몇 지점에서 측정한 하천 깊이 자료를 이용해 전체 단면적을 근사적으로 계산했다는 의미로, 토목·수문 공학 연구에서 흔히 쓰이는 방식이다.

    조금 더 깊게 보면

    심프슨의 법칙은 구간을 짝수 개로 나누고 인접한 세 점을 지나는 포물선으로 각 구간을 근사한 뒤 이를 모두 더하는 방식으로 작동하며, 사다리꼴 공식보다 오차가 훨씬 빠르게 줄어드는 것이 특징이다. 함수가 매끄러울수록 근사 오차가 작아지고, 함수가 급격히 변하거나 불연속인 구간에서는 오차가 커질 수 있어 이런 경우 구간을 더 잘게 나누거나 적응형(adaptive) 수치적분 기법을 함께 사용하기도 한다. 데이터가 등간격으로 주어지지 않은 경우에는 이를 보완한 변형된 형태의 공식이 쓰이기도 한다.

    주의할 점

    심프슨의 법칙(Simpson's rule)은 이름이 비슷한 심슨의 역설과 전혀 관련이 없는 별개의 개념이다. 심프슨의 법칙은 곡선 아래 넓이를 근사하는 수치적분 기법이고, 심슨의 역설은 하위 집단으로 나누면 통계적 경향이 뒤집히는 현상을 가리킨다. 두 용어 모두 "Simpson"이라는 이름을 공유할 뿐, 수학적 배경도 쓰이는 분야도 완전히 다르다.

    용어내용
    적분넓이를 구하는 수학적 개념. 심프슨은 이를 수치로 근사한다
