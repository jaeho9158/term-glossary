    공정모사 (Process Simulation)

    화학공학
    한 줄 정의: 컴퓨터 소프트웨어를 이용하여 물질·에너지수지, 열역학 모델, 장비 모델을 결합해 공정의 거동을 수치적으로 예측하는 작업이다.

    쉽게 풀면

    실제 공장을 짓기 전에 컴퓨터 안에 가상의 공장을 만들어 돌려보는 것이라고 생각하면 된다. 원료 조성과 유량, 장비 사양을 입력하면, 소프트웨어가 물질수지와 에너지수지, 열역학 모델을 이용해 각 지점에서의 온도, 압력, 조성을 계산해 준다. 실제로 실험을 하지 않고도 다양한 조건을 빠르게 시험해 볼 수 있어 설계 시간과 비용을 크게 줄여준다.

    왜 중요한가

    새로운 공정을 설계하거나 기존 공정을 개선할 때, 실험만으로 모든 조건을 검토하는 것은 비용과 시간이 많이 들기 때문에 공정모사를 통해 사전에 최적 조건을 탐색하는 것이 화학공학 산업과 연구 전반에서 표준적인 절차로 자리잡고 있다. 활동도계수 모델, 반응속도식 등 다양한 이론적 배경이 공정모사의 정확도를 좌우한다.

    어떤 절차인가

    • 공정 모사는 화학 공장, 화학 공정, 환경 시스템, 발전소, 복잡한 제조 공정, 생물 공정 같은 기술 공정의 설계, 개발, 분석, 최적화에 쓴다.
    • 화학, 물리, 생물 등의 공정과 단위 조작을 소프트웨어 안에서 모델로 나타낸 것이다. 모델의 기본 전제는 순수 성분과 혼합물의 화학적·물리적 성질, 반응, 그리고 이를 결합해 공정 성질을 계산하게 해 주는 수학 모델이다.
    • 소프트웨어는 단위 조작을 배치하고 흐름으로 연결한 공정 흐름도로 공정을 기술한다. 지정한 변수에서 물질수지와 에너지수지를 풀어 안정된 운전점을 찾는다.

    언제 쓰고 무엇을 얻나

    • 목표는 공정의 최적 조건을 찾는 것이다. 이는 반복 계산으로 푸는 최적화 문제이다.
    • 증류탑 예에서 사용자는 공급 흐름의 조성, 전체 질량 유량, 압력, 온도를 정하고(탄화수소 계에서는 기액 평형비(K값)나 이를 정하는 모델도 지정), 탑의 입구 압력과 이론단 수를 정한다. 재비기와 환류 응축기의 열량은 모델이 지정한 조성 등을 얻도록 계산한다.
    • 모델은 근사와 가정을 도입하지만, 실제 자료가 없는 넓은 온도·압력 범위에서도 성질을 기술할 수 있다. 일정한 한계 안에서 내삽과 외삽도 가능하다.
    • 모델은 두 종류이다. 하나는 실험 자료에 매개변수를 맞춘 단순한 식과 상관식이고, 다른 하나는 성질을 추정하는 예측 방법이다. 상관식이 성질을 (거의) 정확히 기술하므로 대개 선호된다.
    • 정상상태 모사는 시간에 무관한 평형 상태의 물질·에너지 수지를 계산한다. 동적 모사는 물질과 에너지의 축적 같은 미분항으로 시간 의존성을 넣은 확장이다. 공장 시동·정지, 반응 중 조건 변화 등을 다룰 수 있다. 계산 시간이 늘고 수학적으로 더 복잡하다. 동적 모사는 모델 예측 제어(온라인), 설계·문제 해결·최적화·사례 연구(오프라인), 운전원 훈련에 쓰인다.

    논문에는 이렇게 적는다

    • 예측 방법은 오차가 상관식보다 커서 보통 공정 개발 초기에 대략의 해를 찾거나 틀린 경로를 제외하는 데에만 쓴다. 실험이나 자료은행의 자료를 쓰는 것보다 비용은 적게 든다.
    • 모델은 근사와 가정을 포함한다. 논문에서는 사용한 소프트웨어, 물성 모델(상평형 식 등), 가정, 실험 또는 공장 자료와의 비교 여부를 밝힌다.
    • 공정 모사는 1970년대에 FORTRAN과 C 같은 언어와 적합한 하드웨어가 등장하면서 도입되었다고 위키백과는 쓴다. 물성 모형 중 입방 상태방정식과 앙투안 식은 19세기에 나왔다.

    조금 더 깊게 보면

    공정모사는 정상상태 모사와 동적(dynamic) 모사로 나뉘며, 정상상태 모사는 설계 단계에서, 동적 모사는 제어 시스템 설계나 이상 상황 대응 연구에 주로 활용된다. 시뮬레이션의 정확도는 사용하는 열역학 물성 모델(NRTL, UNIFAC 등)의 적합성에 크게 좌우되므로, 대상 혼합물의 특성에 맞는 모델 선택이 중요한 과제로 다뤄진다. 공정모사 소프트웨어는 물성 데이터베이스와 열역학 모델(상태방정식, 활동도계수 모델 등), 장치 단위조작 모델을 결합해 정상상태 또는 동적 상태의 공정 거동을 계산하며, 대표적으로 Aspen Plus, HYSYS, gPROMS 등이 있다. 재순환 흐름이 있는 복잡한 공정은 반복계산기(순차모듈방식) 또는 연립방정식방식(equation-oriented)으로 수렴시켜 해를 구한다.

    주의할 점

    공정모사 결과는 입력한 모델과 가정에 의존하는 예측값이므로, 실제 공정과의 차이를 줄이기 위해서는 실험 데이터를 통한 검증과 보정이 필요하다.

    선택한 열역학 모델이 실제 시스템의 비이상성을 제대로 반영하지 못하면 시뮬레이션 결과가 그럴듯해 보여도 실제와 크게 어긋날 수 있어, 모델 선정 근거를 검증하는 것이 결과 신뢰도의 핵심이다.
