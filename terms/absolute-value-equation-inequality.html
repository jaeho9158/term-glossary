    절댓값을 포함한 방정식과 부등식 (Absolute Value Equation and Inequality)

    절댓값›절댓값을 포함한 방정식과 부등식
    수학
    한 줄 정의: 절댓값 기호 안의 식이 양수인지 음수인지에 따라 경우를 나누어 절댓값 기호를 없앤 뒤 푸는 방정식과 부등식이다.

    쉽게 풀면

    절댓값 |x|는 "원점에서부터의 거리"를 뜻한다. 예를 들어 |x-3|=5라는 방정식은 "수직선 위에서 3으로부터 거리가 5인 점을 모두 찾아라"라는 뜻이므로, 3보다 5만큼 큰 8과 3보다 5만큼 작은 -2, 두 개의 해를 갖는다. 이렇게 절댓값이 포함된 식을 풀 때는 절댓값 안의 식(여기서는 x-3)이 0 이상인 경우와 0 미만인 경우로 나누어, 0 이상이면 그대로 두고 0 미만이면 부호를 뒤집어서 절댓값 기호를 없앤 뒤 각각 계산한다. 부등식도 마찬가지로, |x-3|<5라면 "3으로부터 거리가 5보다 가까운 모든 점", 즉 -2

    왜 중요한가

    실험이나 관측에서 얻은 값은 항상 참값과 얼마간의 오차를 가지므로, "얼마나 벗어나도 되는지"를 하나의 부등식으로 못박아 두는 것이 여러 분야 논문에서 공통적으로 필요하다. 절댓값 방정식·부등식은 이런 오차 허용 범위, 안정성 조건, 수렴 판정 기준을 간결하게 표현하는 표준적인 도구이며, 최적화 문제의 제약조건이나 신호처리에서의 오차 한계를 정의할 때도 자주 등장한다. 결국 이 개념을 이해하고 있어야 논문에서 제시하는 오차범위나 임계조건이 실제로 무엇을 의미하는지 정확히 읽어낼 수 있다.

    어떤 절차인가

    • 실수 x의 절댓값은 x ≥ 0이면 |x| = x, x < 0이면 |x| = −x이다. |x| = √(x2)로도 쓴다.
    • 수직선에서 |x|는 0으로부터의 거리이고 |a − b|는 a와 b 사이의 거리이다.
    • 절댓값 기호 안의 식이 양수인지 음수인지에 따라 경우를 나눠 기호를 없애는 것이 기본 방법이다.

    언제 쓰고 무엇을 얻나

    • 방정식: a ≥ 0일 때 |x| = a의 해는 x = a, x = −a이다. a < 0이면 절댓값은 음수가 될 수 없으므로 해가 없다.
    • 부등식: |x| ≤ b는 −b ≤ x ≤ b와 같고, |x| ≥ b는 x ≤ −b 또는 x ≥ b와 같다. 예: |x − 3| ≤ 9이면 −6 ≤ x ≤ 12이다. 등호가 없는 형태도 같은 방식으로 푼다.
    • 식이 여러 개의 절댓값을 포함하면 기호 안이 0이 되는 값으로 구간을 나눠 구간별로 푼다.

    논문에는 이렇게 적는다

    • 구한 해가 경우를 나눈 구간 안에 있는지 반드시 확인한다. 구간 밖의 해는 버린다.
    • 성질: |ab| = |a||b|, |a + b| ≤ |a| + |b|(삼각부등식), |−a| = |a|, |a − b| ≥ ||a| − |b||.
    • 풀이를 쓸 때는 경우 나누기의 기준과 각 경우의 해, 최종 해(합집합)를 차례로 적는다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "측정값과 참값의 편차를 |x-μ|<ε 형태의 부등식으로 나타내고, 구간을 두 경우로 나누어 풀어 허용 오차 범위를 μ-ε

    이 문장은 "측정값이 참값에서 얼마나 벗어날 수 있는지를 절댓값 부등식으로 표현한 뒤, 절댓값을 풀어서 실제로 허용되는 구간의 상한과 하한을 명확한 숫자 범위로 제시했다"는 뜻이다.

    "제어 시스템의 안정성을 보장하기 위해 상태 오차가 |e(t)|<δ를 만족하는 구간에서만 제어기가 동작하도록 설계하였으며, 이 조건을 경우 분리를 통해 명시적인 시간 구간으로 변환하였다."

    이 문장은 "제어 대상의 실제 값과 목표 값 사이의 차이가 일정 범위 이내로 유지되는 동안에만 제어기가 작동하도록 설계했고, 그 조건을 절댓값을 풀어서 구체적인 시간 구간으로 바꾸어 제시했다"는 뜻이다.

    "두 알고리즘의 성능 차이가 통계적으로 유의미하지 않음을 보이기 위해 |Δp|<τ 형태의 부등식을 세우고, 이를 절댓값 기호를 분리하여 -τ<Δp<τ의 신뢰구간으로 변환한 뒤 검정하였다."

    이 문장은 "두 방법의 성능 차이가 무시할 만큼 작은지를 확인하기 위해 절댓값 부등식을 세우고, 이를 풀어서 실제 비교 가능한 구간으로 바꾼 뒤 통계적으로 검정했다"는 뜻이다.

    조금 더 깊게 보면

    절댓값 부등식은 삼각부등식(triangle inequality), 즉 |a+b|≤|a|+|b|와 밀접하게 연결되어 있으며, 오차 범위를 다룰 때 여러 항의 절댓값을 합쳐서 상한을 추정하는 데 이 성질이 자주 쓰인다. 또한 절댓값을 포함한 식을 부드럽게 다루기 위해 제곱근을 이용한 표현(√(x²)=|x|)이나, 미분이 불가능한 지점(꺾인 점)을 피하기 위한 완화된 근사식이 사용되기도 한다. 통계나 신호처리 논문에서는 절댓값 대신 절대오차(MAE), L1 노름처럼 절댓값의 합으로 정의되는 지표가 함께 등장하는 경우가 많으므로, 절댓값 부등식을 다루는 논리 자체가 이런 지표들의 성질을 이해하는 기초가 된다.

    주의할 점

    절댓값이 여러 번 겹쳐 있거나 절댓값 기호 안에 또 다른 절댓값이 있는 경우, 경우의 수를 빠짐없이 나누지 않으면 해를 놓치기 쉽다. 또한 절댓값 부등식을 풀 때 구한 구간이 애초에 절댓값 안의 식이 양수/음수라고 가정했던 범위와 일치하는지 반드시 확인해야 하며, 이는 이차부등식이나 부등식과 연립부등식을 풀 때 구간을 나누는 방식과 같은 원리이다.
