    파장분할다중 수동광가입자망 (Wavelength Division Multiplexing PON)

    파장분할다중화›파장분할다중 수동광가입자망
    전기전자공학
    한 줄 정의: 하나의 광섬유 회선을 여러 파장으로 나누어 각 가입자에게 독립된 파장 채널을 할당함으로써, 능동 중계 장비 없이도 각 가입자가 전용 대역을 갖는 것처럼 통신할 수 있게 하는 수동광가입자망 기술입니다.

    쉽게 풀면

    기존 수동광가입자망은 하나의 광선로를 여러 가입자가 시간을 나눠쓰듯 공유하는 방식이었습니다. 파장분할다중 수동광가입자망은 이를 확장해서, 여러 색깔(파장)의 빛을 각각 다른 가입자에게 나눠주는 방식입니다. 여러 개의 라디오 채널이 같은 공기를 통해 전파되지만 주파수가 다르면 서로 간섭하지 않는 것처럼, 각 가입자가 자신만의 파장을 갖고 통신하기 때문에 다른 가입자와 대역을 나눠쓸 필요가 없습니다.

    왜 중요한가

    가입자 수가 늘고 요구 대역폭이 커지면서, 기존 시분할 방식으로는 개별 가입자에게 충분한 속도를 보장하기 어려워졌습니다. 파장분할다중 방식은 가입자별로 독립된 파장 채널을 제공해 대역폭 경쟁 없이 고속 서비스를 제공할 수 있어, 차세대 광가입자망 기술로 다뤄집니다.

    핵심 정리

    • 수동광가입자망(PON)은 중앙 국사와 가입자를 잇는 광섬유 망에서 중간에 전원이 필요한 능동 장비 대신 분배기 같은 수동 소자만 쓰는 구조입니다.
    • 기존 TDM-PON(GPON, EPON 등)은 하나의 파장을 시분할로 여러 가입자가 나눠 씁니다. 반면 WDM-PON은 가입자마다 서로 다른 파장을 할당해, 가입자 하나가 파장 하나를 전용으로 갖는 점대점 같은 연결을 제공합니다.
    • 원격 노드에는 파장을 가려 나누어 주는 소자(대표적으로 배열 도파로 격자, AWG)를 두고, 중앙 국사에는 파장별 송수신기, 가입자 단말에는 자기 파장만 받는 송수신기를 둡니다.
    • 장점으로 거론되는 것: 가입자별 전용 대역과 낮은 지연, 가입자 사이 보안 분리, 프로토콜과 속도의 독립성. 단점: 파장별 광부품 비용, 파장 관리, 재고 부담.
    • 가입자 단말마다 다른 파장의 광원을 두는 비용을 줄이려는 무색(colorless) 단말 연구가 핵심 과제입니다. 대표 방식에는 외부 광을 주입해 파장을 고정하는 방식(주입 잠금 패브리-페로 레이저)과 반사형 반도체 광증폭기(RSOA)를 쓰는 방식이 있습니다.

    예시로 보기

    가상의 비교입니다. 가입자 32명이 있는 망에서,

    • TDM-PON: 하나의 하향 파장을 32명이 시간 칸으로 나눠 쓰고, 분배기가 광 신호를 32갈래로 나눕니다. 한 사람이 쓰는 대역이 다른 사람의 사용량에 영향을 받을 수 있습니다.
    • WDM-PON: 32개의 파장을 AWG가 가입자별로 나눠 줍니다. 한 사람이 쓰는 파장은 다른 사람과 겹치지 않아 대역 경쟁이 없습니다.

    두 방식을 섞은 구조(TWDM-PON, 여러 파장 위에 시분할을 얹음)는 ITU-T의 NG-PON2 표준에서 채택되어 실제 망 진화의 중간 단계로 논의됩니다.

    자주 하는 오해

    오해바로잡기
    WDM-PON은 광섬유를 가입자마다 따로 깐다.하나의 광섬유 선로를 공유하되 파장으로 가입자를 구분합니다.
    WDM-PON은 이미 TDM-PON을 대체했다.비용 때문에 상용망에서는 TDM-PON 계열이 널리 쓰이고, WDM-PON은 주로 연구·일부 도입 단계이며 하이브리드 구조도 검토됩니다.
    수동 망이니 전원이 전혀 필요 없다.중간 구간이 수동일 뿐이고, 중앙 국사와 단말에는 전원이 필요합니다.

    조금 더 깊게 보면

    파장분할다중 수동광가입자망은 중앙 국사에 파장을 분리·결합하는 광멀티플렉서를 두고, 가입자 단말에는 해당 파장에만 반응하는 광송수신기를 배치하는 구조가 일반적입니다. 가입자마다 서로 다른 파장의 레이저를 사용해야 하는 부담을 줄이기 위해, 어떤 파장이든 수신할 수 있는 무색 광송수신기를 개발하려는 연구가 이루어지고 있습니다. 시분할다중 방식과 결합한 하이브리드 구조도 실제 상용망에서 함께 검토됩니다.

    주의할 점

    파장별 전용 채널을 제공하는 만큼 시분할 방식보다 광부품 비용이 높아질 수 있어, 실제 배치 시 경제성과 성능 사이의 균형을 고려해야 합니다.
