    Core 1·Core 2 바이오마커 (Core 1 and Core 2 biomarkers)

    뇌과학·신경과학
    한 줄 정의: 2024년 알츠하이머협회 개정 기준에서 알츠하이머병 생체지표를 일찍 변하는 Core 1과 늦게 변하는 Core 2로 나눈 분류이다.

    쉽게 풀면

    병이 시작될 때 바뀌는 지표(Core 1)와 증상이 가까워질 때 바뀌는 지표(Core 2)로 나눈 것이다. Core 1은 진단에, Core 2는 진행 정도를 가늠하는 데 쓴다.

    왜 중요한가

    알츠하이머병을 증상이 아니라 생물학적 지표로 정의하는 최신 기준의 뼈대이다. 어떤 검사가 진단용이고 어떤 검사가 병기 판단용인지 구분해야 논문의 결론을 읽을 수 있다.

    핵심 정리

    • Core 1은 병의 초기에 이상이 나타나며 아밀로이드 판이나 인산화 타우를 PET이나 체액 검사로 직접 잰다. 이상이 하나만 있어도 진단에 충분하다(Alzheimer's Association, 2024).
    • Core 2는 더 늦게 변하며 응집된 타우 침착을 반영한다. 타우 PET과 체액 지표가 포함되고 보통 단독 진단 검사로 쓰지 않는다(Alzheimer's Association, 2024).
    • Core 1에는 A 지표와 인산화 중간부 타우(T1: p-tau217, p-tau181, p-tau231), 혼합 비율이 들어간다(Jack 등, 2024).

    예시로 보기

    구분예쓰임
    Core 1아밀로이드 PET, 뇌척수액 Aβ42/40, 정확한 혈장 p-tau217알츠하이머병 진단(Jack 등, 2024)
    Core 2타우 PET, MTBR-tau243, pT205Core 1과 함께 생물학적 중증도 병기 판단, 예후 정보(Jack 등, 2024)

    자주 하는 오해

    • Core 2 단독 이상은 알츠하이머병 진단이 아니다. A−T2+ 프로필은 알츠하이머병과 맞지 않으며 원발성 연령 관련 타우병증에 해당한다(Jack 등, 2024).
    • 혈장 검사는 아무 것이나 Core 1이 되지 않는다. 승인된 뇌척수액 검사와 동등한 성능이 필요하다(Jack 등, 2024).
    • 공존 병리가 흔하므로 임상 판단이 필요하다(Jack 등, 2024).

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "Core 1 바이오마커가 양성인 참여자를 알츠하이머병 생물학적 양성으로 분류하였다."

    Core 1 단독으로 진단 기준을 충족한다는 점을 반영한 서술이다.

    "Core 2 지표인 타우 PET을 이용해 생물학적 병기를 나누었다."

    Core 2를 병기 판단에 쓰는 형태이다.

    조금 더 깊게 보면

    Core 1에는 아밀로이드 PET, 뇌척수액 Aβ42/40, p-tau181/Aβ42, t-tau/Aβ42 같은 지표와 p-tau217 등 정확한 혈장 검사가 들어가며, 이상이 하나만 있어도 알츠하이머병 진단에 충분하다.

    혈장 검사는 승인된 뇌척수액 검사와 동등한 성능이어야 하며 중등도 이상 신경반을 찾는 정확도가 90% 이상이어야 한다. Core 2에는 타우 PET와 MTBR-tau243 등 T2 타우 지표가 들어가며 더 늦게 변한다. Core 1과 함께 쓰면 생물학적 중증도 병기, 증상과의 관련 가능성, 진행 위험을 가늠할 수 있다.

    관련 개념은 ATN 체계, 아밀로이드 PET, p-tau217에서 볼 수 있다.

    주의할 점

    Core 2 단독으로는 보통 진단 검사로 쓰지 않으며, Core 1이 정상인데 Core 2만 이상인 경우는 알츠하이머병으로 진단하지 않는다. 이 경우는 드물고 기준값 근처 값인 경우가 많으며 원발성 연령 관련 타우병증에 해당한다. 이 기준은 단계별 임상 진료 지침이 아니며 별도 지침이 예정되어 있다.

    참고 문헌

    1. Jack, C. R., Jr., Andrews, J. S., Beach, T. G., et al. (2024). Revised criteria for diagnosis and staging of Alzheimer's disease: Alzheimer's Association Workgroup. Alzheimer's & Dementia, 20, 5143-5169.
    2. Alzheimer's Association. (2024). Alzheimer's Association workgroup publishes biology-based criteria for diagnosis and staging of Alzheimer's disease.
