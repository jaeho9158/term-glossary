    측광필터계 (Photometric Filter System)

    천문학
    한 줄 정의: 특정 파장 대역을 표준화된 방식으로 통과시키는 여러 필터 조합(예: UBV계)을 이용해, 서로 다른 관측자·장비 간에도 비교 가능한 방식으로 천체의 밝기를 측정하는 체계.

    쉽게 풀면

    여러 파장대의 필터를 표준화해서, 어느 망원경으로 재도 서로 비교할 수 있도록 천체의 밝기를 재는 체계입니다.

    논문에서는 이렇게 쓰입니다

    UBV 측광필터계로 얻은 색지수는 항성의 표면온도와 스펙트럼형을 추정하는 데 널리 활용된다.

    서로 다른 필터로 측정한 밝기 차이(색지수)를 비교하면, 별을 직접 분광 관측하지 않고도 대략적인 표면 온도를 추정할 수 있다는 설명이다.

    주의할 점

    측광필터계는 표준화된 체계이므로, 관측 결과를 다른 연구와 비교하려면 반드시 동일하거나 호환되는 필터계를 사용했는지 확인해야 한다.
