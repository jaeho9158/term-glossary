    열교환기 유효도-NTU법 (Heat Exchanger Effectiveness-NTU Method)

    기계공학
    한 줄 정의: 열교환기 출구 온도를 모르는 상태에서도 유효도(effectiveness)와 전열단위수(NTU)라는 무차원 변수를 이용해 열교환기의 열전달 성능을 계산하는 설계·해석 방법입니다.

    쉽게 풀면

    열교환기는 뜨거운 물과 차가운 물을 직접 섞지 않고 열만 주고받게 하는 장치입니다. 이 장치가 이론적으로 가능한 최대치에 비해 실제로 열을 얼마나 잘 전달하는지를 나타내는 값이 '유효도'입니다. 그런데 열교환기를 설계하는 단계에서는 출구 온도를 미리 알 수 없는 경우가 많은데, 이때 유효도-NTU법을 쓰면 온도를 몰라도 열교환기 크기와 유량만으로 성능을 미리 계산할 수 있습니다.

    왜 중요한가

    발전소, 냉동공조, 화학플랜트 등 거의 모든 열 시스템에 열교환기가 사용되기 때문에, 출구 온도가 미지수인 설계 초기 단계에서도 성능을 빠르게 평가할 수 있는 유효도-NTU법은 열교환기 설계 논문과 실무에서 표준적으로 활용됩니다.

    어떤 절차인가

    유효도-NTU법은 출구 온도를 모르는 상태에서 열교환기가 전달하는 열량을 구하는 절차입니다.

    1. 두 유체의 열용량률 C = ṁ·cp를 구하고 작은 쪽을 Cmin, 큰 쪽을 Cmax로 둡니다. Cr = Cmin/Cmax.
    2. NTU = UA / Cmin (U: 총괄열전달계수, A: 전열면적).
    3. 유동 배열(대향류·병류 등)에 맞는 관계식으로 유효도 ε를 구합니다. 대향류는 ε = [1 − e−NTU(1−Cr)] / [1 − Cr·e−NTU(1−Cr)], 병류는 ε = [1 − e−NTU(1+Cr)] / (1 + Cr)입니다.
    4. q = ε·Cmin·(Th,in − Tc,in)로 열량을 얻고, 그에 따라 출구 온도를 계산합니다.

    언제 쓰고 무엇을 얻나

    배열이 성능에 미치는 영향은 Cr = 0.5일 때 다음 계산값으로 확인됩니다.

    NTU대향류 ε병류 ε
    0.50.3620.352
    10.5650.518
    20.7750.633
    30.8740.659

    NTU가 커질수록 대향류는 1에 다가가지만 병류는 1/(1+Cr)(여기서는 0.667)에 머뭅니다.

    작은 예(가상의 값). 고온 유체 C = 2,000 W/K(= Cmin), 저온 유체 C = 4,000 W/K, UA = 4,000 W/K이면 NTU = 2, Cr = 0.5입니다. 입구가 90 ℃와 20 ℃인 대향류에서 ε = 0.775이므로 q = 0.775 × 2,000 × 70 ≈ 108 kW, 출구는 고온 측 약 35.8 ℃, 저온 측 약 47.1 ℃입니다. 같은 조건의 병류는 ε = 0.633이라 q ≈ 88.7 kW에 그칩니다.

    논문에는 이렇게 적는다

    • 사용한 방법(유효도-NTU 또는 LMTD)과 유동 배열, 사용한 ε–NTU 관계식의 출처를 적습니다.
    • Cmin, Cr, NTU, ε를 모두 제시하고, U 값은 가정(오염계수 포함 여부)인지 실측인지 밝힙니다.
    • 상변화·물성 변화가 큰 구간은 구간을 나누어 계산했는지 적습니다(표준 관계식은 정상상태·물성 일정을 전제로 합니다).
    • 실험 검증 시 측정한 입출구 온도에서 ε를 역산해 해석값과 비교하는 표현이 흔합니다.

    논문에서는 이렇게 쓰입니다

    예시 문장

    아래는 용어의 쓰임을 보여 주려고 만든 예시로, 실제 논문에서 가져온 문장이 아닙니다.

    "본 연구에서는 유효도-NTU법을 이용하여 다양한 유량 조건에서 판형 열교환기의 열전달 성능을 예측하였다."

    입출구 온도를 직접 측정하지 않고도 유효도-NTU법으로 열교환기가 얼마나 열을 잘 전달하는지 계산했다는 뜻입니다.

    "대향류 배열은 병류 배열에 비해 동일한 NTU에서 더 높은 유효도를 나타내는 것으로 분석되었다."

    유체가 서로 반대 방향으로 흐르는 대향류 방식이 같은 방향으로 흐르는 병류 방식보다 열을 더 효율적으로 전달한다는 결과를 설명하는 문장입니다.

    조금 더 깊게 보면

    NTU는 열교환기의 전열면적과 총괄열전달계수를 유체의 열용량 유량으로 무차원화한 값이며, 유효도는 실제 열전달량을 이론적 최대 열전달량으로 나눈 비율입니다. 유동 배열(병류, 대향류, 직교류 등)에 따라 유효도와 NTU의 관계식이 달라집니다.

    NTU-효과도 방법은 출구 온도를 모르는 상태에서도 설계가 가능하다는 점에서, 출구 온도를 먼저 가정해야 하는 로그평균온도차(LMTD) 방법과 상호보완적으로 사용되며, 두 방법 모두 동일한 열교환기 성능을 서로 다른 변수 조합으로 표현한 것입니다.

    주의할 점

    유효도-NTU법은 정상상태이고 물성치가 일정하다는 가정을 전제로 하므로, 상변화가 일어나거나 물성이 급격히 변하는 조건에서는 별도의 보정이 필요할 수 있습니다. 동일한 유동배열이라도 대향류와 병행류는 효과도-NTU 관계식이 서로 다르며, 대향류 배열이 이론적으로 더 높은 효과도를 낼 수 있어 배열 선택이 성능에 직접적인 영향을 줍니다.

    헷갈리기 쉬운 용어

    두 방법은 같은 열교환기를 서로 다른 변수로 계산합니다.

    방법알고 있어야 하는 것구하는 것
    대수평균온도차법(LMTD)입출구 온도 모두(또는 반복 계산)필요한 전열면적 또는 열량
    유효도-NTU법(이 항목)입구 온도, 유량, UA(또는 형상)열량과 출구 온도
    열교환기 효율—유효도 ε 자체의 정의와 쓰임. NTU법은 ε를 NTU로 예측하는 절차
