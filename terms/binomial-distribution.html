    이항분포 (Binomial Distribution)

    확률›이산 확률›이항분포
    수학
    한 줄 정의: 성공 확률이 일정한 독립시행을 여러 번 반복할 때, 성공 횟수가 따르는 확률분포이다.

    쉽게 풀면

    동전을 10번 던진다고 해보자. 매번 앞면이 나올 확률은 항상 2분의 1이고, 이전에 어떤 결과가 나왔든 다음 던지기에는 영향을 주지 않는다. 이런 상황에서 "10번 중 앞면이 정확히 7번 나올 확률은 얼마일까?"를 계산해주는 것이 이항분포이다. 즉, (1) 매번 성공 확률이 똑같고 (2) 각 시행이 서로 독립적일 때, 정해진 횟수 안에서 성공이 몇 번 나올지를 확률로 나타낸 분포이다.

    왜 중요한가

    이항분포는 "성공/실패처럼 두 가지 결과만 있는 사건을 여러 번 반복했을 때 몇 번 성공하는가"라는 매우 흔한 질문에 답을 주기 때문에, 통계적 가설검정이나 실험 설계를 다루는 논문에서 기본 도구로 자주 등장한다. 임상시험에서 치료 반응자 수, 설문조사에서 특정 응답자 수, 품질검사에서 불량품 개수처럼 분야를 가리지 않고 폭넓게 쓰인다. 또한 로지스틱 회귀나 카이제곱 검정 같은 더 복잡한 통계 기법들도 이항분포의 가정 위에서 출발하는 경우가 많아, 이 개념을 이해하면 관련 논문의 통계 방법론 부분을 훨씬 수월하게 읽을 수 있다.

    핵심 정리

    n번의 독립 베르누이 시행에서 성공이 정확히 k번일 확률은 f(k, n, p) = C(n, k)·pk(1 − p)n−k (k = 0, …, n)이다. 조건은 시행 횟수가 정해져 있고, 시행이 서로 독립이며, 각 시행의 결과가 예/아니오 둘뿐이고 성공 확률 p가 같다는 것이다. 평균은 np, 분산은 np(1 − p)이다. n = 1이면 베르누이 분포가 되고, 서로 독립인 베르누이(p) 확률변수 n개의 합이 이항분포를 따른다.

    예시로 보기

    공정한 동전(p = 0.5)을 10번 던질 때 앞면이 정확히 7번 나올 확률은 C(10, 7)/210 = 120/1024로 약 0.117이다. 또 앞면 확률이 0.3인 편향 동전을 6번 던져 앞면이 정확히 4번일 확률이 0.059535이다.

    자주 하는 오해

    n이 크면 계산 대신 근사를 쓴다. 정규 근사는 np와 n(1 − p)가 모두 약 5 이상일 때를 흔히 쓰고, 더 엄격한 규칙은 n > 9(1 − p)/p이고 n > 9p/(1 − p)이다(평균이 0~n 범위의 표준편차 3개 안에 든다는 뜻). n이 크고 p가 작으면 포아송 근사(λ = np)를 쓰며, n ≥ 20이고 p ≤ 0.05, 또는 n ≥ 100이고 np ≤ 10이 기준으로 제시된다. 논문에는 n과 p의 값, 독립성 가정이 성립하는 근거, 근사를 쓴 경우 그 조건을 적는다. 예를 들어 같은 사람이 여러 번 응답한 자료처럼 독립이 깨지면 이항 가정이 맞지 않는다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "설문에 응답한 100명 중 찬성 의견을 낼 확률이 각각 독립적이라고 가정하고, 찬성자 수를 이항분포 B(100, 0.3)으로 모형화하였다."

    이 문장은 100번의 독립적인 시행에서 각각 30%의 확률로 "성공(찬성)"이 일어난다고 가정하고, 전체 찬성자 수의 분포를 이항분포로 나타냈다는 뜻이다.

    "각 환자가 신약에 반응할 확률을 동일하다고 가정하고, 전체 반응자 수가 이항분포를 따른다는 전제 하에 유효성을 검정하였다."

    임상시험 논문에서 흔히 볼 수 있는 표현으로, 환자마다 신약 반응 여부가 독립적이고 반응 확률이 동일하다는 가정 아래, 전체 반응자 수의 분포를 이항분포로 놓고 통계적으로 유의한지 판단했다는 의미이다.

    "생산 라인에서 무작위로 추출한 부품 표본의 불량률이 일정하다고 가정하고, 불량품 개수를 이항분포로 모델링하여 관리 한계선을 설정하였다."

    품질관리 분야의 예문으로, 표본에서 불량품이 나올 확률이 매번 같고 각 부품 검사가 서로 독립적이라는 전제 하에, 불량품 개수의 분포를 이항분포로 두고 공정 관리 기준을 세웠다는 뜻이다.

    조금 더 깊게 보면

    이항분포에서 시행 횟수가 아주 많고 성공 확률이 매우 작을 때는 계산이 번거로워지는데, 이런 경우 흔히 포아송분포로 근사해서 다루기도 한다. 반대로 시행 횟수가 충분히 크면 중심극한정리에 의해 정규분포에 가까워지므로, 많은 논문에서 정규근사를 이용해 신뢰구간이나 검정통계량을 계산한다. 또한 이항분포의 평균은 시행 횟수와 성공 확률의 곱, 분산은 여기에 실패 확률을 한 번 더 곱한 형태로 나타나며, 이 값들은 표본 크기 설계나 검정력 계산의 기초로 자주 활용된다.

    주의할 점

    이항분포를 쓰려면 각 시행이 서로 독립적이고 성공 확률이 매번 동일해야 한다는 전제가 반드시 필요하다. 이 전제가 깨지면(예: 표본을 비복원으로 뽑아 확률이 계속 바뀌는 경우) 다른 분포를 써야 한다. 시행 횟수가 충분히 크면 이항분포는 정규분포에 가까운 모양으로 근사되기도 한다.
