    대칭좌표법 해석 (Symmetrical Components Analysis)

    전기전자공학
    한 줄 정의: 불평형 3상 전압·전류를 정상분, 역상분, 영상분이라는 세 가지 균형 잡힌 성분으로 분해하여 비대칭 고장이나 불평형 상태를 계산하는 전력계통 해석 기법이다.

    쉽게 풀면

    정상적인 3상 전기는 세 개의 파형이 똑같은 크기로 120도씩 어긋나며 나란히 흐르는 상태이다. 그런데 한 상만 땅에 닿는 것 같은 고장이 나면 세 파형이 더 이상 균형을 이루지 못해 계산이 복잡해진다. 대칭좌표법은 이렇게 뒤죽박죽인 불평형 파형을 수학적으로 세 가지 '균형 잡힌 성분'으로 나누어, 각각을 따로 계산한 뒤 다시 합치는 방법이다. 마치 복잡한 화음을 여러 개의 단순한 음으로 쪼개서 분석하는 것과 비슷하다.

    왜 중요한가

    실제 전력계통 고장의 대부분은 한 상만 지락되거나 두 상만 단락되는 등 비대칭적으로 발생하기 때문에, 이를 정확히 계산하려면 대칭좌표법이 필수적이다. 보호계전기 정정, 고장전류 계산, 불평형 부하 해석 등 폭넓은 연구와 실무에서 기본 도구로 사용된다.

    어떤 절차인가

    • 대칭좌표법은 불평형 3상 전력계통(고장이 난 경우 등)을 분석하기 쉽게, 불평형 상 벡터 세 개를 더 단순한 성질을 가진 세 묶음으로 나누는 방법이다.
    • 영상분은 세 상 벡터 합의 1/3이며 성분끼리 같은 위상이다. 정상분은 0°, 120°, 240° 회전한 벡터 합의 1/3로 계통과 같은 상순서이다. 역상분은 0°, 240°, 120°로 돌린 합의 1/3로 반대 상순서이다.
    • 연산자 α = ej120°는 벡터를 반시계 방향으로 120° 돌리며 α3 = 1이다. 상전압은 1, α, α2로 이루어진 3×3 행렬로 대칭성분에서 얻고, 1/3을 곱한 역행렬로 되돌린다.

    언제 쓰고 무엇을 얻나

    계통이 평형이면 각 순서의 식이 서로 독립이므로 순서별로 따로 풀 수 있다. 단선도를 정상·역상·영상 회로망으로 펼치고 각 기기의 순서 임피던스를 쓴다. 이 회로망들을 고장 종류에 맞게 연결해 풀고 결과를 다시 상 값으로 바꾼다. 1선 지락 단락 같은 문제가 훨씬 쉬워진다. 보호계전기에서는 역상 전압·전류가 고장을 알리는 믿을 만한 지표이고, 영상 전류는 평소 매우 작아 큰 값이면 지락 고장의 지표로 쓰인다.

    논문에는 이렇게 적는다

    • 불평형(비대칭) 고장은 단상 단선도로 풀 수 없어서 이 방법을 쓰고, 대칭(평형) 고장은 일반 방법으로 해석할 수 있다. 1선 지락 고장이 송전선 고장의 대략 65~70%를 차지한다는 자료가 있다.
    • 방법은 중첩의 원리에 기대므로 선형 계통에서만 쓸 수 있다.
    • 영상 전류는 중성선을 과열시킬 수 있고, 델타 결선은 영상 전류에 대해 개방 회로로 작용한다.
    • 역사로는 1918년 찰스 포티스큐가 N개의 불평형 상 벡터를 N개의 대칭 묶음으로 나타낼 수 있음을 보였고, 1943년 에디스 클라크의 교재가 3상 계통에서 쓰기 쉽게 만들었다.

    논문에서는 이렇게 쓰입니다

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "The fault current for a single line-to-ground fault is calculated using symmetrical components analysis."

    1선 지락고장의 고장전류를 대칭좌표법 해석으로 계산했다는 뜻이다.

    "Negative-sequence current derived from symmetrical components is used to detect unbalanced loading conditions."

    대칭좌표법으로 구한 역상분 전류를 이용해 불평형 부하 상태를 검출한다는 설명이다.

    조금 더 깊게 보면

    대칭좌표법은 정상분(세 상이 정상 순서로 균형을 이루는 성분), 역상분(반대 순서로 균형을 이루는 성분), 영상분(세 상이 모두 같은 크기와 위상을 갖는 성분)으로 구성된다. 고장 종류(1선 지락, 선간단락, 2선 지락 등)에 따라 이 세 성분이 서로 연결되는 방식이 달라지며, 이를 이용해 각 고장 유형별 전류와 전압을 유도한다. 불평형한 삼상 전압이나 전류를 정상분, 역상분, 영상분이라는 세 가지 대칭 성분으로 분해하면, 각 성분이 독립된 단상 회로처럼 취급될 수 있어 비대칭 고장 해석이 훨씬 단순해진다.

    주의할 점

    대칭좌표법은 계통이 선형이고 3상 대칭 구조를 갖는다는 가정 위에서 성립하는 기법으로, 비선형 소자가 많은 최신 전력전자 기반 계통에서는 적용에 한계가 있을 수 있다.
