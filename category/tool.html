    측정·도구 용어 전체 목록

    측정·도구 분야는 연구에서 자료를 수집하고 검증하기 위해 사용되는 각종 도구와 장비를 다룬다. SPSS, R, Python 같은 통계·분석도구부터 심리검사 척도, 의료 측정기기, 소프트웨어·플랫폼까지 매우 광범위하다. 어떤 도구를 선택하고 활용할지 결정해야 하거나 도구의 신뢰도를 확인해야 하는 실험 연구자, 임상 의료인, 산업 전문가들이 자주 찾는다.
