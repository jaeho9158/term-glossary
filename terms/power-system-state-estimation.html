    전력계통 상태추정 (Power System State Estimation)

    전기전자공학
    한 줄 정의: 계통 곳곳에 설치된 제한된 수의 측정값으로부터 전력계통 전체 모선의 전압과 위상각을 추정해 계통의 현재 운영 상태를 파악하는 기법입니다.

    쉽게 풀면

    전력계통에는 수많은 지점(모선)이 있지만 모든 지점에 측정 장비를 설치하기는 비용상 어렵습니다. 상태추정은 마치 몇 군데에서만 온도를 잰 뒤 나머지 지역의 온도를 계산해 지도를 완성하는 일기예보처럼, 일부 지점의 측정값과 계통의 전기적 모델을 결합해 전체 계통의 전압과 위상각을 추정해내는 작업입니다.

    왜 중요한가

    전력계통 운영자는 계통 전체의 실시간 상태를 알아야 사고를 예방하고 최적으로 전력을 배분할 수 있는데, 측정 오차나 통신 장애로 데이터가 불완전한 경우가 많습니다. 상태추정은 이러한 불완전한 데이터를 보정하고 신뢰할 수 있는 계통 상태를 제공함으로써 에너지관리시스템(EMS)의 핵심 기반 기술로 자리잡고 있습니다.

    상태추정 결과는 이후 이어지는 안전도해석이나 최적조류계산의 입력값으로 그대로 쓰이므로, 추정 단계의 오차가 뒤따르는 계통 운영 판단 전체에 연쇄적으로 영향을 미친다는 점에서 중요성이 강조됩니다.

    어떤 절차인가

    1. 모델 구성: 차단기·개폐기 상태로 계통 연결(토폴로지)을 정하고, 선로·변압기 정수로 네트워크 모델을 만듭니다.
    2. 측정 모델: 측정값 z = h(x) + e. x는 상태변수(모선 전압 크기와 위상각, 기준 모선 위상각은 고정), e는 평균 0의 측정 오차입니다.
    3. 가중 최소자승(WLS): J(x) = [z − h(x)]ᵀ R⁻¹ [z − h(x)]를 최소로 하는 x를 구합니다. R은 오차 분산 행렬이며 정확한 측정값일수록 큰 가중치를 받습니다. 반복 계산에서는 이득 행렬 G = HᵀR⁻¹H를 이용합니다(H는 h의 야코비안).
    4. 관측가능성 확인: 주어진 측정 배치로 모든 상태를 유일하게 정할 수 있는지 먼저 확인하고(가관측성 분석), 부족하면 유사측정을 더하거나 PMU를 보강합니다.
    5. 불량 데이터 처리: J(x̂)가 자유도(측정 수 − 상태 수)의 카이제곱 분포 기준을 넘는지 검정하고, 최대 정규화 잔차 검정으로 의심 측정값을 찾아 제거한 뒤 다시 추정합니다.

    언제 쓰고 무엇을 얻나

    • 언제: 에너지관리시스템(EMS)에서 SCADA·PMU 측정값을 받아 주기적으로 계통 상태를 구할 때 쓰고, 결과는 안전도 해석과 최적조류계산의 입력이 됩니다.
    • 얻는 것: 측정되지 않은 모선을 포함한 전체 모선의 전압·위상각, 측정 오차가 걸러진 조류, 의심 측정값 목록입니다.
    • 한계: WLS는 오차가 정규분포를 따른다는 가정에 기대어 극단적 이상치에 취약하므로 불량 데이터 검출이나 강건 추정과 함께 쓰입니다. 측정점이 부족하거나 통신 오류가 크면 정확도가 크게 떨어집니다.

    가상의 예(계산 결과). 모선 3개, 선로 리액턴스 x₁₂ = 0.1, x₁₃ = 0.2, x₂₃ = 0.1 pu의 직류 근사 모형에서 모선 1을 기준(위상각 0)으로 합니다. 측정값은 P₁₂ = 0.520, P₁₃ = 0.390, P₂₃ = 0.315, 모선 2의 주입 P₂ = −0.230 pu이고 표준편차는 모두 0.01 pu로 둡니다(측정 4개, 상태 2개). WLS로 풀면 θ₂ = −0.0519 rad, θ₃ = −0.0817 rad이며 잔차는 (0.0008, −0.0183, 0.0175, −0.0083), 목적함수 J = 7.13입니다. 자유도 2의 카이제곱 95% 기준값 5.99를 넘으므로 이 측정 집합에는 불량 데이터가 있을 수 있다고 판단하고 정규화 잔차 검정으로 의심 측정을 찾게 됩니다. 이 예의 측정값은 참값(θ₂ = −0.05, θ₃ = −0.08)에 오차를 손으로 더해 만들었습니다.

    논문에는 이렇게 적는다

    • 측정 종류(SCADA, PMU)와 개수, 측정 오차의 표준편차 가정, 중복도(측정 수/상태 수).
    • 추정 알고리즘(WLS, 강건 추정 등), 수렴 기준, 사용한 모형(교류 또는 직류 근사).
    • 불량 데이터 처리 방법과 검정 수준.
    • 평가 지표(추정 오차의 크기, 계산 시간)와 시험 계통의 규모.

    논문에서는 이렇게 쓰입니다

    실제 논문에서

    이 용어를 직접 쓴 국내 논문 문장을 아직 수집하지 못했습니다. 수집되는 대로 출처와 함께 싣겠습니다.

    예시 문장

    아래는 용어의 쓰임을 보여 주려고 만든 예시로, 실제 논문에서 가져온 문장이 아닙니다.

    "본 논문에서는 가중 최소자승법 기반의 상태추정 알고리즘에 PMU 데이터를 결합하여 추정 정확도를 향상시켰다."

    기존 SCADA 측정값에 더해 PMU 데이터를 함께 사용해 상태추정 성능을 높이는 연구를 설명하는 문장입니다.

    "불량 측정 데이터(bad data)를 식별하고 제거하는 절차를 상태추정 과정에 포함시켰다."

    측정 오류가 상태추정 결과를 왜곡하지 않도록 처리하는 절차를 설명하는 문장입니다.

    조금 더 깊게 보면

    상태추정은 일반적으로 가중 최소자승법(WLS)을 이용해 측정값과 추정값 사이의 오차 제곱합을 최소화하는 방식으로 계산됩니다. 최근에는 PMU에서 얻는 동기화된 위상 데이터를 함께 활용하는 선형 상태추정 방법도 연구되고 있으며, 잘못된 측정값을 걸러내는 불량 데이터 검출 절차가 함께 수행됩니다.

    관측성(observability)은 주어진 측정 배치만으로 상태추정 해가 유일하게 결정될 수 있는지를 나타내는 개념으로, 관측되지 않는 영역이 있으면 유사측정(pseudo-measurement)을 추가하거나 PMU를 보강해 이를 확보합니다.

    주의할 점

    상태추정 결과는 실제 측정값이 아니라 통계적 추정치이므로, 측정점이 부족하거나 통신 오류가 심한 경우 추정 정확도가 크게 떨어질 수 있습니다. WLS 기반 추정은 측정 오차가 정규분포를 따른다는 가정에 의존하므로, 극단적인 이상치가 섞이면 추정치가 크게 왜곡될 수 있어 불량 데이터 검출과 강건 추정 기법이 함께 다뤄집니다.

    헷갈리기 쉬운 용어

    조류계산과 상태추정은 입력과 목적이 다릅니다.

    용어입력목적
    전력계통 상태추정중복되고 오차가 섞인 측정값실제 운전 상태의 최선의 추정
    조류계산발전·부하 등 주어진 조건조건이 정해졌을 때 전압·조류 계산
    가중최소제곱법신뢰도가 다른 관측값상태추정의 기본 계산 방법
    가관측성 분석(계통)측정 배치상태를 유일하게 정할 수 있는지 판별
    SCADA현장 설비 측정감시·제어 데이터 수집
