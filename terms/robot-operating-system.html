    로봇운영체제 (Robot Operating System (ROS))

    로봇공학
    한 줄 정의: 로봇 소프트웨어 개발을 위한 통신 미들웨어, 라이브러리, 도구 모음을 제공하는 오픈소스 로봇 소프트웨어 프레임워크.

    쉽게 풀면

    여러 로봇 프로그램 부품들이 서로 쉽게 정보를 주고받을 수 있도록 도와주는, 로봇 개발을 위한 공용 소프트웨어 도구 모음입니다.

    논문에서는 이렇게 쓰입니다

    ROS는 노드 간 메시지 교환을 위한 발행-구독 통신 모델과 서비스 호출 구조를 제공하여 모듈화된 로봇 소프트웨어 구성요소의 재사용과 분산 실행을 지원한다.

    각 기능(센서 처리, 경로 계획 등)을 독립된 프로그램(노드)으로 만들고, 이들이 표준화된 방식으로 메시지를 주고받게 함으로써 개발과 재사용을 쉽게 한다는 뜻입니다.

    주의할 점

    실시간성이 엄격히 요구되는 응용에는 기존 ROS의 통신 구조가 지연이나 결정성 측면에서 한계를 보일 수 있습니다.
