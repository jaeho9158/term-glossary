    API뱅킹 (API Banking)

    재무·금융학
    한 줄 정의: 은행이 계좌 조회, 이체, 결제와 같은 핵심 금융 기능을 표준화된 응용프로그램인터페이스 형태로 외부 개발자와 기업에 개방하여, 제3자가 자신의 서비스에 은행 기능을 직접 연동할 수 있도록 하는 기술 체계이다.

    쉽게 풀면

    은행이 자신들의 이체나 조회 기능을 레고 블록처럼 표준화된 형태로 열어두어서, 다른 회사들이 자기 앱이나 서비스에 은행 기능을 쉽게 끼워 넣을 수 있게 해주는 방식이다.

    논문에서는 이렇게 쓰입니다

    Cortet, M., Rijks, T., & Nijland, S. (2016). PSD2: The Digital Transformation Accelerator for Banks. Journal of Payments Strategy & Systems.

    코르테 외 연구진은 유럽 결제서비스지침이 은행에 표준화된 API 개방을 의무화한 배경과 그에 따른 은행의 사업모델 변화를 분석하여, API 기반 개방이 은행을 단순한 계좌 보유자에서 금융 플랫폼 참여자로 전환시키는 계기가 되었음을 보였다.

    주의할 점

    오픈뱅킹이 규제와 정책의 관점에서 데이터 개방을 다루는 개념이라면, API뱅킹은 그러한 개방을 구현하는 구체적인 기술적 연동 방식 자체를 지칭한다는 점에서 서로 밀접하지만 층위가 다른 개념이다.
