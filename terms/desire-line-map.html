    희망선지도 (Desire Line Map)

    지도학
    한 줄 정의: 출발지와 목적지를 실제 이동 경로가 아닌 직선으로 연결하여 이동량이나 흐름의 방향과 크기를 표현하는 지도입니다.

    쉽게 풀면

    사람들이 실제로 걷는 길이 아니라, 잔디밭을 가로질러 가장 짧게 다니는 지름길을 떠올리면 이름의 유래를 이해하기 쉽습니다. 희망선지도는 출발지와 도착지를 도로나 실제 경로와 상관없이 곧은 직선으로 이어서 그립니다. 이동하는 사람이나 물자의 양이 많을수록 선을 굵게 그려서, 어디에서 어디로 얼마나 많은 흐름이 발생하는지 한눈에 보여줍니다. 통근, 이주, 물류 흐름 등을 표현할 때 자주 사용됩니다.

    왜 중요한가

    희망선지도는 복잡한 실제 경로 대신 출발지와 목적지 사이의 관계 자체에 집중할 수 있게 해주어, 인구 이동이나 통근 패턴, 물류 흐름과 같은 공간적 상호작용을 분석하는 연구에서 널리 활용됩니다. 흐름 지도(flow map)의 대표적인 형태 중 하나로 지도학 및 교통지리학 연구에서 자주 다뤄집니다.

    논문에서는 이렇게 쓰입니다

    "본 연구는 수도권 통근자의 출발지와 근무지 데이터를 이용해 희망선지도(desire line map)를 제작하여 통근 흐름의 방향성과 집중도를 시각화하였다."

    통근 데이터를 직선 흐름으로 표현해 이동 패턴을 분석한 연구 사례입니다.

    "희망선지도는 실제 이동 경로 정보를 담지 않기 때문에, 도로망이나 지형에 따른 실제 이동 거리와는 차이가 있을 수 있다."

    희망선지도가 실제 경로가 아닌 직선 관계만을 표현한다는 특성과 한계를 설명한 문장입니다.

    조금 더 깊게 보면

    희망선지도는 흔히 출발지-목적지(origin-destination, OD) 통계 데이터를 기반으로 제작되며, 선의 굵기나 색상 농도를 이동량에 비례하도록 설정합니다. 다수의 선이 교차하거나 밀집될 경우 가독성이 떨어질 수 있어, 곡선화(bundling)나 투명도 조정 같은 후처리 기법이 함께 활용되기도 합니다.

    주의할 점

    희망선지도는 실제 이동 경로가 아닌 관계의 방향과 크기만을 나타내므로, 실제 도로 이용 패턴 분석에는 등시선지도나 네트워크 분석 같은 별도의 방법이 필요합니다.
