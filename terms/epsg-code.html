    EPSG 코드 (EPSG code)

    지도학
    한 줄 정의: 좌표계와 기준계를 숫자 하나로 식별하도록 정한 국제 등록 코드입니다.

    쉽게 풀면

    세상에는 수천 가지 좌표계가 있어서 말로 설명하면 헷갈리기 쉽습니다. EPSG 코드는 각 좌표계에 고유한 번호를 붙여 둔 목록으로, 번호 하나만 말하면 어떤 타원체와 투영법, 어떤 원점을 쓰는지가 모두 확정됩니다. 예를 들어 4326은 위도·경도로 표현한 WGS84 좌표계를, 3857은 웹지도에서 쓰는 투영좌표계를 가리킵니다.

    왜 중요한가

    EPSG 코드는 공간자료를 주고받을 때 좌표계 정보를 오해 없이 전달하는 사실상의 표준이며, 거의 모든 GIS 소프트웨어와 공간 데이터베이스가 이 코드로 좌표계를 지정합니다. 코드 하나로 변환에 필요한 모든 매개변수가 정의되므로 투영변환과 측지기준계 변환을 자동화할 수 있습니다. 논문에서 사용 좌표계를 밝힐 때도 코드를 적으면 재현성이 크게 높아집니다.

    논문에서는 이렇게 쓰입니다

    "모든 공간자료는 EPSG:5186 좌표계로 변환한 뒤 중첩분석을 수행하였다."

    서로 다른 좌표계로 만들어진 자료들을 하나의 지정된 좌표계로 통일해, 겹쳐 놓았을 때 위치가 어긋나지 않도록 했다는 뜻입니다.

    조금 더 깊게 보면

    이 목록은 원래 유럽 석유탐사 단체가 관리하던 데이터베이스에서 출발해 현재는 국제 석유·가스 생산자 협회가 유지하며, 좌표계뿐 아니라 기준계, 타원체, 변환 매개변수, 단위까지 각각 코드로 등록되어 있습니다. 코드는 좌표축의 순서까지 규정하는데, 예를 들어 4326은 공식적으로 위도·경도 순서이지만 많은 소프트웨어가 경도·위도 순서로 다루어 혼선이 생기곤 합니다. 웹지도에서 쓰는 3857은 구를 가정한 웹 메르카토르로, 엄밀한 측지 계산에는 적합하지 않습니다.

    주의할 점

    EPSG 코드는 좌표계를 식별할 뿐 자료의 위치 정확도를 보증하지 않으므로, 코드를 붙였다고 해서 좌표가 옳다는 뜻은 아닙니다. 또한 같은 지역에도 옛 기준계와 현행 기준계에 각각 다른 코드가 있으므로, 코드를 잘못 지정하면 수백 미터의 계통적 위치 이동이 발생합니다.
