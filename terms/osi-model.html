    OSI 7계층 모델 (OSI Model)

    컴퓨터과학·AI
    한 줄 정의: 컴퓨터 간 통신 과정을 물리적 신호부터 사람이 보는 화면까지 7개의 층으로 나눠 설명하는 표준 모델입니다.

    쉽게 풀면

    택배를 보내는 과정을 떠올려봅시다. 물건을 포장하고(포장 담당), 상자에 주소를 쓰고(배송 담당), 트럭에 실어 도로로 옮기는(운송 담당) 것처럼, 각 단계마다 맡은 역할이 다릅니다. OSI 모델도 마찬가지로 네트워크 통신을 7개 층으로 쪼갭니다: 1계층 물리(전선·전파 신호), 2계층 데이터링크(같은 네트워크 내 기기 간 전달), 3계층 네트워크(다른 네트워크로 가는 경로 찾기, IP), 4계층 전송(데이터가 순서대로 잘 도착했는지 확인, TCP/UDP), 5계층 세션(연결 유지), 6계층 표현(암호화·압축 등 형식 변환), 7계층 응용(우리가 실제로 쓰는 웹브라우저·이메일 같은 프로그램). 각 층은 자기 바로 아래·위 층하고만 소통하면 되므로, 한 층의 기술이 바뀌어도 다른 층에는 영향을 주지 않는다는 장점이 있습니다.

    왜 중요한가

    OSI 모델은 네트워크 보안, 프로토콜 설계, 시스템 성능 분석 등 컴퓨터 네트워크를 다루는 거의 모든 연구에서 문제를 어느 층에서 다루고 있는지 명확히 밝히는 공통 언어 역할을 합니다. 예를 들어 침입 탐지 연구는 어느 계층의 정보를 분석하느냐에 따라 접근 방식과 탐지 가능한 공격 유형이 달라지므로, 계층을 명시하는 것이 연구의 범위와 한계를 규정하는 데 중요합니다. 또한 서로 다른 분야의 연구자가 통신 시스템을 논의할 때 계층 개념은 복잡한 네트워크 스택을 비교·설명하는 표준 틀로 작동합니다.

    논문에서는 이렇게 쓰입니다

    "제안하는 침입 탐지 기법은 OSI 모델의 네트워크 계층(3계층)과 전송 계층(4계층)에서 수집된 패킷 특징을 기반으로 한다."

    이 문장은 "통신 과정 중 경로 정보(IP)와 전달 확인 정보(TCP/UDP)가 다뤄지는 층에서 뽑아낸 데이터를 분석에 사용했다"는 뜻입니다.

    "사물인터넷 기기 간 통신 지연은 응용 계층(7계층)의 프로토콜 오버헤드와 데이터링크 계층(2계층)의 매체 접근 방식에서 각각 기인하는 것으로 분석되었다."

    사물인터넷·임베디드 시스템 연구에서 통신 지연의 원인을 특정 계층별로 나누어 진단할 때 사용되는 표현입니다.

    "본 논문에서 설계한 라우팅 알고리즘은 OSI 3계층에서 동작하며, 상위 계층 프로토콜과 독립적으로 동작하도록 구현되었다."

    네트워크 프로토콜 설계 연구에서 새로 제안한 기법이 어느 계층에서 동작하며 다른 계층과 어떻게 분리되는지 명시할 때 쓰인다.

    조금 더 깊게 보면

    실무와 논문에서는 OSI 7계층을 그대로 쓰기보다 TCP/IP 4계층(또는 5계층) 모델과 섞어서 언급하는 경우가 흔하므로, 계층 번호가 어떤 기준을 따르는지 문맥으로 파악해야 합니다. 또한 논문에서 "L2", "L3", "L7"처럼 계층 번호만으로 줄여 표기하는 관행도 흔하니, 각 층에서 다루는 대표 프로토콜(예: 2계층의 이더넷, 3계층의 IP, 4계층의 TCP/UDP, 7계층의 HTTP)을 함께 기억해 두면 논문을 읽을 때 도움이 됩니다.

    주의할 점

    OSI 모델은 개념을 이해하기 위한 참조 모델이며, 실제 인터넷에서 널리 쓰이는 것은 이를 단순화한 TCP/IP 4계층 모델입니다. 논문에서 계층 번호를 언급할 때는 어떤 모델 기준인지 혼동하지 않도록 네트워크와 프로토콜 기초 개념과 함께 확인하는 것이 좋습니다.

    관련 용어

    네트워크와 프로토콜 기초 API (응용 프로그래밍 인터페이스) 공개키 암호화 로드밸런싱 암호화 네트워크 지연 시간 해시 함수 전자서명 인피니밴드 TCP/IP
