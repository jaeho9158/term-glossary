    동적계획법 (Dynamic Programming)

    산업공학
    한 줄 정의: 복잡한 문제를 여러 개의 작은 하위 문제로 나누고, 각 하위 문제의 최적해를 저장해 재사용함으로써 전체 문제의 최적해를 구하는 최적화 기법입니다.

    쉽게 풀면

    여행 경로를 계획할 때, 목적지까지 가는 여러 경로를 매번 처음부터 다시 계산하는 대신, 이미 계산해둔 중간 지점까지의 최적 경로를 재활용하는 것과 비슷합니다. 동적계획법은 큰 문제를 작은 단계로 쪼갠 뒤, 각 단계에서 얻은 최적의 결과를 기록해두고 다음 단계에서 그대로 활용하는 방식입니다. 같은 계산을 반복하지 않아도 되기 때문에 복잡한 문제도 효율적으로 풀 수 있습니다.

    왜 중요한가

    생산 계획, 재고 관리, 경로 탐색 등 여러 단계에 걸쳐 의사결정이 이어지는 문제는 산업공학 전반에서 흔히 등장하는데, 이런 문제들은 하위 문제로 나누어 순차적으로 풀 수 있는 구조를 가진 경우가 많아 동적계획법이 강력한 해법으로 활용됩니다. 최적 부분구조와 중복되는 하위 문제라는 두 가지 조건을 만족하는 문제에 특히 효과적입니다.

    논문에서는 이렇게 쓰입니다

    "본 연구에서는 다단계 재고 정책 문제를 동적계획법을 이용하여 각 기간별 최적 발주량을 도출하였다."

    여러 기간에 걸친 의사결정 문제를 단계별로 나누어 최적해를 구하는 과정을 설명하는 문장입니다.

    "제안된 알고리즘은 동적계획법 기반의 상태 전이 구조를 이용하여 설비 교체 시점을 순차적으로 결정한다."

    설비의 상태가 시간에 따라 변화하는 문제를 단계적으로 풀어나가는 응용 맥락입니다.

    조금 더 깊게 보면

    동적계획법은 문제를 상태(state)와 단계(stage)로 정의하고, 각 상태에서의 최적 가치를 재귀적인 관계식(벨만 방정식)으로 표현하는 방식이 핵심입니다. 이미 계산한 하위 문제의 결과를 저장해두는 메모이제이션(memoization) 기법을 통해 중복 계산을 피하며, 순방향 또는 역방향으로 상태를 갱신해나가는 방식이 함께 사용됩니다.

    주의할 점

    동적계획법은 상태 공간이 커질수록 저장해야 할 정보와 계산량이 급격히 늘어나는 '차원의 저주' 문제를 겪을 수 있어, 문제 규모가 매우 큰 경우에는 근사적 접근이나 다른 최적화 기법과의 결합이 필요할 수 있습니다.
