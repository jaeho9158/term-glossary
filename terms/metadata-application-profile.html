    메타데이터적용프로파일 (Metadata Application Profile)

    문헌정보학
    한 줄 정의: 특정 기관이나 프로젝트가 자신의 목적에 맞게 하나 이상의 기존 메타데이터 표준에서 필요한 요소를 선택하고 값 범위나 필수 여부를 재조정하여 정의한 맞춤형 메타데이터 규격이다.

    쉽게 풀면

    기존 메타데이터 표준 중에서 필요한 항목만 골라 자기 기관에 맞게 다시 정리한 맞춤형 규격이다.

    논문에서는 이렇게 쓰입니다

    이 연구는 특정 대학의 디지털 아카이브가 더블린코어를 기반으로 자체 메타데이터적용프로파일을 설계한 사례를 분석하였다.

    더블린코어를 바탕으로 기관 맞춤형 메타데이터적용프로파일을 설계한 사례를 분석한 문장이다.

    주의할 점

    메타데이터적용프로파일은 기관별로 상이하게 설계될 수 있어, 여러 기관의 데이터를 통합할 때는 프로파일 간 차이를 조율하는 별도의 매핑 작업이 필요하다는 점에 유의해야 한다.
