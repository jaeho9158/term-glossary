    다중 유전체 편집 (Multiplex Genome Editing)

    생명공학
    한 줄 정의: 여러 개의 유전자 위치를 동시에 표적으로 삼아 한 번에 여러 곳을 편집하는 유전체 편집 기법입니다.

    쉽게 풀면

    보통 유전자가위는 한 번에 한 유전자를 겨냥해 자르는 방식으로 많이 소개되지만, 실제로는 여러 개의 가이드 RNA를 함께 사용해 동시에 여러 유전자를 편집할 수도 있습니다. 다중 유전체 편집은 이렇게 여러 표적을 한꺼번에 다루는 방식으로, 여러 스위치를 동시에 눌러 여러 기능을 한 번에 바꾸는 것에 비유할 수 있습니다.

    왜 중요한가

    복잡한 생물학적 경로는 한 유전자만 바꿔서는 원하는 표현형을 얻기 어려운 경우가 많아, 여러 유전자를 동시에 조작해야 하는 연구나 여러 유전자가 관여하는 질환의 치료 전략을 다루는 논문에서 이 기법이 중요하게 다뤄집니다.

    논문에서는 이렇게 쓰입니다

    "Multiplex genome editing was used to simultaneously knock out three genes involved in the metabolic pathway."

    대사 경로에 관여하는 세 개의 유전자를 동시에 결손시키기 위해 다중 유전체 편집을 사용했다는 예문입니다.

    "We designed a multiplex genome editing strategy using multiple guide RNAs delivered in a single vector."

    하나의 벡터로 여러 가이드 RNA를 전달하는 다중 유전체 편집 전략을 설계했다는 내용입니다.

    조금 더 깊게 보면

    다중 유전체 편집은 대체로 여러 개의 가이드 RNA를 동시에 세포에 발현시키거나 전달하는 방식으로 이루어지며, 하나의 벡터에 여러 가이드 RNA를 배열해 넣는 방법이 흔히 사용됩니다. 편집 대상이 늘어날수록 각 위치의 편집 효율을 개별적으로 확인하는 과정이 더 중요해집니다.

    주의할 점

    표적 위치가 많아질수록 의도하지 않은 위치를 자르는 오프타깃 편집이 발생할 가능성도 함께 검토해야 하며, 여러 편집이 동시에 일어나면서 예기치 않은 유전체 재배열이 생길 위험도 있습니다.
