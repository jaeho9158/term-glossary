    벡터 데이터 모델 (Vector Data Model)

    지도학
    한 줄 정의: 지리 현상을 점, 선, 면과 같은 좌표 기반의 도형 요소로 표현하는 공간 데이터 저장 방식입니다.

    쉽게 풀면

    벡터 데이터 모델은 지도 위의 대상을 정확한 좌표를 가진 도형으로 표현합니다. 건물이나 우물처럼 하나의 위치는 점으로, 도로나 하천처럼 길게 이어진 것은 선으로, 행정구역이나 호수처럼 넓은 면적을 가진 것은 면으로 나타냅니다. 마치 그림판에서 도형 도구로 지도를 그리는 것과 비슷한 방식입니다. 좌표를 정확히 저장하기 때문에 확대해도 형태가 흐트러지지 않는다는 특징이 있습니다.

    왜 중요한가

    벡터 데이터 모델은 정확한 위치와 형태 정보를 담을 수 있어, 도로망 분석이나 행정구역 경계 관리처럼 정밀한 공간 관계가 중요한 연구와 실무에서 널리 활용됩니다. 지리정보시스템의 핵심 데이터 구조 중 하나로서, 공간분석 방법론을 논의할 때 항상 함께 다루어지는 개념입니다.

    논문에서는 이렇게 쓰입니다

    "행정구역 경계는 폴리곤 형태의 벡터 데이터 모델로 구축하여 면적 계산에 활용하였다."

    면 형태의 벡터 데이터가 행정구역 분석에 활용된 예입니다.

    "도로망을 선형 벡터 데이터 모델로 구축하고 네트워크 분석을 통해 최단 경로를 산출하였다."

    선 형태의 벡터 데이터로 경로 분석을 수행한 사례입니다.

    조금 더 깊게 보면

    벡터 데이터 모델은 각 도형 요소에 속성 정보를 함께 저장할 수 있어, 위치 정보와 속성 정보를 연결한 분석이 가능합니다. 점, 선, 면 사이의 위상관계를 관리하는 방식은 데이터 정확도와 분석 효율성에 큰 영향을 미치는 것으로 알려져 있습니다.

    주의할 점

    벡터 데이터 모델은 연속적으로 변화하는 지형이나 기후처럼 경계가 뚜렷하지 않은 현상을 표현하는 데는 상대적으로 적합하지 않을 수 있어, 이런 경우 래스터 데이터 모델과 함께 검토됩니다.

    관련 용어
