    OAI-PMH (Open Archives Initiative Protocol for Metadata Harvesting (OAI-PMH))

    문헌정보학
    한 줄 정의: 서로 다른 기관의 디지털 저장소가 보유한 메타데이터를 표준화된 방식으로 수집(harvesting)할 수 있도록 정의한 프로토콜로, 여러 기관레포지토리의 메타데이터를 통합하여 검색 서비스를 구축하는 데 널리 활용된다.

    쉽게 풀면

    여러 도서관이나 저장소가 가진 자료 설명 정보를 한곳에 자동으로 모아올 수 있게 해주는 통신 규약이다.

    논문에서는 이렇게 쓰입니다

    본 통합검색 서비스는 OAI-PMH를 통해 전국 기관레포지토리의 메타데이터를 정기적으로 수집하여 하나의 검색 인터페이스로 제공한다.

    OAI-PMH를 이용해 여러 기관레포지토리의 메타데이터를 통합 수집하는 서비스 구축 사례를 설명하는 문장이다.

    주의할 점

    OAI-PMH는 메타데이터만을 수집할 뿐 원문 콘텐츠 자체를 전송하지 않으므로, 실제 원문 접근은 별도의 링크를 통해 이루어진다.

    관련 용어

    기관레포지토리 메타데이터 상호운용성 더블린코어 통합검색
