    APACHE II 점수 (APACHE II Score)

    의학

    ✓ 출처 대조 2026-11-08

    한 줄 정의: 입원 첫 24시간의 생리 지표와 나이·기저질환으로 중환자의 사망 위험을 추정하는 점수이다.

    쉽게 풀면

    APACHE II는 체온, 혈압, 맥박, 호흡수, 산소, 전해질, 신장 기능 등 급성 생리 지표에 나이 점수와 만성질환 점수를 더해 계산한다. 이 점수는 다시 환산식을 거쳐 이 환자가 병원에서 사망할 확률이 몇 퍼센트쯤 되는지를 나타내는 예측값으로 바뀐다. 즉 개별 환자의 운명을 맞히는 도구라기보다, 비슷한 상태의 환자 집단이 평균적으로 어떤 결과를 보였는지를 알려 주는 참조표에 가깝다.

    왜 중요한가

    중환자실 연구에서는 병원마다 받아들이는 환자의 중증도가 달라 결과를 그대로 비교하기 어렵다. APACHE II 점수로 예측 사망률을 계산하면 실제 사망률과의 비를 구할 수 있어, 서로 다른 기관의 성적을 비교적 공정하게 견줄 수 있다. 임상시험에서도 두 군의 기저 중증도가 같은지 보여 주는 표준 지표로 오래 쓰여 왔다.

    무엇을 재는가

    APACHE II(Acute Physiology and Chronic Health Evaluation II)는 중환자실(ICU) 점수 체계 가운데 하나로 질병의 중증도를 분류한다. 환자가 중환자실에 입원한 뒤 24시간 안에 적용하며, 여러 측정값으로 0~71의 정수 점수를 구한다. 점수가 높을수록 병이 더 중하고 사망 위험이 크다. 첫 APACHE 모형은 1981년 Knaus 등이 발표했다.

    성인 중환자실 환자의 중증도를 재도록 설계했고, 16세 미만 어린이·청소년에서는 검증되지 않았다.

    구성과 채점

    점수는 12개 입원 시 생리 변수로 이루어진 급성 생리 점수, 나이 점수, 만성 건강 점수를 합해 구한다.

    구성내용
    A. 급성 생리 점수(입원 24시간 내)AaDO2 또는 PaO2(FiO2가 0.5 이상이냐 미만이냐에 따라), 직장 체온, 평균 동맥압, 혈액 pH, 심박수, 호흡수, 혈청 나트륨, 혈청 칼륨, 크레아티닌(급성 신부전은 점수 2배), 헤마토크릿, 백혈구 수, 글래스고 혼수 척도(15에서 실제 GCS를 뺀 값)
    B. 나이 점수연령에 따라 점수 부여
    C. 만성 건강 점수심한 장기 부전 병력(간경변, 문맥고혈압, NYHA IV기 심부전, 중증 호흡기 질환, 투석 의존) 또는 면역저하(항암, 방사선, 고용량 스테로이드, 진행성 백혈병·림프종·AIDS)가 있으면 비수술 또는 응급 수술 후 환자는 5점, 예정 수술 후 환자는 2점

    정수 값과 선택지 수 제한으로 한 장의 종이 서식에서 손으로 계산하도록 최적화되었다. 입원 점수이므로 입원 기간 중 다시 계산하지 않으며, 퇴실 뒤 재입원하면 새로 계산한다.

    결과 읽는 법

    • 원 논문에서는 APACHE II 점수와 입원 시 주진단을 합쳐 예측 사망률을 계산했다.
    • 특정 점수 이상의 환자에게만 어떤 시술이나 약을 쓰기도 하고, 다른 환자와 결과를 비교할 때 환자의 중증도를 기술하는 데 쓴다. 집단의 예측 사망률을 평균해 집단의 중증도를 나타낸다.
    • APACHE III(1991, 0~299점, 20개 생리 변수)와 APACHE IV(2006)가 많은 곳에서 대체했으나, 문헌이 APACHE II에 기대어 있어 여전히 널리 쓰인다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "평균 APACHE II 점수는 중재군 22.4점, 대조군 21.9점으로 두 군 간 유의한 차이가 없었다."

    연구 시작 시점에 양쪽 환자의 중증도가 비슷했음을 보여 결과 해석의 신뢰를 높이는 서술이다.

    "APACHE II로 예측한 사망률 대비 실제 사망률의 비는 0.82였다."

    표준화사망비를 이용해 중환자실의 진료 성과를 평가하는 용례이다.

    조금 더 깊게 보면

    APACHE II는 1980년대에 미국의 대규모 중환자 자료로 개발되었기 때문에, 현재의 진료 수준에서는 사망률을 과대 추정하는 경향이 보고된다. 이후 개정판이나 다른 계열의 중증도 모형이 나왔지만, 계산이 비교적 단순하고 축적된 문헌이 많다는 이유로 APACHE II가 여전히 널리 인용된다. 논문에서는 점수를 그대로 보고하기도 하고, 예측 사망률로 환산해 모형의 보정도와 판별력을 함께 제시하기도 한다. 이후 나온 APACHE III·IV나 SAPS, MPM 같은 모형들은 변수 구성과 통계적 보정 방법을 개선했지만, 계산의 번거로움과 외부 라이선스 문제로 APACHE II만큼 자유롭게 쓰이지는 못했다.

    주의할 점

    APACHE II는 입원 첫 24시간 자료로 한 번 계산하는 것이 원칙이므로, 날마다 반복해 경과를 보는 SOFA 점수와 목적이 다르다. 또 개별 환자의 치료 방향을 이 점수만으로 결정해서는 안 되며, 집단 수준의 위험 보정 도구로 쓰는 것이 원칙이다. 점수가 개발된 인구집단과 현재 진료 환경이 다르면 예측 사망률의 보정도가 떨어지므로, 새로운 병원이나 시대에 적용할 때는 반드시 재보정 여부를 확인해야 한다.
