    내비게이션패턴 (Navigation Pattern)

    디자인학
    한 줄 정의: 사용자가 인터페이스 내에서 콘텐츠와 기능 사이를 이동할 수 있도록 설계된 반복 가능한 탐색 구조와 UI 형식이다.

    쉽게 풀면

    메뉴, 탭, 뒤로가기 버튼처럼 화면 사이를 이동할 때 쓰는 정해진 방식들이다.

    왜 중요한가

    내비게이션 패턴은 사용자가 앱이나 웹사이트 내에서 길을 잃지 않고 원하는 정보에 도달하도록 돕는 반복 가능한 구조로, 탭바, 햄버거 메뉴, 사이드바 등이 대표적 유형이다. 정보 구조가 복잡한 서비스일수록 검증된 패턴을 채택해 학습 비용을 낮춘다. 메가메뉴처럼 한 번에 많은 하위 항목을 펼쳐 보여주는 패턴은 콘텐츠가 매우 많은 이커머스 사이트에 적합하지만, 항목이 적은 서비스에 적용하면 오히려 화면이 불필요하게 복잡해 보인다. 같은 서비스 안에서도 데스크톱은 사이드바를, 모바일은 하단 탭바를 쓰는 것처럼 화면 크기에 따라 서로 다른 내비게이션 패턴을 조합해 쓰는 것이 반응형 설계의 일반적 접근이다. 내비게이션 패턴을 바꾸는 리디자인은 기존 사용자의 학습된 습관을 깨뜨리는 것이라, 변경 초기에는 오히려 과업 완료율이 일시적으로 떨어지는 적응 구간이 나타나는 경우가 많다. 사용자가 한 번 학습한 내비게이션 패턴은 다른 유사 서비스에서도 그대로 기대하게 되므로, 새로운 패턴을 도입할 때는 충분한 사용성 검증을 거치는 것이 안전하다.

    논문에서는 이렇게 쓰입니다

    본 연구는 하단 탭바 내비게이션패턴과 햄버거메뉴 패턴 간 사용자 접근 속도를 비교 분석하였다.

    서로 다른 탐색 방식이 사용자 접근 효율에 미치는 영향을 비교한 UI 연구이다.

    본 연구는 내비게이션패턴 유형에 따라 사용자의 정보 탐색 소요시간과 만족도가 어떻게 달라지는지 비교하였다.

    동일한 콘텐츠라도 어떤 내비게이션패턴을 적용하느냐에 따라 사용자가 원하는 정보를 찾는 속도와 경험이 달라진다는 의미예요.

    조금 더 깊게 보면

    특정 패턴이 유행한다고 해서 모든 서비스에 적합한 것은 아니며, 예를 들어 모바일에서 인기 있는 하단 탭바를 콘텐츠가 방대한 데스크톱 서비스에 그대로 적용하면 오히려 정보 접근성이 떨어질 수 있다. 사이트맵이 정보 구조 전체의 설계도라면 내비게이션 패턴은 그 구조를 사용자가 실제로 조작하는 인터페이스 요소를 가리킨다. 내비게이션 패턴은 크게 전역 내비게이션(항상 노출되는 최상위 메뉴), 로컬 내비게이션(현재 섹션 내 하위 메뉴), 맥락 내비게이션(관련 콘텐츠 추천 링크)의 세 층위로 나뉘며, 이 층위를 혼동하면 사용자가 자신이 어느 깊이에 있는지 가늠하기 어려워진다.

    주의할 점

    내비게이션패턴 선택은 콘텐츠 양과 사용 맥락에 따라 달라지며 하나의 정답이 있는 것은 아니다.
