    근의 공식 (Quadratic Formula)

    이차방정식›근의 공식
    수학
    한 줄 정의: ax² + bx + c = 0 형태의 이차방정식을 인수분해 없이도 항상 풀 수 있게 해주는 공식 x = (-b ± √(b²-4ac)) / 2a 이다.

    쉽게 풀면

    이차방정식은 인수분해가 깔끔하게 되는 경우도 있지만, 대부분은 숫자가 지저분해서 인수분해로 풀기 어렵다. 근의 공식은 어떤 이차방정식이든 계수 a, b, c만 알면 답을 바로 계산해내는 "만능 열쇠"이다. 마치 복잡한 자물쇠마다 다른 열쇠를 깎을 필요 없이, 하나의 만능키로 모든 자물쇠를 열 수 있는 것과 비슷하다. 공식 안의 b²-4ac 부분(판별식)이 답의 개수와 종류를 미리 알려주는 신호등 역할을 한다.

    왜 중요한가

    근의 공식은 이차식으로 정리되는 해석적 문제에서 근을 즉시, 정확하게 구할 수 있게 해주기 때문에 수치해석 알고리즘의 초기값을 정하거나, 시뮬레이션 검증용 정답(해석해)을 마련하는 데 널리 쓰인다. 복잡한 비선형 문제를 이차식으로 근사하거나 국소적으로 선형화한 뒤 근의 공식을 적용해 대략적인 해의 위치를 가늠하는 경우도 많아, 다양한 공학·물리 분야 논문에서 보조 도구로 자주 언급된다.

    핵심 정리

    • ax² + bx + c = 0 (a ≠ 0)의 해는 x = (−b ± √(b² − 4ac)) / 2a이다. 완전제곱식으로 고쳐 쓰는 과정(제곱완성)에서 유도된다.
    • 근호 안의 D = b² − 4ac가 판별식이다. D > 0이면 서로 다른 두 실근, D = 0이면 중근(실근 하나), D < 0이면 서로 켤레인 두 허근이다.
    • 두 근을 α, β라 하면 α + β = −b/a, αβ = c/a이다(근과 계수의 관계).
    • 이차함수의 그래프에서 근은 y = ax² + bx + c가 x축과 만나는 점이다. D의 부호는 만나는 점이 2개, 1개, 0개인지를 알려 준다.

    이차방정식은 바빌로니아 쐐기문자 점토판에서 이미 다루어졌고 초기 방법은 기하학적이었다. 브라마굽타(Brahmagupta, 628년경)의 『브라마스푸타싯단타』는 한 근을 구하는 일반적 방법을 말로 적었고, 9세기 페르시아의 알콰리즈미는 이차방정식을 대수적으로 풀었다. 모든 경우를 포괄하는 공식은 1594년 시몬 스테빈이 처음 얻었고, 데카르트의 『기하학』(1637)에 오늘날 쓰는 형태의 특수한 경우들이 실렸다.

    예시로 보기

    세 경우를

    방정식D근
    x² − 5x + 6 = 01x = 2, 3
    x² − 4x + 4 = 00x = 2 (중근)
    x² + 2x + 5 = 0−16x = −1 ± 2i

    수치 계산에서는 주의할 점이 있다. x² − 10⁸x + 1 = 0의 작은 근은 참값이 약 10⁻⁸인데, 공식을 그대로 쓰면 두 값이 거의 같은 수를 빼는 과정에서 유효숫자가 사라져 부동소수점(배정밀도) 계산 결과가 약 7.45×10⁻⁹로 나온다. 큰 근을 먼저 구하고 두 근의 곱 c/a를 이용해 작은 근을 구하면 10⁻⁸을 얻는다(근 구하는 안정적 방법).

    자주 하는 오해

    오해바로잡기
    a = 0이어도 공식을 쓸 수 있다.a = 0이면 일차방정식이 되고 분모가 0이 되어 공식을 쓸 수 없다.
    D < 0이면 해가 없다.실수 범위에서만 해가 없다. 복소수 범위에서는 항상 두 근이 있다.
    ±는 한쪽만 고르면 된다.두 부호를 각각 계산해야 두 근이 나온다.
    컴퓨터로 공식을 그대로 구현해도 항상 정확하다.b²이 4ac보다 훨씬 클 때 상쇄 오차가 커져 안정적인 변형식이 필요하다.
    b의 부호를 −b 대신 b로 쓴다.공식의 분자 첫 항은 −b이다. 부호를 틀리면 근이 반대로 나온다.

    b² ≫ 4|ac|여서 |b| ≈ √D일 때는 −b와 ±√D가 서로 지우는 쪽 근의 뺄셈에서 유효숫자가 크게 사라지는 상쇄가 일어난다. 근호가 분모에 오는 변형식을 쓰거나 b의 부호에 따라 식을 골라 쓰면 이를 피할 수 있고, 비에타의 관계 x₁x₂ = c/a로 정확한 다른 근을 복원할 수도 있다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "최적화 문제의 임계점은 근의 공식을 이용해 해석적으로 구할 수 있으며, 이는 수치해석 알고리즘의 초기값 설정에 활용되었다."

    공학이나 물리학 논문에서 이차식으로 표현되는 모델(포물선 운동, 회로 방정식 등)의 해를 구할 때, 근의 공식은 복잡한 수치 계산 없이 정확한 해를 얻는 기초 도구로 언급된다.

    "RLC 회로의 특성방정식이 이차식으로 유도되어, 근의 공식을 적용해 감쇠 진동의 두 고유근을 해석적으로 도출하였다."

    전기회로 해석에서 회로를 나타내는 식이 이차방정식 형태가 되었고, 이를 근의 공식으로 풀어 회로가 어떻게 진동하며 감쇠하는지를 결정하는 두 값을 구했다는 뜻이다.

    "이차 손실함수의 최소값 조건을 근의 공식을 통해 도출하여, 폐형(closed-form) 해를 제시하였다."

    기계학습이나 통계 모형에서 손실함수가 이차식 형태일 때, 반복 계산 없이 근의 공식으로 곧바로 정확한 최적해를 구할 수 있었다는 의미이다.

    조금 더 깊게 보면

    근의 공식에서 √(b²-4ac) 항의 판별식이 음수이면 두 근은 서로 켤레인 복소수가 되며, 이는 진동계에서 감쇠진동(oscillatory decay)이 나타나는 조건과 대응된다. 실제 수치 계산에서는 b와 √(b²-4ac)의 값이 비슷해 두 항이 서로 상쇄되면서 부동소수점 오차가 커지는 "재앙적 상쇄(catastrophic cancellation)" 문제가 생길 수 있어, 수치해석 분야에서는 근의 공식을 변형한 대안적 계산식을 함께 다루기도 한다.

    주의할 점

    근의 공식 안의 b²-4ac 값(이차방정식의 판별식)이 음수이면 실수 범위에서는 해가 존재하지 않고, 대신 복소수 해를 갖게 된다. 판별식의 부호만 봐도 실제로 근을 다 구하지 않고도 해의 개수를 알 수 있다.
