    번스타인코드이론 (Bernstein's Code Theory)

    교육학
    한 줄 정의: 번스타인이 제시한 이론으로, 사회계층에 따라 사용하는 언어 코드의 유형이 다르며 이것이 학교 학습에서의 성공과 실패에 영향을 미친다고 본다.

    쉽게 풀면

    자라난 가정환경에 따라 말하는 방식이 다르고, 학교에서 요구하는 말투와 비슷한 방식을 쓰는 아이가 더 유리하다는 이론이다.

    논문에서는 이렇게 쓰입니다

    "노동계급과 중산층 가정 아동의 언어 사용 양상을 번스타인코드이론에 기반해 비교분석하였다."

    정교화코드와 제한코드의 구분을 통해 계급별 언어사회화와 학업성취의 관계를 설명하는 대표적 교육사회학 이론이다.

    주의할 점

    노동계급의 언어를 '결핍된 것'으로 낙인찍는 방식으로 오용되지 않도록 코드 개념이 언어능력의 우열이 아님을 유의해야 한다.
