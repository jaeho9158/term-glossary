    과업분석 (task analysis)

    디자인학
    한 줄 정의: 사용자가 목표를 달성하기 위해 수행하는 일련의 행동과 의사결정 단계를 세분화하여 분석하는 기법이다.

    쉽게 풀면

    사람이 어떤 일을 할 때 어떤 순서로 어떤 행동을 하는지 하나하나 나누어서 자세히 살펴보는 분석 방법이에요. 그래서 사람들이 놓치기 쉬운 중간 단계까지 하나하나 적어서 살펴보는 거예요. 그래서 사용자가 목표를 이루기까지 거치는 과정을 하나하나 순서대로 적어 보는 거예요.

    왜 중요한가

    과업분석은 사용자가 목표를 달성하기 위해 수행하는 세부 행동 단계를 체계적으로 분해해 각 단계에서의 인지적, 신체적 부담을 파악하는 기법으로, 인터페이스 설계 전 사용자의 실제 작업 흐름을 이해하는 기초 자료로 활용된다. 계층적 과업분석(HTA) 같은 표준화된 표기법이 산업 현장에서 흔히 쓰인다. 사용자가 목표를 이루기 위해 실제로 거치는 단계를 세분화해 설계에 반영하는 기초 자료가 된다.

    논문에서는 이렇게 쓰입니다

    "과업분석 결과 사용자가 목표 화면에 도달하기까지 평균 7단계의 조작이 필요한 것으로 나타났다."

    사용자의 조작 단계를 세분화해 과도한 단계 수라는 문제를 정량적으로 파악한 분석 결과이다.

    과업분석은 신규 시스템 설계 초기 단계에서 사용자 요구사항을 구체화하는 도구로도 활용된다.

    실제 사용자가 목표를 이루기까지 거치는 절차를 미리 파악해 설계에 반영하는 데 쓰인다는 의미이다.

    조금 더 깊게 보면

    과업분석이 관찰이나 인터뷰 없이 설계자의 추측만으로 이뤄지면 실제 사용자의 행동과 괴리된 결과를 낳을 수 있어 현장 관찰 데이터와 결합하는 것이 권장된다. 태스크플로우가 특정 과업의 화면 간 이동 경로를 다룬다면 과업분석은 그 과업을 구성하는 인지·행동적 단계 자체를 더 세밀하게 분해한다는 점에서 층위가 다르다. 과업분석은 사용자가 목표에 이르는 단계를 순서도 형태로 세분화하는데, 이 과정에서 겉으로 드러나지 않는 판단 지점이나 예외 분기까지 함께 기록해야 실제 사용 흐름을 놓치지 않는다. 계층적 과업분석은 큰 목표를 하위 목표로, 다시 구체적 행동으로 쪼개어 트리 구조로 정리하는 대표적 표기 방식이다.

    주의할 점

    과업분석은 관찰된 절차적 행동에 집중하는 경향이 있어, 사용자의 감정이나 동기와 같은 비절차적 요소는 별도의 방법으로 함께 파악해야 한다. 분석 결과를 문서로만 남기고 실제 설계에 반영하지 않으면 조사 자체가 무의미해질 수 있다. 과업분석은 이상적인 행동 순서만 다루기 쉬워 실제 사용자의 우회 행동이나 예외 상황을 놓칠 수 있다.
