    코드분할다중접속 (Code Division Multiple Access)

    전기전자공학
    한 줄 정의: 여러 사용자에게 서로 구별되는 고유한 확산 코드를 부여하여 동일한 시간과 주파수 대역을 동시에 공유하도록 하는 다중접속 방식입니다.

    쉽게 풀면

    코드분할다중접속은 여러 사람이 같은 방에서 동시에 대화해도, 각자 다른 언어를 쓰면 자신의 언어를 아는 사람만 알아들을 수 있는 것과 비슷한 원리입니다. 여기서 "언어"에 해당하는 것이 사용자마다 부여되는 고유한 코드 시퀀스입니다. 신호를 보낼 때 이 코드를 곱해 넓은 대역으로 퍼뜨리고, 받을 때는 같은 코드를 다시 곱해 원래 신호만 골라내는 방식입니다.

    왜 중요한가

    시간이나 주파수를 물리적으로 나누지 않고도 여러 사용자가 동시에 통신할 수 있어 주파수 자원을 유연하게 활용할 수 있으며, 이런 특성 때문에 초기 이동통신 표준과 위성통신, GPS 신호 방식 등에서 다뤄지는 핵심 다중접속 기술입니다.

    논문에서는 이렇게 쓰입니다

    "제안된 CDMA 시스템에서는 직교 코드 대신 준직교 코드를 사용하여 사용자 수용 용량을 증대시켰다."

    서로 다른 사용자를 구분하는 코드를 개선해 더 많은 사용자를 동시에 수용할 수 있게 했다는 뜻입니다.

    "본 연구는 CDMA 환경에서 다중 사용자 간섭을 제거하기 위한 수신기 구조를 제안한다."

    여러 사용자의 신호가 섞여 발생하는 간섭 문제를 줄이는 수신기 설계를 다뤘다는 의미입니다.

    조금 더 깊게 보면

    각 사용자에게 배정되는 확산 코드는 서로 직교하거나 상관성이 매우 낮게 설계되어, 수신기에서 특정 사용자의 코드로 역확산(despreading)을 하면 다른 사용자의 신호는 잡음처럼 낮게 퍼지고 원하는 신호만 상대적으로 커집니다. 사용자 수가 늘어날수록 코드 간 간섭이 누적되는 다중접속 간섭(MAI) 문제가 발생할 수 있어, 이를 줄이기 위한 다양한 수신기 기법이 연구됩니다.

    주의할 점

    코드 간 상관성이 완벽히 0이 아닌 경우가 많아 사용자 수가 증가하면 간섭이 누적되어 용량이 이론치보다 낮아질 수 있으며, 이는 다중경로 채널에서 특히 두드러집니다.
