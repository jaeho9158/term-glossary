    대칭좌표법 해석 (Symmetrical Components Analysis)

    전기전자공학
    한 줄 정의: 불평형 3상 전압·전류를 정상분, 역상분, 영상분이라는 세 가지 균형 잡힌 성분으로 분해하여 비대칭 고장이나 불평형 상태를 계산하는 전력계통 해석 기법입니다.

    쉽게 풀면

    정상적인 3상 전기는 세 개의 파형이 똑같은 크기로 120도씩 어긋나며 나란히 흐르는 상태입니다. 그런데 한 상만 땅에 닿는 것 같은 고장이 나면 세 파형이 더 이상 균형을 이루지 못해 계산이 복잡해집니다. 대칭좌표법은 이렇게 뒤죽박죽인 불평형 파형을 수학적으로 세 가지 '균형 잡힌 성분'으로 나누어, 각각을 따로 계산한 뒤 다시 합치는 방법입니다. 마치 복잡한 화음을 여러 개의 단순한 음으로 쪼개서 분석하는 것과 비슷합니다.

    왜 중요한가

    실제 전력계통 고장의 대부분은 한 상만 지락되거나 두 상만 단락되는 등 비대칭적으로 발생하기 때문에, 이를 정확히 계산하려면 대칭좌표법이 필수적입니다. 보호계전기 정정, 고장전류 계산, 불평형 부하 해석 등 폭넓은 연구와 실무에서 기본 도구로 사용됩니다.

    논문에서는 이렇게 쓰입니다

    "The fault current for a single line-to-ground fault is calculated using symmetrical components analysis."

    1선 지락고장의 고장전류를 대칭좌표법 해석으로 계산했다는 뜻입니다.

    "Negative-sequence current derived from symmetrical components is used to detect unbalanced loading conditions."

    대칭좌표법으로 구한 역상분 전류를 이용해 불평형 부하 상태를 검출한다는 설명입니다.

    조금 더 깊게 보면

    대칭좌표법은 정상분(세 상이 정상 순서로 균형을 이루는 성분), 역상분(반대 순서로 균형을 이루는 성분), 영상분(세 상이 모두 같은 크기와 위상을 갖는 성분)으로 구성됩니다. 고장 종류(1선 지락, 선간단락, 2선 지락 등)에 따라 이 세 성분이 서로 연결되는 방식이 달라지며, 이를 이용해 각 고장 유형별 전류와 전압을 유도합니다.

    주의할 점

    대칭좌표법은 계통이 선형이고 3상 대칭 구조를 갖는다는 가정 위에서 성립하는 기법으로, 비선형 소자가 많은 최신 전력전자 기반 계통에서는 적용에 한계가 있을 수 있습니다.

    관련 용어
