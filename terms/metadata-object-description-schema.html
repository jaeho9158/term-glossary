    MODS메타데이터스키마 (Metadata Object Description Schema)

    메타데이터 스키마›MODS메타데이터스키마
    문헌정보학
    한 줄 정의: 미국의회도서관이 개발한 XML 기반 서지메타데이터 표준으로, MARC의 상세함과 더블린코어의 단순함 사이에서 절충점을 제공하며 디지털 자원을 기술하는 데 널리 활용된다.

    쉽게 풀면

    MARC보다는 간단하고 더블린코어보다는 자세한, XML로 만든 서지메타데이터 표준이다.

    왜 중요한가

    MODS는 MARC의 풍부한 서지 정보를 사람이 읽을 수 있는 XML 요소 이름으로 표현하는 스키마로, 더블린코어보다 상세하고 MARC보다 다루기 쉬운 중간 지점을 제공해 디지털도서관 프로젝트와 METS 패키지의 기술 메타데이터로 널리 채택되었다. 디지털 리포지터리를 운영하는 기관이 MARC의 세밀함을 완전히 포기하지 않으면서도 XML 기반 웹 환경에 맞는 메타데이터를 원할 때, MODS는 이 둘 사이의 실용적인 절충점을 제공한다.

    핵심 정리

    • MODS는 미국 의회도서관이 2002년에 도입한 XML 기반 서지 스키마이다.
    • 3.8판이 2022년 9월에 나왔고 현재 판이다.
    • MARC의 복잡성과 더블린코어의 단순함 사이의 절충으로 만들어졌다.
    • 숫자 태그 대신 언어 기반 태그를 쓴다.

    형식복잡도태그
    MARC복잡하다세 자리 숫자 태그
    MODS중간언어 기반 태그(XML)
    더블린코어단순하다-

    미국 의회도서관의 네트워크 개발 및 MARC 표준 사무소가 MODS를 유지·관리한다.

    자주 하는 오해

    오해바로잡기
    MARC를 MODS로 바꿔도 정보가 그대로 남는다.변환할 때 MARC의 일부 데이터가 사라진다.
    MODS는 더 이상 갱신되지 않는다.3.8판이 2022년 9월에 나왔고 현재 판이다.

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    본 연구는 디지털 리포지터리 구축 시 MODS메타데이터스키마 채택이 MARC 레코드와의 상호 변환 용이성 때문이라고 분석하였다.

    MODS가 MARC와 쉽게 변환될 수 있어 디지털 리포지터리에서 채택되었다는 점을 분석한 문장이다.

    디지털도서관 연구는 MODS메타데이터스키마가 MARC보다 다루기 쉬우면서도 더블린코어보다 상세한 서지 기술을 가능하게 한다고 보고했다.

    이 연구는 MODS가 기관 리포지터리 간 메타데이터 교환의 실무 표준으로 자리잡아가는 과정을 분석했다.

    조금 더 깊게 보면

    MODS는 MARC에서 변환할 때 일부 세부 정보가 손실되고(역변환도 완전하지 않음), MARC 관행에 기반하므로 MARC의 개념적 한계를 일부 물려받는다. 미의회도서관이 BIBFRAME에 무게를 옮기면서 장기 유지관리 방향이 관심사가 되고 있다. 더블린코어가 15개의 평면적 요소로만 구성된 것과 달리, MODS는 하나의 레코드 안에 관련 자료나 구성 부분을 중첩된 하위 구조로 표현할 수 있어 총서나 다권본처럼 위계를 가진 자료를 기술하는 데 더 유리하다.

    주의할 점

    MODS메타데이터스키마는 MARC의 모든 세부 필드를 완전히 대응시키지는 못하므로, 변환 과정에서 일부 정보 손실이 발생할 수 있다는 점에 유의해야 한다.

    MODS는 요소 이름이 사람이 읽기 쉽게 지어져 있지만 그 의미가 MARC 필드의 세부 규칙을 완전히 반영하지는 않으므로, MARC에서 변환할 때 특정 하위필드의 미묘한 의미 차이가 뭉뚱그려질 수 있다는 점을 감안해야 하며, 원본 MARC 레코드를 함께 보존해 두는 것이 바람직하다.
