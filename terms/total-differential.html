    전미분 (Total Differential)

    미분›편미분›전미분
    수학

    ✓ 출처 대조 2026-11-08

    한 줄 정의: 변수가 여러 개인 함수에서, 각 변수가 아주 조금씩 변할 때 함수값 전체가 얼마나 변하는지를 한 번에 더해서 나타낸 식이다.

    쉽게 풀면

    직사각형의 넓이 z = xy를 생각해보자. 가로 x와 세로 y가 둘 다 아주 조금씩 변한다면, 넓이는 얼마나 변할까? 가로가 변해서 생기는 변화량과 세로가 변해서 생기는 변화량을 각각 따로 계산한 뒤 더하면 된다. 이걸 수식으로 쓴 것이 전미분이며, dz = (∂z/∂x)dx + (∂z/∂y)dy로 표현한다. 여기서 ∂z/∂x, ∂z/∂y는 각각 x, y 하나만 바꿀 때의 변화율(편미분)이고, 전미분은 이 개별 변화율들을 전부 합쳐서 "모든 변수가 동시에 조금씩 바뀔 때 전체가 얼마나 변하는지"를 알려준다. 즉 부분(편미분)들을 다 모은(전체) 미분이라서 '전(全)미분'이다.

    왜 중요한가

    여러 변수가 동시에 조금씩 바뀔 때 전체 결과가 어떻게 변하는지를 다루는 문제는 경제학의 한계효과 분해, 물리학·공학의 오차 전파 및 민감도 분석, 열역학의 상태함수 변화량 계산 등 다양한 분야에서 공통적으로 나타나기 때문에, 전미분은 여러 학문에서 다변수 함수의 변화를 다루는 표준 도구로 쓰인다.

    핵심 정리

    두 변수 함수 f(x, y)의 전미분은 df = fx dx + fy dy이다. 편미분 fx, fy는 다른 변수를 고정한 채 한 변수만 바꿀 때의 변화율이고, 전미분은 모든 변수의 아주 작은 변화를 함께 반영해 합친 것이다. n개의 변수라면 각 변수의 편미분 항을 모두 더한다. 함수가 미분 가능하면 실제 증분 Δf는 df와 가깝고, 증분이 작을수록 오차가 상대적으로 작아진다. 즉 전미분은 변화의 선형 근사 부분이다.

    변수들이 t에 의존하면 연쇄 법칙으로 dz/dt = (∂f/∂x)(dx/dt) + (∂f/∂y)(dy/dt)가 된다. 편미분이 한 점에서 모두 존재한다고 해서 미분 가능한 것은 아니지만, 주변에서 존재하고 그 점에서 연속이면 미분 가능하다.

    예시로 보기

    f(a, b) = ab이면 fa = b, fb = a이므로 Δf ≈ b·Δa + a·Δb이다. 양변을 f = ab로 나누면 Δf/f = Δa/a + Δb/b가 되어 상대 오차가 더해진다. a = 2, b = 5(f = 10)에서 Δa = 0.01, Δb = 0.02이면 Δf ≈ 5(0.01) + 2(0.02) = 0.09로 상대 오차는 약 0.9%이다.

    상황쓰는 식
    오차의 한계만 알 때|Δf| ≤ |fx|δx + |fy|δy
    독립 오차의 표준편차를 알 때σf2 = fx2σx2 + fy2σy2

    자주 하는 오해

    • 전미분과 전도함수를 같은 것으로 보기 쉽다. 예를 들어 f(x, y) = xy에서 y = x로 놓으면 편미분 ∂f/∂x는 y이지만 전도함수 df/dx는 2x이다. x가 바뀌면 y도 함께 바뀌기 때문이다.
    • 편미분들의 합이라고만 기억하기 쉽다. 각 편미분에 해당 변수의 작은 변화(dx, dy)를 곱해서 더해야 한다.
    • 열역학의 dU = T dS − P dV 같은 식은 상태함수의 전미분인데, 이때는 완전성(exactness)이 따로 문제가 된다.

    실제 논문에서

    국내 학술지 논문에서 이 용어가 쓰인 문장을 그대로 옮겼다. 제목·학술지·연도와 원문 링크를 함께 적었다.

    • “아울러, 본 연구는 평균값 정리를 이용하여 함수값 변화에 대한 전미분 분해를 새롭게 개발했는데, 한계성과 일관성을 갖추고 있어 실효관세율 변화에 적용했다.”

      한국의 對캐나다 수출실효관세율 요인분해, 관세학회지, 2020 · KCI 한국학술지인용색인 · 원문 보기 ↗

    조금 더 깊게 보면

    전미분이 실제로 존재하려면 편도함수가 각 점에서 존재하는 것만으로는 부족하고, 그 편도함수들이 연속이거나 함수가 해당 점에서 미분가능(differentiable)해야 한다는 더 강한 조건이 필요하다. 이 조건이 성립하지 않는 함수는 편미분값이 개별적으로 존재해도 전미분으로 근사한 값이 실제 변화량과 크게 어긋날 수 있다. 오차 전파 계산에서는 전미분의 각 항을 제곱해 더하는 방식(제곱합의 제곱근)으로 독립적인 오차들을 합성하는 경우가 많다는 점도 논문을 읽을 때 참고할 만하다.

    주의할 점

    전미분은 각 변수의 변화가 "아주 작을 때(무한소)"만 정확히 성립하는 근사식이다. 변화량이 크면 편미분값이 그 사이에서 계속 바뀌므로 단순히 더하는 방식은 오차가 커진다. 또한 전미분이 존재하려면 함수가 해당 지점에서 매끄럽게(미분가능하게) 정의되어 있어야 하며, 편도함수가 각각 존재한다고 해서 자동으로 전미분이 존재하는 것은 아니다.
