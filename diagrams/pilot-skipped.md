# 파일럿 — 도식화하지 않은 후보

- iba-1, gfap, myelin-basic-protein, synaptotagmin — 단일 분자/표지자 명칭, 구조 없음 (분자 도메인 그림 템플릿이 있으면 가능)
- glia-neuron-ratio, ampa-nmda-ratio — 수치 비율 (막대/비율 게이지 템플릿이 있으면 가능)
- mipsc, miniature-excitatory-postsynaptic-current, field-excitatory-postsynaptic-potential, paired-pulse-ratio — 파형 자체가 핵심 (전기생리 파형 템플릿 필요)
- spike-timing-dependent-plasticity — 시점차-가중치 변화 곡선이 핵심 (x-y 곡선 템플릿 필요)
- metaplasticity — BCM 문턱 이동 곡선 (x-y 곡선 템플릿 필요)
- critical-period-plasticity, ocular-dominance-plasticity — 시간축 위 창(window) 표현 (타임라인 템플릿 필요)
- synaptic-cleft, astrocyte-endfoot, perisynaptic-astrocyte-process, bergmann-glia, dendrodendritic-synapse — 공간 배치·해부 구조 (해부 모식도/배치 템플릿 필요)
- myelination, demyelination, myelin-plasticity — 세포 위 수초 감김 형태 (해부 모식도 필요); 탈수초 기전은 질환별로 달라 단일 chain 불확실
- synaptic-cycle류 순환 구조(synaptic-vesicle-cycle은 chain으로 대체) — 원형 순환 템플릿이 있으면 더 자연스러움
- nmda-receptor-hypofunction-hypothesis — 억제성 인터뉴런 탈억제 경로가 분기·되먹임 포함 (분기 chain 템플릿 필요)
- basal-ganglia 직·간접 경로 — 억제/흥분 분기 회로 (회로도 템플릿 필요; 이번엔 구성 hierarchy로만 작성)
- hippocampal-replay, synaptic-clustering, synaptic-turnover, synaptogenesis — 시간적 패턴·공간 분포 (시계열/산점 템플릿 필요)
- ng2-glia, radial-glia-guided-migration — 계통 분화 + 이동 단계가 섞임 (계통수+단계 혼합 템플릿)
- neuronal-autophagy, maladaptive-plasticity, inhibitory-synaptic-plasticity, activity-dependent-synaptic-refinement, experience-dependent-plasticity — 범위가 넓어 단일 도식이 과단순화
- 나머지 풀 항목(synapse 계열 상위어 중복 등) — 이미 선정된 스펙과 내용 중복
