# 자연과학 스타일 가이드
## 자주 맞는 type
(검수 통과 127개 기준: chain 65, contrast 31, hierarchy 18, procedure 13. cycle·matrix·venn·timeline·plot은 0개)
- chain: 인과·반응·생성 경로. 예: 온난강수과정, 채프먼 메커니즘, 보른-하버 순환, 보웬의 반응계열.
- contrast: 두 반응·현상의 속성 대비. 예: SN1 대 SN2, 한랭전선 대 온난전선, pp 연쇄 대 CNO 순환(axis로 비교 기준 명시).
- hierarchy: 분류·종류. 예: 판의 경계 종류(발산·수렴·보존), 암석의 분류, 허블분류.
- procedure: 순서가 있는 공정·절차. 예: 정수처리공정, 하수처리공정, 재결정, 충돌 크레이터 형성.
- (v1) 순환을 chain + 되돌이 엣지로 그린 예가 있다(물의 순환, 암석의 순환) — 새로 쓸 때는 cycle을 쓴다.
## 라벨 관례
- 라벨 평균 5.5자, 대부분 10자 이내의 명사구. 설명은 sub(평균 8자)로 넘긴다.
- 화학식은 유니코드 아래·위첨자(O₂, O₃, M⁺(g), e⁻)와 → 로 쓰고 상태기호 (s)(g)를 붙인다. 반응은 라벨에 식, sub에 의미("오존 생성").
- 단위·수치는 sub에 짧게(예: "~10 µm", "중심 약 1500만 K", "약 1.3 태양질량 이상"). 정확한 수치가 불확실하면 "약"을 붙인다.
- 영문 약어는 용어명 그대로 쓴다(SN1, pp, CNO, NOx). 인명은 한글 표기(보웬, 헬름홀츠), 연도는 source에만 둔다.
- contrast는 머리 행에 대비 대상명, 아래 행은 같은 속성을 좌우 같은 순서로 맞춘다.
## 색 쓰는 법
- blue: 주체·기본 대상(구름방울 응결, 한랭전선 머리, 판의 경계 루트, 금속 승화).
- violet: 방법·매개·신호(광분해 단계, 중간체, 변환단층, 열·압력).
- amber: 외부 요인·입력·개입(증발, 이온화, 풍화·퇴적, 고질량 항성의 촉매).
- green: 바람직·최종 생성물(강수·유출, 오존 생성, 격자 형성, 발산형 새 지각).
- rose: 소멸·위험·고에너지 상태(오존 소멸, 마그마, 수렴형, 감람석 고온 정출). 가치 판단이 아니라 파괴·강한 변화에 쓴다.
- gray: 약한·기준 쪽(온도 의존 약함, 지속적 약한 강수). 좌우 contrast에서는 같은 속성 행에 같은 색을 맞춘다.
- mode 필드는 쓰지 않는다(bio 모드는 이 분야에서 0건).
## 피할 것
- 교과서의 이상화 모형을 보편 법칙처럼 단정: 보웬 계열은 "건조한 현무암질 마그마의 이상화 모형", 채프먼은 "NOx·Cl 촉매 파괴를 더해야 설명" 같은 limit 노트로 한계를 단다(limit 노트 72개, pos 3개).
- 단방향 화살표로 실제의 상호 전환·병행 경로를 가림: 암석 순환은 "어느 암석이든 서로 바뀔 수 있음", 판 경계는 "경사 이동도 흔함", 보웬은 연속 계열 병행을 노트로 보강.
- 부호·방향 혼동(흡열·발열, 엔탈피)은 "부호 관례를 일관되게 표기"처럼 명시하고 임의로 바꾸지 않는다.
- 연속적 크기·온도 범위를 날카로운 경계값으로 단정하지 말고 "약"·범위로 쓴다.
- 4~5개를 넘는 노드에 sub를 모두 채워 길게 만들기(보른-하버 5노드가 상한 수준).
## v2 새 type
- 위 관찰은 cycle·matrix·venn·timeline·plot이 생기기 전 스펙 기준이다. 새로 쓸 때는 README의 9개 type 중 개념에 가장 맞는 것을 고른다.
- 물·암석·탄소 순환처럼 끝이 처음으로 돌아오는 과정은 이제 **cycle**로 쓴다(기존 chain+되돌이 엣지 방식은 v1 제약 때문). 감쇠·지수 증가·S자 반응은 plot.
## 좋은 예
- warm-rain-process: 4노드 chain, 역할색(blue 응결, violet 충돌병합, amber 성장, green 강수)이 의미와 맞고, 노트 하나로 "빙정 없이" 적용 범위를 한정.
- bowens-reaction-series: 5노드에 고온·저온 sub를 양 끝에만 두고, general 노트(연속 계열)와 limit 노트(이상화 모형)를 함께 달아 단순화를 스스로 밝힘.
