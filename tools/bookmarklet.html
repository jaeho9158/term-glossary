    선택한 단어 사전에서 찾기

    논문이나 기사를 읽다가 모르는 단어를 만났을 때, 마우스로 단어를 선택하고 버튼 하나만 누르면 논문용어사전에서 바로 찾아 볼 수 있습니다. 별도 프로그램이나 로그인은 필요 없고, 한 번만 설정해 두면 됩니다.

    1단계: 아래 버튼을 북마크 막대로 끌어다 놓기

    선택한 단어 찾기

    위 버튼을 마우스로 잡아서 브라우저 맨 위의 북마크 막대(즐겨찾기 막대)에 끌어다 놓으세요. 북마크 막대가 보이지 않으면 Ctrl + Shift + B(맥은 Command + Shift + B)를 눌러 켤 수 있습니다. 이 페이지에서 버튼을 직접 누르면 단어 입력창이 뜨는데, 설정이 잘 되었는지 시험해 볼 때 쓰세요.

    2단계: 사용하기

    1. 아무 웹페이지에서 모르는 단어를 마우스로 드래그해 선택합니다.
    2. 북마크 막대의 선택한 단어 찾기를 클릭합니다.
    3. 새 탭에서 논문용어사전이 열리고, 선택한 단어의 검색 결과가 바로 나타납니다.

    선택한 글자가 없으면 단어를 직접 입력하는 창이 뜹니다. 선택한 글은 60자까지만 사용되며, 이 사이트로 보내는 것은 검색어뿐입니다.

    참고

    • 일부 보안이 강한 사이트(은행, 일부 PDF 뷰어 등)에서는 브라우저가 북마클릿 실행을 막을 수 있습니다. 그럴 때는 단어를 복사해서 사전 검색창에 붙여 넣어 주세요.
    • 휴대폰 브라우저는 북마클릿 지원이 제한적이라, 컴퓨터에서 쓰시기를 권합니다.
    • 북마크 막대에 추가한 뒤 이름은 얼마든지 바꿔도 됩니다.
