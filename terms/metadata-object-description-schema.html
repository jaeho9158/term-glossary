    MODS메타데이터스키마 (Metadata Object Description Schema)

    문헌정보학
    한 줄 정의: 미국의회도서관이 개발한 XML 기반 서지메타데이터 표준으로, MARC의 상세함과 더블린코어의 단순함 사이에서 절충점을 제공하며 디지털 자원을 기술하는 데 널리 활용된다.

    쉽게 풀면

    MARC보다는 간단하고 더블린코어보다는 자세한, XML로 만든 서지메타데이터 표준이다.

    논문에서는 이렇게 쓰입니다

    본 연구는 디지털 리포지터리 구축 시 MODS메타데이터스키마 채택이 MARC 레코드와의 상호 변환 용이성 때문이라고 분석하였다.

    MODS가 MARC와 쉽게 변환될 수 있어 디지털 리포지터리에서 채택되었다는 점을 분석한 문장이다.

    주의할 점

    MODS메타데이터스키마는 MARC의 모든 세부 필드를 완전히 대응시키지는 못하므로, 변환 과정에서 일부 정보 손실이 발생할 수 있다는 점에 유의해야 한다.
