    REDCap

    측정·도구
    한 줄 정의: 환자·연구참여자의 임상 데이터를 안전하게 입력·저장·관리하도록 설계된, 대학·병원에서 널리 쓰이는 무료 임상연구 데이터베이스 플랫폼입니다.

    쉽게 풀면

    병원이나 임상연구에서는 환자 이름, 진단명, 검사 수치처럼 민감한 정보를 다루기 때문에, 아무 온라인 설문 도구나 함부로 쓸 수 없습니다.

    REDCap(Research Electronic Data Capture)은 이런 민감한 연구 데이터를 안전하게 담을 수 있도록 미국 밴더빌트 대학이 개발해 전 세계 대학·병원 연구기관에 무료로 배포한 데이터 입력·관리 시스템입니다.

    연구자가 직접 "환자 등록번호, 방문일, 혈압, 부작용 발생 여부" 같은 항목(변수)을 하나하나 설계해서 전자 증례기록지(eCRF)를 만들고, 여러 연구자가 같은 시스템에 동시에 접속해 데이터를 입력하면서도 접근 권한과 수정 이력을 꼼꼼히 관리할 수 있습니다.

    왜 중요한가

    REDCap은 임상연구와 관찰연구에서 자료 수집 과정을 표준화하고 감사 추적(누가 언제 무엇을 입력·수정했는지 기록)을 남길 수 있게 해주기 때문에, 연구윤리심의위원회(IRB) 심사나 논문 심사 과정에서 자료관리의 신뢰성을 보여주는 근거로 자주 언급됩니다. 여러 기관이 함께 참여하는 다기관 연구에서 동일한 형식으로 자료를 모으는 표준 플랫폼 역할을 한다는 점도 널리 채택되는 이유입니다.

    어떤 절차인가

    REDCap(Research Electronic Data Capture)은 Vanderbilt 대학이 개발한, 웹 기반 연구 자료 수집·관리 플랫폼입니다. 연구기관이 자체 서버에 설치해 연구자에게 제공하는 방식이 일반적입니다(Harris 외, 2009, 2019).

    1. 데이터 사전(변수 정의) 설계: 변수 이름, 유형(숫자·날짜·선택형), 허용 범위, 필수 여부를 정합니다. CSV 파일로 작성해 올릴 수도 있습니다.
    2. 입력 화면(instrument) 구성: 변수를 묶어 증례기록지(CRF)나 설문 화면으로 만들고, 분기 논리(앞 응답에 따라 문항 표시)와 입력 검증 규칙을 설정합니다.
    3. 시험 입력과 점검: 개발 상태에서 가상 자료를 넣어 화면·논리를 확인합니다.
    4. 운영 전환: 실제 자료 입력을 시작합니다. 이후 변수를 바꾸면 이미 쌓인 자료에 영향이 있으므로 변경 이력을 남기고 신중히 합니다.
    5. 사용자 권한 설정, 입력, 내보내기: 연구자별 접근 권한과 데이터 접근 그룹을 정하고, 자료를 CSV나 통계 프로그램용 파일(SPSS, R, SAS, Stata 등)로 내보냅니다.

    언제 쓰고 무엇을 얻나

    • 쓰임: 임상연구·코호트 연구의 증례 자료 수집, 여러 기관이 함께하는 연구, 반복 방문이 있는 종단 연구, 온라인 설문 수집.
    • 얻는 것: 변수 정의가 일관된 자료, 입력 시점의 형식·범위 점검, 사용자별 수정 이력(감사 기록), 접근 권한 관리, 정리된 내보내기 파일.
    • 한계: REDCap은 자료를 담는 틀일 뿐 자료의 질을 보장하지 않습니다. 설계 단계의 검증 규칙과 데이터관리계획이 부실하면 오입력·결측이 그대로 쌓입니다. 개인정보 보호 수준은 REDCap 자체가 아니라 그것을 설치·운영하는 기관의 보안 체계와 승인 절차(연구윤리위원회)에 달려 있습니다.

    논문에는 이렇게 적는다

    REDCap 개발자는 사용한 연구에서 두 논문을 모두 인용하도록 안내합니다(Harris 외, 2009, 2019). 아래는 방법 절에 넣는 한 예입니다.

    보고 예. “연구 자료는 본 기관에서 운영하는 REDCap(Research Electronic Data Capture) 전자 데이터 수집 도구에 입력·관리하였다(Harris 외, 2009; Harris 외, 2019).” 필요하면 사용한 입력 검증 규칙, 이중 입력 여부, 자료 정제 방법을 덧붙입니다.

    • 개인 식별 정보를 별도로 분리하거나 가명 처리했는지, 접근 권한을 누가 가졌는지도 방법 절이나 윤리 항목에 적습니다.

    논문에서는 이렇게 쓰입니다

    실제 논문에서

    이 용어를 직접 쓴 국내 논문 문장을 아직 수집하지 못했습니다. 수집되는 대로 출처와 함께 싣겠습니다.

    예시 문장

    아래는 용어의 쓰임을 보여 주려고 만든 예시로, 실제 논문에서 가져온 문장이 아닙니다.

    "모든 임상 자료는 REDCap 데이터베이스에 입력되었으며, 이중 확인 절차를 거쳐 자료의 정확성을 검증하였다."

    이 문장은 연구팀이 환자 자료를 종이 차트에서 REDCap이라는 전산 시스템으로 옮겨 입력했고, 입력 오류를 줄이기 위해 같은 자료를 두 사람이 각각 입력해 대조하는 절차까지 거쳤다는 뜻입니다.

    "다기관 코호트 연구에 참여한 모든 기관은 동일한 REDCap 프로젝트를 통해 표준화된 설문 문항으로 자료를 수집하였다."

    여러 병원이나 기관이 함께 참여하는 대규모 연구에서는 REDCap의 다기관 지원 기능을 이용해 자료 수집 양식과 절차를 통일했다는 설명이 흔히 등장합니다.

    "참여자는 REDCap의 온라인 설문 기능을 통해 스스로 삶의 질 척도를 작성하였다."

    REDCap은 연구자가 직접 입력하는 임상 자료뿐 아니라, 참여자가 스스로 응답하는 자가보고식 설문(환자보고결과) 수집 도구로도 활용됩니다.

    조금 더 깊게 보면

    REDCap은 단순한 데이터 입력 화면 이상의 기능을 제공하는데, 입력값의 범위나 형식을 강제하는 검증 규칙, 응답에 따라 다음에 보여줄 문항을 바꾸는 분기 로직, 특정 조건에서 항목을 숨기거나 표시하는 로직 등을 연구자가 코드 작성 없이 설계할 수 있습니다. 또한 데이터 사전(변수명, 유형, 허용값을 정의한 문서)을 함께 관리하기 때문에, 여러 연구자가 참여하는 프로젝트에서도 변수 정의가 일관되게 유지되도록 돕습니다.

    주의할 점

    REDCap은 데이터를 안전하게 담아 두는 그릇일 뿐, 자료의 질 자체를 보장해 주지는 않습니다. 입력값의 범위나 형식을 미리 제한하는 검증 규칙을 잘 설계해 두지 않으면 결측치 처리이나 오입력이 그대로 쌓일 수 있으므로, 데이터베이스 설계 단계부터 데이터관리계획을 세워두는 것이 중요합니다.

    헷갈리기 쉬운 용어

    같은 층위의 말이 아니어서 서로 혼동하기 쉽습니다.

    용어무엇인가REDCap과의 관계
    REDCap전자 데이터 수집 소프트웨어(플랫폼)자료를 입력·저장·관리하는 도구
    증례기록지(CRF)연구 대상자별 자료를 기록하는 서식REDCap에서 전자 형태(eCRF)로 구현
    데이터 사전변수의 이름·유형·허용값을 정의한 문서REDCap 프로젝트의 설계도 역할
    임상시험약·의료기기 등의 효과를 검증하는 연구자료 관리에 REDCap을 쓸 수 있으나, 규제 요건 충족은 별도로 확인

    참고 문헌

    1. Harris, P. A., Taylor, R., Thielke, R., Payne, J., Gonzalez, N., & Conde, J. G. (2009). Research electronic data capture (REDCap): A metadata-driven methodology and workflow process for providing translational research informatics support. Journal of Biomedical Informatics, 42(2), 377–381.
    2. Harris, P. A., Taylor, R., Minor, B. L., Elliott, V., Fernandez, M., O'Neal, L., et al. (2019). The REDCap consortium: Building an international community of software platform partners. Journal of Biomedical Informatics, 95, 103208.
