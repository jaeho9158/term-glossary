    다이제틱 UI (Diegetic UI)

    문화콘텐츠학·게임학
    한 줄 정의: 게임 세계 내부에 실재하는 오브젝트로서 표현되는 인터페이스를 말한다. 캐릭터의 손목 시계나 무기의 탄약 표시창처럼 서사적 세계관 안에 자연스럽게 통합된다.

    쉽게 풀면

    게임 화면 밖 UI가 아니라, 캐릭터의 시계나 총의 탄창처럼 게임 세계 안에 실제로 존재하는 형태로 만든 정보 표시 방식이다.

    왜 중요한가

    다이제틱 UI는 체력 게이지나 탄약 수 같은 정보를 캐릭터의 헬멧 디스플레이나 무기 자체의 물리적 표시로 구현해 게임 세계 안에 존재하는 요소처럼 보이도록 만드는 인터페이스 설계 기법으로, 데드 스페이스의 등 표시 체력바가 대표 사례로 자주 인용되며 몰입을 방해하지 않는 정보 전달을 목표로 합니다.

    논문에서는 이렇게 쓰입니다

    Fagerholt, E. & Lorentzon, M. (2009). Beyond the HUD: User Interfaces for Increased Player Immersion in FPS Games.

    이 논문은 다이제틱, 논다이제틱, 메타, 공간적 UI로 구성된 4분류 체계를 최초로 제시하여 게임 UI 연구의 표준 프레임워크가 되었다.

    조금 더 깊게 보면

    다이제틱 UI는 몰입감을 높이지만 정보 가독성이 떨어질 수 있어, 실제로는 완전한 다이제틱과 화면 오버레이인 논다이제틱 UI 사이에 메타 UI, 공간적 UI 같은 중간 단계가 존재한다는 것이 다이제틱 인터페이스 분류 연구에서 세분화되어 있습니다.

    주의할 점

    다이제틱 UI는 몰입감은 높이지만 정보 전달의 명료성과 접근성이 떨어질 수 있어 장르와 목적에 따라 신중히 선택해야 한다.
