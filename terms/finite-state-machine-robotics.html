    유한상태기계 (Finite State Machine (Robotics))

    로봇공학
    한 줄 정의: 로봇의 동작을 유한한 개수의 상태와 상태 간 전이 조건으로 모델링하여 행동을 제어하는 고전적인 행동 관리 기법.

    쉽게 풀면

    로봇의 행동을 '대기', '이동', '작업 중'과 같은 몇 가지 상태로 나누고, 어떤 조건이 되면 다른 상태로 넘어가도록 정해놓는 방법입니다.

    논문에서는 이렇게 쓰입니다

    유한상태기계는 상태 집합 S, 입력 집합 Σ, 전이 함수 δ: S × Σ → S로 정의되며, 현재 상태와 입력에 따라 결정적으로 다음 상태가 결정된다.

    지금 어떤 상태에 있는지와 어떤 신호가 들어왔는지만 알면 다음에 어떤 상태로 바뀔지가 정확히 정해진다는 뜻입니다.

    주의할 점

    상태 수가 많아지면 전이 규칙이 기하급수적으로 늘어나는 상태 폭발 문제가 발생해 관리가 어려워집니다.
