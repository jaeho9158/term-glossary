    부분분수분해 (Partial Fractions)

    수학
    한 줄 정의: 분모가 여러 인수로 곱해진 복잡한 분수식을, 분모가 각각 하나씩인 더 간단한 분수들의 합으로 쪼개는 방법이다.

    쉽게 풀면

    1/2 + 1/3을 하나의 분수 5/6으로 합치는 것은 학교에서 배운 통분이다. 부분분수분해는 이 과정을 거꾸로 되돌리는 것과 비슷하다. 예를 들어 분모가 (x-1)(x+2)처럼 여러 인수의 곱으로 되어 있는 복잡한 분수식을 A/(x-1) + B/(x+2) 형태의 더 단순한 분수 두 개의 합으로 쪼개는 것이다. 왜 이렇게 나눌까? 복잡하게 합쳐진 분수는 그대로 적분하기 어렵지만, 단순한 분수 하나하나는 적분 공식이 이미 잘 알려져 있어서 훨씬 쉽게 계산할 수 있기 때문이다.

    왜 중요한가

    부분분수분해는 그 자체로 새로운 이론을 만든다기보다, 복잡한 유리함수를 다루기 쉬운 형태로 바꿔주는 실용적인 계산 도구이기 때문에 여러 응용 분야에서 폭넓게 쓰인다. 특히 제어이론과 신호처리에서는 라플라스 변환이나 Z변환의 역변환을 구할 때 거의 필수적으로 거치는 단계이며, 확률론에서 생성함수를 분석할 때도 활용된다. 복잡한 수식을 단순한 항들의 합으로 바꾸는 이 전략은 적분뿐 아니라 급수 전개, 극한 계산 등 다른 수학적 절차의 기초로도 자주 쓰인다.

    어떤 절차인가

    1. 분자의 차수가 분모의 차수 이상이면 먼저 나눗셈으로 다항식 부분을 떼어 낸다.
    2. 분모를 기약인수로 분해한다.
    3. 중복된 인수는 낮은 차수의 항을 모두 포함한다. 예를 들어 A/(x−α) + B/(x−α)² + …처럼 쓴다.
    4. 계수는 계수비교, 치환, 잔여(residue)법 또는 극한법으로 정한다.

    언제 쓰고 무엇을 얻나

    부분분수분해는 유리식을 분모가 더 간단한 분수들의 합(다항식 몫 + 여러 분수)으로 나타내는 방법이다. 분모는 기약다항식의 거듭제곱 꼴이고, 각 분자의 차수는 해당 분모보다 낮다.

    분모가 서로 다른 단순근을 가질 때는 각 근 xᵢ에 대한 계수를 a = P(xᵢ)/Q′(xᵢ)로 바로 구할 수 있다. 예를 들어 1/((x−1)(x+2))에서 P = 1, Q = x²+x−2, Q′ = 2x+1이므로 x = 1의 계수는 1/3, x = −2의 계수는 −1/3이다.

    쓰이는 곳은 부정적분(로그 항으로 적분), 라플라스 변환과 역변환, Z변환, 테일러 급수, 컴퓨터 대수이다. 이 방법은 요한 베르누이와 라이프니츠가 1702년에 서로 독립적으로 발견했다.

    논문에는 이렇게 적는다

    풀이 과정을 적을 때는 분모를 어떤 인수로 나누었는지, 중복 인수의 항을 어디까지 두었는지, 계수를 어느 방법으로 정했는지를 함께 적는다. 예를 들면 “분모를 인수분해한 뒤 부분분수로 분해하여 각 항을 역변환하였다.”와 같이 쓴다. 이 문장은 쓰임을 보이려고 만든 예시이다.

    논문에서는 이렇게 쓰입니다

    예시 문장

    아래 예문은 용어의 쓰임을 보이려고 만든 것으로, 실제 논문 문장이 아니다.

    "전달함수의 라플라스 역변환을 구하기 위해 유리함수를 부분분수분해(partial fraction decomposition)한 뒤 각 항을 개별적으로 변환하였다."

    이 문장은 복잡한 분수 형태의 함수를 그대로 다루기 어려우니, 이를 여러 개의 단순한 분수 항으로 쪼갠 다음 각 항에 이미 알려진 변환 공식을 적용해서 최종 결과를 얻었다는 뜻이다. 전자공학의 회로 해석, 제어이론의 시스템 응답 분석 논문에서 흔히 등장하는 절차이다.

    "이산 확률변수의 확률생성함수를 부분분수분해하여 각 항의 급수 전개로부터 확률질량함수를 직접 도출하였다."

    확률론에서 부분분수분해가 생성함수를 통해 확률분포를 구하는 데 활용되는 예문이다.

    "디지털 필터의 전달함수를 부분분수분해하여 병렬 구조의 필터 뱅크로 구현함으로써 계산 효율을 높였다."

    신호처리 및 디지털 회로 설계에서 부분분수분해가 시스템 구현 방식에 활용되는 사례다.

    조금 더 깊게 보면

    부분분수분해는 분모의 인수가 서로 다른 일차식인지, 중근을 가진 일차식인지, 아니면 실수 범위에서 더 이상 인수분해되지 않는 이차식인지에 따라 분해되는 항의 형태가 달라진다. 예를 들어 중근을 가진 인수는 차수가 올라갈수록 여러 항으로 나뉘어 표현되고, 인수분해되지 않는 이차식은 분자가 일차식(Bx+C 꼴)인 항으로 처리된다. 논문에서 부분분수분해가 등장할 때는 분모가 어떤 형태의 인수들로 이루어져 있는지, 그리고 그 결과가 어떤 후속 계산(적분, 역변환, 급수 전개 등)에 쓰이는지를 확인하면 전체 흐름을 이해하기 쉽다.

    주의할 점

    부분분수분해를 적용하려면 먼저 분자의 차수가 분모의 차수보다 낮아야 하며, 분자 차수가 분모 차수 이상이면 먼저 다항식 나눗셈을 한다. 실수 범위에서 더 인수분해되지 않는 이차 인수는 그대로 두고, 그 항의 분자를 일차식으로 둔다.
