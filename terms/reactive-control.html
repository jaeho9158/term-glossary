    반응형제어 (Reactive Control)

    로봇공학
    한 줄 정의: 복잡한 내부 표현이나 계획 없이 현재 센서 입력에 즉각적으로 반응하여 행동을 결정하는 로봇 제어 방식.

    쉽게 풀면

    미리 깊이 생각하지 않고 지금 눈앞에 보이는 것에 즉각 반사적으로 반응해서 행동하는 방식입니다.

    왜 중요한가

    복잡한 계획 없이 즉각적으로 반응하기 때문에 연산 지연이 적어, 장애물 회피처럼 빠른 반응이 요구되는 저수준 제어 계층에서 실용적으로 활용됩니다. 갑자기 사람이 앞으로 뛰어들거나 예상치 못한 장애물이 나타나는 상황에서는 복잡한 계획을 다시 세울 시간적 여유가 없기 때문에, 센서 값이 들어오자마자 곧바로 행동으로 이어지는 반응형 제어가 로봇의 최종 안전판 역할을 하는 경우가 많습니다.

    논문에서는 이렇게 쓰입니다

    반응형 제어는 감지-행동(sense-act) 매핑을 직접 정의하여 내부 세계 모델 없이 낮은 지연으로 환경 변화에 대응하는 제어 패러다임이다.

    센서 값이 들어오면 그 즉시 정해진 규칙에 따라 행동으로 바로 연결시켜, 별도의 복잡한 추론 단계를 거치지 않는다는 의미입니다.

    "포텐셜필드 기반 반응형 제어기는 장애물로부터의 척력과 목표점으로의 인력을 실시간으로 합산하여 조향각을 결정함으로써, 별도의 경로계획 없이도 동적 장애물을 회피하였다."

    반응형 제어가 단순한 조건문 나열이 아니라, 힘의 합처럼 수학적으로 정의된 규칙을 통해 실시간으로 동적인 장애물까지 회피하는 데 쓰인다는 점을 보여주는 문장이다.

    조금 더 깊게 보면

    반응형 제어만으로는 장기적인 목표 지향 행동을 만들기 어려워, 실제 로봇 시스템에서는 계획 기반 상위 계층과 결합하는 계층형 구조로 많이 설계됩니다. 대표적인 구현 방식인 포텐셜필드법은 목표 지점을 로봇을 끌어당기는 인력으로, 장애물을 밀어내는 척력으로 표현해 이 둘을 더한 방향으로 로봇을 움직이게 하는데, 계산이 단순하고 빠른 대신 여러 힘이 서로 상쇄되어 로봇이 국소적인 함정에 갇히는 문제가 대표적인 약점으로 다뤄집니다. 이런 한계 때문에 실제 시스템에서는 반응형 제어가 전역 경로계획을 세우는 심의형 계층 아래에서 국소적인 안전장치로 함께 작동하는 계층형 구조가 흔히 채택됩니다.

    주의할 점

    장기적인 목표 지향적 계획 능력이 부족해 복잡한 작업에는 심의형(deliberative) 요소와 결합해야 합니다.
