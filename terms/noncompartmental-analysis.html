    비구획분석 (Noncompartmental Analysis)

    독성학
    한 줄 정의: 특정 구획 구조를 가정하지 않고, 관찰된 혈중 농도-시간 데이터로부터 직접 독동태 파라미터를 계산하는 분석 방법입니다.

    쉽게 풀면

    구획모델은 몸을 몇 개의 가상 통으로 나누는 가정을 세운 뒤 계산하지만, 비구획분석은 그런 가정 없이 실제로 측정된 농도-시간 데이터 자체만 가지고 필요한 값을 계산하는 방법입니다. 마치 그래프 아래 면적을 직접 재는 것처럼, 별도의 모델 구조를 세우지 않고도 청소율이나 혈중농도곡선하면적 같은 값을 구할 수 있습니다. 가정이 적은 만큼 더 간편하고 자료 의존도가 낮은 방법으로 여겨집니다.

    왜 중요한가

    비구획분석은 구획 수를 미리 정하거나 복잡한 모델을 적합시키는 과정 없이도 신속하게 핵심 독동태 파라미터를 얻을 수 있어, 규제기관 제출 자료나 초기 스크리닝 연구에서 널리 활용됩니다.

    논문에서는 이렇게 쓰입니다

    "비구획분석을 통해 각 투여군의 AUC, 청소율, 반감기를 산출하였다."

    모델 구조 가정 없이 직접 데이터로부터 파라미터를 계산했다는 의미입니다.

    "비구획분석 결과는 별도로 수행한 2-구획모델 분석 결과와 유사한 경향을 보였다."

    두 분석 방법의 결과를 비교 검증한 예문입니다.

    조금 더 깊게 보면

    비구획분석에서는 사다리꼴 공식을 이용해 혈중농도곡선하면적을 계산하고, 이를 바탕으로 청소율과 제거반감기 등을 유도하는 것이 일반적인 절차입니다. 구획모델에 비해 계산이 단순하지만, 대신 관찰되지 않은 시점의 농도를 추정하는 데는 한계가 있습니다.

    주의할 점

    비구획분석은 측정 시점 간격이나 마지막 채혈 시점에 따라 결과 정확도가 크게 좌우될 수 있어, 충분한 빈도로 채혈된 데이터가 뒷받침되어야 신뢰할 수 있는 값을 얻을 수 있습니다.
